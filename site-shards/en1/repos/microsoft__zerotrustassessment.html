Zero Trust Assessment

The Zero Trust Assessment is a PowerShell module for administrators who want to review their Microsoft 365 tenant and Azure security configuration. It runs read-only assessments, generates local reports, and provides recommendations to help prioritize improvements.

 [!IMPORTANT]
 This is a community project maintained by Microsoft employees, not an official Microsoft product. It is provided as-is and is not supported through any Microsoft support program or service. See SUPPORT.md for community help and issue-reporting guidance.

 What the assessment covers

All seven current pillars run by default: Identity, Devices, Network, Data, Infrastructure, SecOps, and AI. The -Preview switch is reserved for preview-only features and is not required for these pillars.

Coverage depends on service connections, permissions, licenses, and available data. Review skipped checks and errors as well as pass/fail results. The assessment does not apply remediation.

The repository can contain changes not yet available in a published package. See the release history for shipped changes, and the PowerShell guide for the current source's requirements and behavior.

 Installing and running the assessment

Before you start, review the prerequisites and required permissions and roles. Use PowerShell 7.6 or later for the current source's dependencies; published packages can have different requirements. Windows is needed for full service coverage. A dedicated Windows VM and a fresh PowerShell session help avoid dependency conflicts.

Install the stable package, connect to your tenant, and run the assessment:

powershell
Install-PSResource -Name ZeroTrustAssessment -Scope CurrentUser
Connect-ZtAssessment -Tenant contoso.onmicrosoft.com
Invoke-ZtAssessment


Replace contoso.onmicrosoft.com with your tenant's verified domain or GUID. The default output directory is .\ZeroTrustReport; use a new output directory for each fresh run. Protect the reports and exports because they can contain sensitive tenant data.

See the PowerShell guide for app-only certificate authentication, pillar selection and resume behavior, and configuration tuning.

Telemetry is enabled by default, with the tenant ID as its only tenant-specific custom property. Assessment results are not included. Use -DisableTelemetry to opt out; see data handling and telemetry for payload and network-metadata details.

 Infrastructure Pillar Scope

Infrastructure results use Microsoft Defender for Cloud recommendations and include only accessible Azure subscriptions tagged with ZeroTrustAssessment:Infrastructure. Arrange the tags and Azure read access before running; see Infrastructure scope.
