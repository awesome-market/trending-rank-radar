React Native Skia





  
    
    
  


React Native Skia bring Skia, the rendering engine behind Google Chrome to React Native to React Native.

We use Graphite, Skia’s new GPU backend built on WebGPU (Dawn). It plugs directly into React Native WebGPU, so 2D drawings, 3D scenes, and machine learning models share the same GPU device and the same canvas, at zero cost. The result is a unified GPU runtime for React Native.  See Documentation.

React Native Skia has been downloaded more than 60 millions times on NPM. And today, it powers the user-experiences of some of the top apps on the App Store and Google Play, including several that have won awards from Apple, Google, and Expo.

Installation instructions

 v3 and v2

React Native Skia v3 renders with Graphite, Skia's new GPU backend. It runs on Metal on Apple platforms and on Vulkan on Android.

| | v3 | v2 |
|:--|:--|:--|
| npm | react-native-skia | react-native-skia@2 |
| Skia backend | Graphite (Vulkan/Metal) | Ganesh (OpenGL/Metal) |
| Architecture | multi-threaded | single-threaded |
| Platforms | iOS, Android, macOS, Mac Catalyst, tvOS, Web | iOS, Android, macOS, Mac Catalyst, tvOS, Android TV, Web |
| Branch | main | 2.x |
| Documentation | wcandillon.github.io/react-native-skia | wcandillon.github.io/react-native-skia/v2 |

v2 is still maintained. To upgrade from v2 or from @shopify/react-native-skia, follow the migration guide.

 WebGPU

Graphite runs on Dawn, Google's WebGPU implementation.
With React Native WebGPU installed alongside it, Skia and WebGPU share the same GPU device and can exchange textures without any copy. This also works with three.js.
See the WebGPU documentation.
