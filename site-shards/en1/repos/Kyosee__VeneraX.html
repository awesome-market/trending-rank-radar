VeneraX 是一款免费开源的多平台漫画阅读应用，基于 Venera 持续维护与增强。

下载 · 功能 · 使用说明 · 更新日志 · 反馈

 原始项目： 本项目 fork 自 venera-app/venera。

 [!IMPORTANT]
 使用前请阅读《VeneraX 用户协议与免责声明》，了解软件功能、第三方服务风险及数据处理情况。本说明不增加 GNU GPLv3 之外的许可限制；依法需要另行取得的数据处理同意仍须单独办理。

Linux AppImage 安装说明

在 Releases 下载 VeneraX--x86_64.AppImage（Intel / AMD 64 位）或 VeneraX--aarch64.AppImage（ARM64）。赋予执行权限后直接运行，无需安装 deb 包：

bash
chmod +x VeneraX--x86_64.AppImage
./VeneraX--x86_64.AppImage


请替换示例中的版本号和架构。AppImage 包含 GTK、WebKitGTK、ONNX Runtime 及托盘运行库，基于 Ubuntu 22.04 构建；需要 glibc 2.35 或更新版本、桌面图形驱动及 X11／XWayland，不支持旧版 glibc 或 Alpine 等 musl 系统。系统缺少 FUSE 时可解包运行：

bash
./VeneraX--x86_64.AppImage --appimage-extract
./squashfs-root/AppRun


更新时下载新版 AppImage 并替换旧文件；应用数据仍保存在原有用户数据目录。

- [x] 自动翻页新增匀速滚动模式，可设置阅读时屏幕常亮
- [x] 夜览模式
- [x] 阅读背景色（可按漫画设置）
- [x] 墨水屏适配（实验性）：翻页时全屏刷新清残影，掌阅设备支持系统水波纹翻页

 漫画管理

- [x] 本地、追更、收藏优化；追更可同时追多个收藏夹，可设检查间隔、启动时检查与每日定时检查

- [x] 支持自定义自动清理历史记录

 首次启动与升级提示

应用仅在新安装且本机没有应用数据时展示一次引导：先阅读可切换语言的协议，再设置界面语言、查看基础权限说明，最后选择导入备份或配置 WebDAV；可选设置可跳过。已有数据的用户升级后仅显示一次本版协议更新提示，不重新进入新用户引导。

本机保存已确认的协议版本、确认时间和阅读语言。普通应用升级不重复提示；协议发生实质变更时会展示变更摘要及新版全文，并请用户重新确认。导入备份或 WebDAV 恢复不会代替本机确认。未确认或拒绝不会删除已有数据；开启应用锁时先解锁再阅读协议。维护者修订实质条款时须同步更新协议版本、日期、变更摘要及全部语言正文。

系统权限、WebDAV、翻译及其他依法需要单独同意的数据处理分别选择或授权，确认协议不替代这些授权。

电脑端第三步展示“功能与访问说明”，不会提供无实际作用的授权按钮：说明网络及系统限制、应用内任务进度，以及导入导出时的文件选择；访问受保护目录时仍可能需要系统确认。Android / HarmonyOS 保留实际支持的通知授权入口。

 更新日志
