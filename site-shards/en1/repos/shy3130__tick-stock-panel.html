 核心功能

 自由扩展

日 K、分钟 K、实时行情和除权因子可分别选择数据源。扩展表支持定时拉取、历史回补和 API 写入，字段可供信号、因子及回测使用。在「设置 → 导入与备份」安装数据源和页面插件，导入策略、信号、因子与图表指标。扩展页面可以和内置页面一起分组、排序。数据源配置 · 扩展与导入

 二次开发

用 Page Pack SDK 开发自有页面，复用工作台的行情接口和公共个股详情，打包上传后刷新即可使用。源码扩展可注册路由和导航，在个股详情、自选页等已开放的插槽添加组件。后端支持注册独立接口、启动钩子和通知格式化器，也可以编写自定义仓位策略。页面 SDK · 二次开发指南

脚本和外部 AI 可通过 Open API 或 MCP 按权限读取行情、查询策略和提交回测。AI 接入指南

 自研 Tivelo 引擎

- Tivelo Data 负责采集、校验和发布数据版本，可把日 K 与复权因子固定为快照，供策略复跑和归档研究使用。数据引擎
- Tivelo Backtest 为工作台的日线、分钟策略和组合回测提供撮合与记账，按 A 股 T+1、涨跌停和交易费用等约束模拟成交。回测引擎

两个引擎都提供 Python 库和命令行入口。工作台普通回测支持前复权和后复权，启用并授权 Tivelo Pro 后，A 股日线策略还可直接选择动态复权。快照回测 · 动态复权

 快速开始

Docker 可直接运行工作台。行情、策略和用户配置保存在当前目录的 data/。

bash
docker run -d --name tsp -p 3018:3018 \
  -e DATA_DIR=/app/data -v "${PWD}/data:/app/data" \
  ghcr.io/shy3130/tick-stock-panel:latest


打开 localhost:3018。

 第一次使用

1. 在「设置 → 数据源」选来源并检测能力。
2. 在「数据」同步日 K 和指标。需要分钟策略时，同步对应的分钟历史。
3. 创建或导入策略，先筛选，再选区间回测并保存候选。
4. 把通过验证的规则用于监控或模拟盘。外部客户端通过「设置 → 开放接口」获取对应权限的 Token。







 整体架构





TSP 工作台通过登录会话管理数据源、策略和研究任务。脚本和 MCP 按 Token 权限访问开放接口。数据源、扩展表、策略与信号、页面和后端模块通过各自的契约接入工作台。扩展与导入 · 开放接口




Tivelo Data 负责数据校验、版本发布和快照，Tivelo Backtest 负责应用交易规则、模拟撮合与账户记账。两者也可通过 Python 库或命令行独立使用。数据与市场契约



 数据与执行流程



普通策略回测使用工作区里的策略。A 股前复权日线回测可选用已发布的日 K 快照，启用回测过滤时会记录所用扩展数据版本。归档研究会先检查匹配的数据快照和策略归档，再提交任务。用快照跑回测




 计算内核与性能

行情整理、指标与因子计算、回测面板准备使用 Polars 1.44 的 Rust 列式内核。在支持 Numba 的环境中，部分回测矩阵的滚动和递推算子使用 JIT 加速。

同机、同策略的 15 组参数网格 A/B 基准中，逐组独立准备与共享行情面板、矩阵编码的总耗时分别为 19.47 秒和 6.19 秒。两组均计入数据准备，共享后的耗时减少约 68%，逐笔成交及统计结果一致。基准记录
