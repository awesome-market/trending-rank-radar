 这是什么

Drama Skills 覆盖 AI 短剧与漫剧从点子或原著到成片的全流程：原著分析 → 分集剧本 → 视觉设定 → 图片提示词与分镜 → 视频提示词 → 确认后生产 → 剪辑成片 → 审查。它以 12 个技能的形式装进你常用的编程 Agent（Claude Code、Codex、Antigravity 及其他支持 Agent Skill 规范的环境），直接使用当前 Agent 的模型写作。

这套技能脱胎于我们漫剧工作室的日常产线：2025 年以来累计做过上千个 AI 短剧和漫剧项目，近 8 万行代码的一体化图形工具跟不上模型迭代后，我们把工程做法和提示词经验提炼成这套技能，改用 Agent CLI 加纯文本文件管项目，内部工具只留排队生成。

- 五份 Markdown 记录创作决定 — 按阶段维护 剧本.md、视觉设定.md、分镜.md、图片提示词.md、视频提示词.md，剪辑时加一份 剪辑单.md；只做部分阶段就交付对应文档。
- 白纸黑字防跨镜穿帮 — 跨镜不变的穿着造型写成可原样贴入提示词的固定短语（连戏锁与锁定词），每镜首帧写明出场设定，检查脚本自动核对跨文档引用。
- 先看预览、确认后再花钱生成 — 图片、视频（支持单镜与 GROUP- 多镜合生）、配音和配乐任务均支持整批预览，在文件里列清数量、内容、参考图与参数，明确确认后再批量调用外部接口；平台密钥留在项目外，文档与前置技能不绑定特定平台。
- 成片剪辑也在套件里 — 剪辑技能逐段写明入出点取舍，字幕逐字取自剧本，统一响度后导出成片；检查与测量脚本只列核对结果和实测数据，不替人做创作判断。

 创作指导层与自动化脚本的边界：各技能中的创作方法、剧本/分镜/提示词规范与审查视角不绑定语言、画幅或目录布局，可以直接用于任意语言或已有项目；本地自动化脚本（跨文档检查、创作台、生产交接与剪辑渲染）目前面向标准中文项目结构，要求使用上述五份中文文档与 剪辑单.md 的约定文件名及中文 Markdown 字段。

 安装

前提：已在用 Claude Code、Codex、Antigravity 或其他支持 Agent Skill 规范的编程 Agent，终端可执行 npx（Node.js）。

bash
npx skills add zenstory-ai/drama-skills -y -g


-g 为全局安装，去掉则只装到当前目录；更新时重跑同一条命令即可。带脚本的 7 个技能需要 Python 3.9 或更高版本（其余 5 个纯知识文档技能零运行依赖），short-drama-edit（剪辑成片）与 short-drama-breakdown（对标视频测量/反推）另需安装 ffmpeg / ffprobe；启用可选 Remotion 复杂画面文字面板或动态字幕叠层时另需 Node.js / npm / npx（纯普通字卡场景支持 --screen-text-mode 降级至 ffmpeg 直出，无需安装 Node/Remotion）。

支持直接导入 GitHub 仓库的平台（如 WorkBuddy，见社区整理的完整用法），也可以直接对 Agent 说：


安装这些技能 https://github.com/zenstory-ai/drama-skills



手动软链安装（可安装全部，也可只链需要的技能）

bash
git clone https://github.com/zenstory-ai/drama-skills.git && cd drama-skills

 Claude Code
mkdir -p "$HOME/.claude/skills"
for skill in skills/; do
  ln -s "$PWD/$skill" "$HOME/.claude/skills/$(basename "$skill")"
done

 Codex
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
for skill in skills/; do
  ln -s "$PWD/$skill" "${CODEX_HOME:-$HOME/.codex}/skills/$(basename "$skill")"
done

 Antigravity（CLI / IDE / App，全局安装）
mkdir -p "$HOME/.gemini/config/skills"
for skill in skills/; do
  ln -s "$PWD/$skill" "$HOME/.gemini/config/skills/$(basename "$skill")"
done


每个技能目录都可独立安装；只用某一项能力时软链对应目录即可。short-drama 负责项目初始化、阶段调度与本地创作台。如果只想在单个项目里启用，Antigravity 也支持把所需技能链接到项目根目录的 .agents/skills/（在 Antigravity 里直接打开本仓库副本时，.agents/skills.json 会自动加载全部 12 个技能）；在 Antigravity CLI（agy）中新增链接后运行 /skills reload 即可生效。



也可在 ClawHub 中查找安装（清单见 .clawhub/publish.json）。技能本身统一使用宿主中立的技能名（如 short-drama、short-drama-write），调用前缀随运行环境而变：Claude Code 与 Antigravity 用 /short-drama，Codex 用 $short-drama，其他支持 Agent Skill 规范的环境直接用技能名或自然语言描述任务；下文示例统一以 $ 为例，按所用宿主替换或省略前缀即可。

 版本变更见 CHANGELOG.md 与 Releases；旧项目升级见「升级到新版本后要做什么」。
