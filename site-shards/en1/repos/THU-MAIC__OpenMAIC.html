Latest release

OpenMAIC v1.4.2 — Course-level undo v1.4.2 2026-11-09
1.4.2 is a regular patch release. Its main addition is course-level undo: one undo/redo line per course that covers manual edits, page add/delete/reorder, narration, titles and agent runs, with buttons in the workbench header and Cmd/Ctrl+Z. It also stops a Director from retrying a failing child agent without end (the 1.4.0 known issue 2122), keeps Pro edits from leaving an interactive page empty, lets ALLOW_LOCAL_NETWORKS cover TUN/fake-ip proxies, and carries a batch of PBL v3 fixes plus Java application previews.
