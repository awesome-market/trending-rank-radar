 Install

Install the official Codex / ChatGPT app once and quit it, then download the package for your platform from GitHub Releases:

| Platform | Download | First-run guide |
|---|---|---|
| macOS · Apple Silicon / Intel | CodexDreamSkin-vX.Y.Z.dmg | docs/install-macos.md |
| Windows · x64 | CodexDreamSkin-Setup-vX.Y.Z.exe | docs/install-windows.md |

No source checkout, Node.js install, .sh or .ps1 command is required. After installation, use the macOS menu bar or the Windows system tray. Updates are manual: install the new package over the existing one and your themes and images are preserved. Because the public packages are unsigned, a new download may show a one-time OS security warning — the guides cover the safe GUI approval path, updates and uninstall steps.

Codex Dream Skin v1.5.21

中文 · English

本次更新修复 Windows 在启用 Node.js 环境代理时，因一条非致命警告而无法安装、启动或操作主题的问题。对应 435。

 修复与改进

- Windows 代理环境兼容：启用 NODE_USE_ENV_PROXY=1 时，Node.js 的 UNDICI-EHPA 实验性警告不再被 Windows PowerShell 5.1 当成操作失败。图片检查、主题导入及应用继续根据实际校验结果决定是否成功，非法图片、CSS 和主题包仍会被拒绝。
- Windows 启动判断：将辅助程序的结构化结果与警告分开读取，避免无害警告干扰隐藏窗口识别和已显示皮肤的保留判断；实际失败的诊断信息仍会保留。
- macOS：本次没有运行时行为变更，版本号同步为 1.5.21。

 升级与使用

Windows 用户可使用新版安装包覆盖安装。此修复不需要关闭代理或屏蔽全部 Node.js 警告，安装器不会改写用户的代理环境变量。

完整变更：v1.5.20 → v1.5.21
