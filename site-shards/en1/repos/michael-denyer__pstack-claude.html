README

pstack




Lauren Tan's pstack is an opinionated Cursor skill stack that improves agent outcomes. This is a port for Claude Code, Codex, Pi, GitHub Copilot, Muse, and other agent harnesses. It tracks upstream and also carries named policy forks, each declared in tools/forks.json.

Tell poteto-mode your goal and it will invoke the correct workflow for the task. It keeps your code concise, simple and verified.

For concurrency bugs and invariants that tests cannot reach, /create-formal-verification-skill picks the riskiest property in your code, verifies it with a tool that fits, and leaves a project skill the next agent reruns. The separate agent-formal-verify plugin goes deeper on the method, with guided TLA+ model checking, Lean proofs, and Kani for Rust.

 Built for Claude Code

This port translates upstream's Cursor skills for Claude Code before installation. Upstream's Claude Code install asks agents to translate Cursor names at runtime, using extra tokens and relying on them to apply the mapping correctly. This port also adds a SessionStart hook that routes tasks to poteto-mode.

 Install

 Any harness: npm or Homebrew

shell
npx open-pstack


Or install it once and run it by name:

shell
npm install -g open-pstack
open-pstack


With Homebrew:

shell
brew install michael-denyer/tap/open-pstack


open-pstack needs Node 20 or later; Homebrew installs Node for you. It finds the agent harnesses on your PATH and shows a picker. Press Enter to install into the ones it found, or choose others by number or id, then confirm the planned steps. It runs the same recipe as each harness's section below.

| Option | Effect |
| --- | --- |
| --only claude,pi | Install into the named harnesses without the picker. Each section below gives its id. |
| --yes | Install into every detected harness without asking. |
| --dry-run | Print every step without running or writing anything. |
| --list | Show each harness id and whether it was detected. |

The shared ~/.agents/skills directory (id skills) is never chosen by default, because Codex and OpenCode read it as well as their own plugin and would load each skill twice. Choose it for Gemini CLI, Prime Agent, or DeepSeek Harness.

Muse, Grok Build, MiniMax Code, Antigravity, and the shared skills directory install from a local copy of the plugin, so no clone is needed: open-pstack stages the copy that ships with it at ~/.local/share/open-pstack/pstack, or under XDG_DATA_HOME when that is set. To update, upgrade the installer (npm update -g open-pstack or brew upgrade open-pstack) and run open-pstack again. That refreshes the staged copy, so the shared skills links pick up the new version and any new skills. Plugins that a harness installed itself update through that harness, as its section below describes. See Install with open-pstack for uninstalling.
