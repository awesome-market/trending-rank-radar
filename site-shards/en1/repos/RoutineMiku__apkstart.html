ApkStart








Windows 上的安卓应用运行器 —— 让安卓应用像 Windows 原生软件一样被安装和使用。

- 🖱️ 双击 .apk 即安装：注册 .apk 文件关联后，在资源管理器里双击 APK，自动解析 → 安装 → 生成桌面图标，全程无需打开任何模拟器界面。
- 🧩 每个应用一个桌面图标：图标从 APK 内部离线提取并转为多尺寸 ICO，双击桌面图标 = 直接启动该应用，与打开一个原生 Windows 软件的体验一致。
- 🪟 应用就是一个窗口：运行时以带窗口模式启动（无头模式下 Android 不出 VSYNC，应用进程活着但屏幕上是空的），ApkStart 把这块窗口改标题、换真实应用图标、按竖屏比例摆好位置，就是一个独立应用窗口；全屏铺满屏幕高度并居中，窗口模式可自由拖动缩放且按应用记忆尺寸。
- 🔍 能被 Windows 搜到：安装后同时创建桌面 + 开始菜单（程序\ApkStart\）快捷方式，按应用名在开始菜单搜索即可直达，任务栏按应用分组。
- 📁 数据互通：%USERPROFILE%\ApkStartShared ↔ 安卓内 /sdcard/ApkStartShared 持续双向同步，安卓应用存下的文件直接出现在本机。
- 🪶 极致轻量：壳层本身零第三方依赖（连 ZIP / PNG / ICO / AXML 解析都是手写的），运行时按需拉起，空闲自动回收；也可以完全复用你机器上已有的安卓运行时，额外占用为零。

 下载即用（不想编译）

两个源内容一致，国内建议用 Gitee：

- GitHub：github.com/RoutineMiku/apkstart/releases
- Gitee：gitee.com/daily-miku/apkstart/releases（国内直连快得多）

安装包：

- ApkStart-v-Setup.exe（约 1.3 GB）：一个 EXE 包含全部运行时（adb / Android Emulator / 系统镜像），装完首次启动自动把镜像展开到用户目录，之后不再联网下载任何东西。装到当前用户目录、不要求管理员权限。
- 另有轻量版 ApkStart-v-win64-portable.zip（95 MB，解压后约 226 MB）：首次启动才在后台下载运行时。运行时的下载源就是本项目的 GitHub Release（ApkStart-runtime-.zip 整包），不走 dl.google.com；整包拿不到时才自动退回官方源。

 在线更新（自动选较快的源）

设置 → 软件更新 → 「检查更新」，或托盘右键 → 「检查更新」。发现新版本后点「立即更新」即可。

- 安装版下载 ApkStart-v-Setup.exe 静默安装；
- 轻量版下载 ApkStart-v-win64-portable.zip，解压后覆盖程序目录——运行时目录（%APPDATA%\apkstart\runtime）、已装应用与快照都不在程序目录里，所以更新不会丢东西；
- 替换动作由一段独立 PowerShell 脚本完成（等主进程退出 → 覆盖 → 重新拉起），不会出现「请手动关闭程序」的弹窗，也不会在桌面上残留模拟器窗口。

更新链路不是死连 GitHub，而是每次现测现选：

1. 同时问 GitHub 与 Gitee 的最新版本，取版本号更高的那个（一个源超时/被墙不影响另一个）；
2. 把「源站直连 / Gitee 同名资产 / 镜像前缀」列成候选，每个地址真下 256KB 测速，
   只算「收到首字节之后」的吞吐（握手时间不计入，否则高延迟大带宽的源会被误判成慢）；
3. 按实测速度排序，用最快的那条分块并行下载；失败自动换下一条。

设置里的「下载与更新源」可以强制只用某一边（企业网络只放行一个域名时用），
也可以关掉公共加速镜像、或改用自建镜像前缀。Gitee 附件单文件上限 100MB，
便携包换用 7-Zip 的 deflate（-mx=9）压缩后是 95.0MB，所以 Gitee 上也是
一个能直接双击解压的整包（以前要切成 .part1/.part2 手工拼接，那版已经废弃）。
两个源的同名包体积并不完全一样，客户端按测速结果只挑一个源下完，不会混拼。

两个仓库都是公开的，Gitee 的发行版列表匿名就能读，不需要填任何 token。
（只有在 Gitee 限流返回 403/429 时，才需要在设置里填一个只读 token 提高额度。）


开箱即有的默认行为（不用去设置里找）：

- 开机自动启动，常驻托盘；双击桌面图标直接进应用。
- 安装 APK 后自动创建桌面 + 开始菜单两份快捷方式，Windows 搜索能直接搜到应用名；老版本漏建的会在启动时自动补齐。
- 应用窗口是原生渲染（非投屏）：全屏铺满屏幕高度并居中、保持手机比例不变形；窗口模式保持竖屏，可自由拖动缩放，每个应用的尺寸单独记忆。随时按 F11 或右键托盘切换。
- 安装后自动授予应用申请的运行时权限，不会卡在系统授权框；应用闪退会自动重试、必要时重置应用数据后再拉起。
- 网络直接用主机的网络：安卓侧走 QEMU 用户态 NAT，出口复用主机的物理网卡，不会在 Windows 上创建任何虚拟网卡 / 虚拟交换机（不需要装驱动、也不多一个网络适配器）。不需要联网下载、不需要改任何网络设置。

 〇·五、下载不再无限重下 + 任意位置旧版本可清理 + 点击跟手 + 省资源

下载失败不再留半截文件。 以前所有失败路径都只抛异常不删文件，tmp 里永远
躺着一个半截 zip + .chunks.json 边车；下次带 Range 续传时若服务器/源变了就拼不出
正确字节 → 又失败 → 又留半截……每次打开都在重下同一个包。现在 discardPartial()
在所有失败点（重试耗尽、写流中断、大小不符、校验失败、换源前、openStream 直接
reject）统一清理。自动部署还加了 30 分钟失败冷却，手动点「一键部署」可立即重试。

其他文件夹里的旧版本能清掉了。 清理器原来只扫当前 exe 父目录 + 两个固定
Program 目录，便携版解压到别处就永远找不到。现在扩展扫描各磁盘根目录浅层 +
Downloads/Desktop/Documents，并从桌面/开始菜单快捷方式反查真实安装目录。
.prev- 打包备份残留也纳入清理，且始终排除当前运行版本。本机实测从漏扫到发现
24+ 个条目约 5.6GB。
