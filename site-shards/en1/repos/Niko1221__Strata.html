 Install



 Desktop app

Download Strata for Windows, Linux or Mac →

Install the app, choose a model, and start chatting. There is one installer for each system. On first start the app
downloads the engine for your graphics card. Help with the installer.

Files: Strata-0.2.16-windows-x64-setup.exe · Strata-0.2.16-linux-x86_64.AppImage · Strata-0.2.16-macos-arm64.dmg


  
  Chat, files and a live preview in one window.




 Terminal app

Prefer the terminal? Install Strata, then run strata launch.


Install commands

Linux / Mac

sh
curl -fsSL --connect-timeout 15 --max-time 120 https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh


Windows PowerShell

powershell
irm -TimeoutSec 120 https://github.com/Niko1221/Strata/releases/latest/download/install.ps1 | iex


On Windows, open a new terminal afterwards. Then:

sh
strata launch


Follow the prompts to download and start a model. Terminal guide.

Strata 0.2.15: fixes in the app and the Terminal

The app and the Terminal are 0.2.15. Control is 0.1.61. The engines stay at 0.1.60: the same files as in 0.2.14, which the update feed downloads from the 0.2.14 release. The update feed is sequence 127.

 What changes for you
