HGhub

一个通过插件连接内容的通用视频播放器。


  开始使用 ·
  在线文档 ·
  插件开发 ·
  参与开发 ·
  反馈问题


HGhub 将浏览、搜索、播放和个人片库放在同一个应用中。通过导入 JavaScript 插件，你可以接入不同内容来源，并使用统一的界面观看与管理内容。

应用不内置内容源，不分发第三方插件，也不提供官方源列表。 首次使用需自行导入插件，无需注册 HGhub 账号；来源要求登录时，由对应插件提供登录入口。

 核心体验

- 沉浸式播放：桌面与移动端界面，配合手势和播放控制，在面板中查看详情、选集与评论。
- 多来源浏览与搜索：推荐、分类筛选和聚合搜索，支持按来源查看结果，并保留本地搜索历史。
- 灵活的播放选择：支持 HLS 与普通视频，切换线路、清晰度和解析器，也可搜索其他来源继续观看。
- 自己的片库：管理本地收藏、观看历史与续播进度；支持追更，以及将插件提供的云端列表导入本地收藏。
- 按需扩展：通过文件、网址或插件列表导入内容源与解析器，检查更新，并在更新失败时恢复上一可用版本。
- 更多内容形式：除点播外，还可通过插件接入直播、信息流和图文内容。

具体内容、账号、评论与互动能力取决于所安装的插件。

 开始使用

插件版处于早期开发阶段，目前可从源码运行或构建。当前重点完善 Windows 与 Android，其他平台仍在适配和验证；详见支持状态。

1. 打开 插件中心 → 导入与订阅。移动端从“我的”进入插件中心。
2. 选择插件文件、粘贴代码，或输入插件／列表网址；确认安装并启用。
3. 从首页、搜索或分类找到内容，开始播放。需要切换首页来源时，可在设置中选择。

HGhub 维护播放器与插件接口，第三方内容的可用性由相应来源决定。

HGhub v0.0.5 v0.0.5 2026-11-24
HGhub 0.0.5

本版本新增插件排序，并修复 iOS 安装包结构、HLS 片尾连播以及插件网络解码相关问题。

 新增与修复
- 插件中心排序（77）：长按插件行右侧把手即可拖动排序；分类页沿用相同的数据源顺序。
- iOS IPA 包结构（78）：调整 .ipa 打包方式，并验证包内包含 Payload/HGhub.app/Info.plist，便于签名工具识别。
- HLS 片尾与自动连播（79）：为未派发原生 ended 事件的播放环境增加片尾兜底，避免播放停在最后一帧而不切换下一集。
- 大 Base64 解码（80）：分块转换解码结果，避免大数据触发参数数量限制。
- HTTP 字符集识别（81）：字符集参数名大小写不敏感，兼容 Charset=GBK 等响应头写法。

 下载说明
- Windows：安装版 .exe 或便携版 _portable.zip。
- Android：根据设备架构选择签名 .apk。
- macOS：选择 arm64、x64 或 universal 的 .dmg / .app.tar.gz；安装包可用性仍需设备验证。
- iOS：_ios.ipa 为未签名包，需要通过 TrollStore 或自行签名安装；安装及运行仍需设备验证。
- Linux：.deb 或 .AppImage。
