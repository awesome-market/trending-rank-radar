 项目架构

ReveriePaint 采用混合架构设计:


Kotlin / Jetpack Compose UI (现代化触控交互与界面)
       │ JNI
C++ ReverieCore (文档状态与渲染管线)
       │ C++
Krita Core Engine (KisImage / KisPainter / KisPaintOp)


- 界面层: Jetpack Compose 构建, 针对平板触控与手势深度定制, 支持 Material You 动态色彩与自定义主题
- 核心层: C++ 原生引擎, 封装 Krita 笔刷与图像合成流水线, 文档操作与投影合成均在渲染后台异步执行

---

 核心能力

- Krita 原生笔刷系统: 复用 Krita 核心画笔管线, 内置 240+ 预设, 支持笔刷工坊实时微调动态与压感响应曲线
- 图层与混合体系: 支持图层组嵌套、滤镜图层、剪贴蒙版、Alpha 锁定与 25 种图层混合模式
- 手写笔与手势交互: 低延迟压感适配、悬浮光标预览、双指捏合缩放旋转及双指点击撤销手势
- 事件流回放与安全保存: 二进制轻量笔迹录制, 支持倍速延时回放与后台定时自动保存机制

更多功能细节与开发文档可参阅 官方使用指南、AGENTS.md 与 CONTRIBUTING.md

---

 下载与使用

 运行环境
- 操作系统: Android 7.0 及以上 (API 23+)
- 架构支持: 仅支持 64 位 ARM (arm64-v8a)
- 推荐配置: 支持主动式压感手写笔的 Android 平板设备

 安装渠道
- 官方 Release: 前往 GitHub Releases 下载最新 APK 安装包
- 国内镜像: 通过 Mirror酱 获取高速下载

 崩溃报告与隐私
官方构建默认开启崩溃报告自动上报，用于定位闪退。上报内容只有崩溃堆栈、设备型号、系统版本与当前页面/工具标签，
不含任何画作内容、文件名、账号凭据，也不含广告标识或位置信息。可在「设置 → 隐私与诊断」随时关闭，关闭会同时清除本地安装标识。

完整字段清单与保留期见 docs/PRIVACY.md。若你自行编译，可用 -Ptelemetry=false
（或不注入 TELEMETRY_ENDPOINT）得到完全不联网上报的构建。

 新增特性 (Features)

- 独立多文本矢量图层: 新增独立多文本矢量图层，支持单图层维护多文本块与内联即时编辑，横排竖排支持边界手柄自由自动换行，图层详情与存档深度集成
- 驻笔成形对称与透视联动: 在对称尺与 3D 透视辅助下放行驻笔成形，几何成形与镜像分支即时同步预览并烘焙提交 (by @MatikaneMeika in 205)
- 手势映射与三指滑动调笔: 扩展快捷手势映射体系，支持单指双击与轻点滑动触发翻转画布、重置旋转、橡皮切换等操作，并新增三指滑动平滑调节笔刷大小与不透明度
- 画布自由调整手势: 画布调整工具支持双指捏合缩放、平移与旋转，裁切框及图像缩放实时连续反馈
- 多重动效与视觉光感: 增加画廊进工程有机扭曲波转场、面板错峰滑入动效、选区闭合晶莹流光爆发、吸色光谱呼吸光晕与 Toast 扫掠微光

 缺陷修复 (Bug Fixes)

- 延时摄影与蒙版抓帧修复: 修复透明度蒙版抓帧时导致的白块缺陷，以及绘图过程中改变画布尺寸后导出视频尺寸不跟随更新的问题
- 阴影辅助内存防爆与生命周期: 针对超大画布阴影生成补充降采样保护，修复预览位图回收后偶发触发的 Canvas 绘制异常与 OOM
- 变形撤销漂移与会话状态修复: 修复变形工具在异步守卫窗口、撤销漂移与几何更新上的时序缺陷，支持变形会话内逐手势
