 Documentation

The full docs live at ryko.is-a.dev/godothub-docs: installation, every feature, the settings reference, keyboard shortcuts, and troubleshooting.

Want to build GodotHub or contribute? See Build from source and Architecture.

 Flutter migration

GodotHub is a Flutter desktop app (since v1.6.0) built on a shared Rust core. Releases before 1.6.0 were built with Tauri; their installers stay on the releases page, and existing Tauri installs keep reading the same update feeds. The Tauri code itself has been removed from the repository.

Details

| Feature | Description |
|---|---|
| Create & Import | Create new projects from scratch or from templates, import existing ones from disk, or clone directly from a Git repo. |
| List, Grid & Kanban | Switch between a list, a responsive grid, or a Kanban board with a column per category. Drag projects between columns to recategorize them. |
| Drag & Drop Reorder | Rearrange projects with drag-and-drop, within a category or between categories. |

GodotHub v1.6.0 v1.6.0 2026-11-17
What's new in v1.6.0

 [!IMPORTANT]
 GodotHub has been rebuilt with Flutter. It looks and works the same, starts faster on Windows and uses less memory. Your projects, Godot versions, workspaces and settings carry over on their own.

 What changes for you

- Windows: updates now download and install inside the app, with no installer window. If a new version fails to start, GodotHub goes back to the previous one by itself.
- Windows: the portable build is now a .zip. Unzip it anywhere and run godothub.exe inside. Everything it needs is in the folder, and neither WebView2 nor a Visual C+
