MarKing 是一款桌面端 Markdown 编辑器，注重原生性能与稳定性。  
本地优先、零追踪、无广告 — 文字始终保存在你自己的设备上。

 v1.6.5 — 多文档工作台专版：新增文档标签页——预览页签单击轻量打开，编辑/双击/固定/拖拽即转正，固定/关右/重开/键导全件套；反向链接「未链接提及」一键转双链；Lite 快速查看支持导出；搜索 path:/tag:/- 算子与大纲拖拽整节重排。

 为什么选择 MarKing？

- 真正的本地优先 — 文件以纯 .md 明文存储在你的硬盘上，无云端锁定、无私有格式、无数据追踪
- 原生性能 — 原生编译，启动 

   全功能专业编辑器  
    支持十万字以上的超大型文件流畅滚动。内置 70+ 种 Markdown 智能代码片段与上下文提示，专业级编辑体验。

    

 2. 知识管理与效率

   双链系统与知识图谱 NEW  
    完整的 [[WikiLink]] 双向链接系统，搭配交互式知识图谱可视化。支持力导向布局、缩放漫游、万级节点流畅交互、图谱导出（PNG/SVG）与全屏沉浸。

    

   命令面板与快捷切换器 NEW  
    Ctrl+Shift+P 唤出命令面板搜索一切操作；Ctrl+O 快捷切换器毫秒级模糊搜索文件跳转。编辑区顶部面包屑导航实时显示路径层级。

    

   专注模式 NEW  
    打字机模式（光标行始终居中）+ 聚焦模式（淡化非当前段落），一键进入沉浸式无干扰写作。

   Callout 提示框 NEW  
    兼容 GitHub Alerts 与 Obsidian 语法，支持  [!NOTE]、 [!WARNING] 等多类型提示块的实时渲染。

 3. 创作与交互

   MathLive 公式编辑器  
    集成可视化数学公式编辑器，支持行内与块级公式的所见即所得编辑。内置虚拟数学键盘，完全离线渲染，无需手写 LaTeX。

    

   LaTeX 公式交叉引用 NEW  
    支持 \label{name}、\eqref{name}、\ref{name} 语法，实现公式自动编号与交叉引用。块级公式中 \label 自动分配编号，\eqref 点击一键跳转；支持用户手动 \tag{} 覆盖自动编号；重复 label 每个公式独立编号。

   Excalidraw 手绘白板 NEW  
    在文档中嵌入自由绘制的流程图、架构草图与示意图。以手绘风格激发创意表达，让技术文档不再枯燥。

    

   可视化表格编辑器  
    在应用内悬浮编辑 Markdown 表格，彻底告别字符对齐的烦恼。支持类似 Excel 的行列拖拽、增删及内容对齐。

    

   Mermaid 图表助手  
    内置专业的 Mermaid 绘图渲染支持。流程图、时序图、架构图均可通过助手系统实时预检与可视化渲染。

    

   双域主题与代码块高亮  
    12px 无边框沉浸界面。全局深浅色主题之外，独立内置多套经典代码块预设主题（Dracula、Nord、Tokyo Night 等），极致代码高亮体验。

    

 4. 安全可靠的本地数据

   本地多库管理 (Multi-Vault)  
    在应用内物理隔离不同文档库。个人日记与工作文档完全独立存放，零检索干扰。

    

   Git / WebDAV 双通道同步 NEW  
    笔记库可同步到 Git 远端仓库，或坚果云 / NextCloud / 自托管等 WebDAV 网盘：左侧栏实时显示同步状态，保存后自动同步；执行前可预览同步计划，冲突时逐文件对比差异并选择保留版本；断网超时自动退避重试，多设备同步概况一目了然。同步凭据加密存储，API 密钥等敏感内容永不写入同步或备份。

    

   文档对比与文件历史 NEW  
    文件树右键「文档对比」，将当前文档与历史快照或另一篇文档并排比对差异；对开启过同步的库，「查看文件历史」可浏览提交记录、预览任意旧版本、一键恢复到工作区。

   文档缩放与排版优化 NEW  
    Ctrl+滚轮 缩放显示比例，Ctrl+± / Ctrl+0 调整与重置；预览时中西文、数字之间自动插入视觉空隙，超宽表格自动限宽换行。

   卡片式文件浏览 NEW  
    全新卡片视图，支持树状/卡片模式切换、紧凑/标准/宽松三种密度、面包屑导航与文件夹快速跳转。键盘导航（方向键/Enter/Backspace）与多选操作（Shift+方向键/Ctrl+点击/Ctrl+A）一应俱全。

   大纲面板三栏布局 NEW  
    大纲面板新增右侧独立面板布局模式，宽度可拖拽调整，布局偏好自动保存。默认保持传统侧边栏标签模式，兼容旧版习惯。

   自动防抖保存与历史快照  
    2 秒静默自动保存 + 历史快照回溯，防止误操作或断电丢失数据。

    

   剪贴板图片本地转存  
    Ctrl+V 粘贴截图即自动保存至本地附件目录，并转为正确的相对引用链接。

 5. AI 辅助写作与生态互联 NEW

   AI 排版  
    一键调用 AI 优化文档排版与结构，逐项 Diff 预览，接受或拒绝每一处修改。快捷键 Ctrl+Alt+F。

   行内 AI  
    选中文本即可呼出 AI 工

 多文档工作台专版：新增文档标签页，可同时打开多篇文档——单击以「预览页签」轻量浏览不堆页签，编辑、双击或固定即转为正式页签；反向链接面板新增「提及」视图，一键把正文中的裸提及转换为双链；快速查看（Lite）模式支持直接导出；搜索支持算子筛选，大纲可拖拽整节重排。

 ✨ 新增功能

- 文档标签页 — 同时打开多篇文档：单击文件以「预览页签」轻量打开，编辑内容、双击页签、固定、拖拽换位或 Ctrl+Alt+Enter（可自定义）即转为正式页签；支持固定页签、关闭右侧、重开已关闭、方向键切换与溢出列表；预览页签可在「设置 → 标签页」整体关闭。
- 未链接提及 — 反向链接面板新增「提及」页：找出正文里提到本文档名却没有写成链接的位置，行级或整组一键转换为 [[双链]]。
- Lite 快速查看可导出 — 外部文件快速查看窗口新增导出入口：标题栏图标或快捷键即可导出为 HTML / PDF / DOCX 等格式；切换回主程序时保留浏览位置，窗口标题同步显示文档名。
- 搜索算子 — 全局搜索支持 path:路径、tag:标签、-排除词 组合筛选；输入即弹补全建议，可直接选取库内目录与标签，定位更精确。
- 大纲拖拽重排 — 大纲面板中拖拽标题到同级之间，整节内容（标题 + 正文 + 子标题）一起移动，改结构不再剪切粘贴。
