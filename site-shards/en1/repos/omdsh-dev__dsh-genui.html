GenUI turns DeepSeek Harness (DSH) assistant replies into safe, fully interactive UI surfaces.

 [!IMPORTANT]
 Install GenUI using the full npm package name @changfenhuang/dsh-genui. See Quick Start for setup.

Ask “How are this month’s orders doing?”, and instead of plain text or raw code blocks, the response streams out an interactive sortable data table, audio/video players, draggable function plots, self-grading quizzes, or a persistent workspace dock — all embedded seamlessly within the conversation.

Latest release

GenUI 0.17.0 v0.17.0 2026-11-22
GenUI 0.17.0 修复了三种会让图形或整段界面显示失败的输入。

 围栏和图形修复

- 图解省略布局类型时，自动按流程图排版（460）。
- Mermaid 和 SVG 的源码写在 content 或 text 时也能渲染。同时提供 code 时，以它为准（466）。
- Windows 路径里的非法 JSON 转义会自动修复，原始反斜杠和后续组件完整保留（467）。

 查看与导出

- 图片和 Mermaid 图可以点击放大。导出独立 HTML 时，可读取的同源图片会随文件保存（444、452、453）。
- 修复 iOS Safari 和 WKWebView 中部分表格留白的问题（442）。
- 围栏后误接的解释文字会保留。GenUI 校验后模型只返回空白时，会进入宿主恢复流程（418、458）。

npm 同步完成后，按使用的 DSH 版本运行对应一行，再重启 DSH。

sh
dsh plugin --profile desktop add @changfenhuang/dsh-genui@0.17.0
dsh plugin --profile web add @changfenhuang/dsh-genui@0.17.0
