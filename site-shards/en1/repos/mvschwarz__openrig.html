OpenRig

   

A harness wraps a model. A rig wraps your harnesses. Define your agent team in YAML, boot it with one command. Claude Code and Codex in the same rig, managed as one system.

OpenRig is open-source software for building and running your own network of agents. It turns AI coding agents from a pile of terminal sessions into a persistent, organized team. Talk to a lead agent about the outcome you want; it can coordinate specialists across teams and bring you results and decisions that need your attention. Start with a repository and one useful change, then keep the team's work and context at the same addresses.

It's the open-source system behind my AI civilization experiments.

 Install and first run

Let your coding agent set it up. First check that node --version shows 22 or 24: the command below needs
Node.js and the npx that comes with it. Then, in your project folder, add OpenRig's rigs skill to the agent you
use:

sh
 Claude Code
npx skills add https://github.com/mvschwarz/openrig/tree/v0.7.21/skills/rigs --skill rigs --agent claude-code
 Codex
npx skills add https://github.com/mvschwarz/openrig/tree/v0.7.21/skills/rigs --skill rigs --agent codex
 OMP (Oh My Pi): the pi target installs to .agents/skills, which OMP reads
npx skills add https://github.com/mvschwarz/openrig/tree/v0.7.21/skills/rigs --skill rigs --agent pi


OMP: this pin installs the shared skill only. The v0.7.21 skill includes OMP attachment guidance (rig attach --self … --runtime omp),
but complete setup from OMP has not been verified. OMP isn't a kernel provider; Claude Code or Codex must still be
signed in.

Then type /rigs in Claude Code, $rigs in Codex, or /skill:rigs in OMP (after /reload-plugins if OMP was already
open), and say what you want built. The skill has your agent tell you what it will run and change before it does,
install OpenRig, open the OpenRig view and pass your goal to OpenRig's operator. If Claude Code was already running
when you added the skill, type /reload-skills first, or start
a new session: a session doesn't see a skills folder created after it started.

You need Node.js 22 or 24 (22 on Apple silicon), tmux, macOS or Linux (WSL2 on Windows), and Claude Code or Codex
signed in. One provider is enough to start.

Already have OpenRig? Use the tag that matches rig --version, or upgrade first.

OpenRig 0.7.22 is a patch for a useful first result, responsive coordination and state that tells the truth: a person's agent can wait for its task's answer, several slow daemon reads do less work, and more status reads unknown instead of guessing.

 Before you upgrade

Run the upgrade in the environment that owns your daemon, keeping the same OPENRIG_HOME (legacy RIGGED_HOME) if you set it. Stop the daemon, back up its database, install the patch, then restart it. Your agents keep running; do not use rig down for this upgrade.
