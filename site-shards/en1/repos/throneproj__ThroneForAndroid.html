Throne for Android

Android proxy client, powered by sing-box









Throne for Android manages proxy profiles and subscriptions, routes traffic with rule-based routing profiles, and works either as a VPN or as a proxy-only service. It shares Throne desktop's core and data model, so profiles, share links, route profiles and .thrbackup backups move freely between the two. See the documentation for guides.


  


 Installation

APKs for arm64-v8a, armeabi-v7a and x86_64 are on GitHub Releases, with a SHA256SUMS file to verify them. Throne runs on Android 7.0 (API 24) or newer, including Android TV.

 Upgrading from 1.x
Releases from v2.0.0 on are signed with a new key, so Android refuses to install them over a 1.x release (signature conflict). Uninstall the old release first, then import your subscriptions and profiles again: old local configurations are not migrated.

 Subscription Formats

Various formats are supported, including share links, various JSON representation of Sing-box configs, and v2rayN link format as well as limited support for Shadowsocks and Clash formats.

Deeplinks are also supported, read the documentation for more information.
