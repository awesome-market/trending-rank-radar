 About

Edge0 is an open-source streaming MoE inference framework for running large sparse models on consumer hardware.

Use it through the command line, a local API server, or the Edge0 Chat app.

The latest release brings 145B and 120B latent-MoE models to a single NVIDIA GPU or an Apple Silicon Mac.

Trained natively at 4 bits, both models are available in Q3_K and NVFP4 for local agent workloads.

edge0-infer provides shared serve and chat commands and selects the engine from the model folder. The latest models run on edge0-strata, a fork of Strata; the previous 35B release runs on the GGML-based native engine.

 Platforms

Support depends on the model and its engine.

| Platform | edge0-145b, edge0-120b (edge0-strata) | edge0-35b (native engine) |
| --- | --- | --- |
| Linux | NVIDIA GPU (CUDA 13) | CPU |
| Windows | NVIDIA GPU (CUDA 13) | CPU, Vulkan |
| macOS (Apple Silicon) | Metal | Metal, CPU |
| iOS | — | Metal |
| Android | — | CPU |

Use the 145B / 120B setup for the latest release. The previous-release guide covers native backends, platform-specific builds and chat examples. The 8B checkpoint is available; native-engine support is planned.
