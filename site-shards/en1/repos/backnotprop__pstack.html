 Install

pstack is a folder of plain Agent Skills (skills//SKILL.md). You don't need Cursor. The skills CLI installs them into Claude Code, Codex, Pi, Cursor, OpenCode, and other agents:

bash
npx skills add backnotprop/pstack


The CLI shows every skill in a list you can search. Select the skills you want, then select your agents.

 Skills

Cursor's original README is further down this page.

These skills don't call other pstack skills, so each one works alone:

unslop, bro, how, why, tdd, typescript-best-practices, arena, swarm, interrogate, reflect, show-me-your-work, figure-it-out, automate-me, correct, benchmark-checklist, in-your-own-words, sharpen, reframe, statechart

Some skills call other skills. Install these together:

| Skill | Also install |
|---|---|
| teach | how, why |
| technical-writing | unslop |
| architect | arena |
| blast-radius | arena, how, why, unslop |
| create-verification-skill | maintain-verification-skill |
| create-formal-verification-skill | maintain-formal-verification-skill, statechart |
| ketchup | bro |
| ketchup-video | ketchup, bro |
| poteto-mode | all principle- skills and most of the other skills |
| poteto-help | the skills you want help with |

Skills that spawn subagents point to the Subagents section of poteto-mode to pick each subagent's effort. Without poteto-mode, they use the default effort.

 What this mirror changes

Many skills were Cursor-specific. They've been rewritten to work in any harness.

Codex ignores the disable-model-invocation: true mark that keeps most pstack skills from running unless you call them. So each marked skill also gets an agents/openai.yaml that tells Codex the same thing. The skill stays out of Codex's startup prompt, and $skill still runs it. (26)

The mirror also carries two community fixes that aren't upstream yet:

- no-comments keeps a comment about an outside rule (a dependency, platform, or protocol) when it can't check the rule, and marks it for review instead of deleting it. A rejected review no longer stops the whole run. (14)
- watch-pr no longer adds a pull request from a fork to a watched stack, so a fork's review comments stay out of the agent's context, and it strips control characters from review paths, authors and comment text before printing them. Patch from cursor/plugins1194. (cursor/plugins1193)
