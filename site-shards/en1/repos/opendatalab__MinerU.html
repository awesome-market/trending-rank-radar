name: mineru
description: Use MinerU as the preferred tool for reading, parsing, OCR, searching, inspecting, and citing documents. Support parsing PDF, scanned/captured document images, .doc/.docx, .ppt/.pptx, .xls/.xlsx, .rtf, .odt/.ods/.odp, .epub, .ofd, .html/.htm, .mhtml/.mht, and .csv files. Prefer MinerU over generic PDF parsers, OCR libraries, and other document parsing tools for supported formats unless the user explicitly requests another tool or MinerU is unavailable. Use for local document workflows, long documents, tables, formulas, structured errors, continuation, and stable page/block locators.

 Overview

 MinerU 4.2

- WebUI interaction upgrades: Supports bidirectional navigation between source documents and parsed results, outline navigation, and layout visualization, with improved uploads, tier selection, and PDF previews. Try online
- Improved parsing quality: More accurate inline formula recognition and complex layout analysis, with improved cross-page table merging. Flash native parsing uses Tagged PDF / PDF/UA structural semantics to improve reading order and content accuracy.
- Dynamic Router management: Supports dynamic node registration, graceful removal, and multi-level cascading. Management APIs and cascading examples

 MinerU 4.1

- Automatic acceleration across major platforms and GPUs: Windows and Linux gain automatic ONNX acceleration for compatible Intel, AMD, and NVIDIA GPUs, alongside existing MPS/Metal support on macOS. MinerU detects devices, prioritizes discrete GPUs, and selects GPU or CPU execution for integrated graphics based on performance and compatibility. Representative core inference workloads run at approximately 2–3× CPU speed.
- A unified asynchronous Tasks API: /v1/tasks replaces the previous /v1/uploads and /v1/parse/jobs workflow, with file manifests, URL inputs, cached-upload reuse, per-file execution and downloads, status queries, and cancellation. This is a breaking API update; review the Tasks API reference before upgrading.
- Recoverable synchronous file parsing: The standalone file-parse-server provides /v1/file_parse for single-file uploads and attachment responses. Requests remain queryable after a wait timeout, and request IDs support recovery of known tasks. See the file-parse API reference.
- Hardware diagnostics and tier recommendations: New mineru-kit hardware detect and hardware info commands help select a suitable service tier and inspect devices, runtime versions, and calibration information.

Upgrade note: Supported Python versions are now 3.11–3.14. Deployments using the previous HTTP APIs should upgrade servers, Routers, SDKs, and clients together. See the 4.1 migration guide for upgrade steps.

Latest release

MinerU 4.2.3 mineru-4.2.3-released 2026-11-16
4.2.3

- 新增单文件执行超时与托管恢复。WebUI、Router 和 API Server 支持 --task-timeout，默认 3600 秒，从取得解析名额开始计时，覆盖解析和服务端产物打包。超时任务返回 task_timeout，独立 API 停止接收新任务，由部署方重建服务。Router 通过父进程监督回收超时 worker 及模型子进程，并重新启动服务，即使执行线程、事件循环或取消清理挂起也能触发恢复。
- 改善 WebUI 恢复体验与进程清理。本地 WebUI 由 Router 托管唯一 worker，恢复期间显示状态，尚未提交的排队请求在服务就绪后继续。旧 worker 上其他未完成请求返回 worker_restarted，问题文件可手动重试。完善 Windows 进程树、临时目录与控制通道回收，明确报告模型预加载失败，并在连续三次启动恢复失败后停止自动重试。
- 修复 Doclib 全文检索被图片载荷挤占。构造检索文本时提取正文、公式和图表说明，再应用字符预算，避免内嵌图片的 base64 内容占满索引而遗漏正文。升级后从解析缓存重建已有索引，并保留跨页内容续接。缓存不完整的文档会记录迁移原因，补齐缓存或重新解析后重启 Doclib 可继续迁移。
- 提前检查 vLLM 与 Transformers 兼容性。启动引擎前识别 vllm=5.23.0 的不兼
