duckdb-rs







duckdb-rs is an ergonomic Rust wrapper for DuckDB.

You can use it to:

- Query DuckDB with type-safe bindings and an API inspired by rusqlite.
- Read and write Arrow, Parquet, JSON, and CSV formats natively.
- Create DuckDB extensions in Rust with custom scalar and table functions.

 Quickstart

Create a new project and add the duckdb crate:

shell
cargo new quack-in-rust
cd quack-in-rust
cargo add duckdb -F bundled


Update src/main.rs with the following code:

rust
use duckdb::{params, Connection, Result};

struct Duck {
    id: i32,
    name: String,
}

fn main() - Result {
    let conn = Connection::open_in_memory()?;

    conn.execute(
        "CREATE TABLE ducks (id INTEGER PRIMARY KEY, name TEXT)",
        [], // empty list of parameters
    )?;

    conn.execute_batch(
        r"
        INSERT INTO ducks (id, name) VALUES (1, 'Donald Duck');
        INSERT INTO ducks (id, name) VALUES (2, 'Scrooge McDuck');
        ",
    )?;

    conn.execute(
        "INSERT INTO ducks (id, name) VALUES (?, ?)",
        params![3, "Darkwing Duck"],
    )?;

    let ducks = conn
        .prepare("FROM ducks")?
        .query_map([], |row| {
            Ok(Duck {
                id: row.get(0)?,
                name: row.get(1)?,
            })
        })?
        .collect::()?;

    for duck in ducks {
        println!("{}) {}", duck.id, duck.name);
    }

    Ok(())
}


Execute the program with cargo run and watch DuckDB in action!

 New! duckdb-neo: the v2 C API wrapper (beta)

duckdb-neo is the new crate that targets DuckDB's new v2 C API (duckdb_v2.h) instead of the v1 API used by duckdb. This allows you to do much more - replacement scans, copy, aggregates, all first-class citizens.

Installation is simple:

shell
cargo add duckdb-neo


rust,ignore
use duckdb_neo::{
    Parameters,
    environment::{Environment, StorageLocation},
};

fn main() - duckdb_neo::Result {
    let environment = Environment::new()?;
    let instance = environment.open(StorageLocation::InMemory)?;
    let connection = instance.connect()?;

    let mut result = connection.query("SELECT $1::INTEGER", Parameters::positional(&[&42]))?;
    let chunk = result.next_chunk()?.expect("query returned no rows");
    let values = chunk.get_vector_at::(0)?.reader()?;

    assert_eq!(values.get(0)?, Some(&42));
    Ok(())
}


To try it interactively, run the SQL REPL example with cargo run -p duckdb-neo --example repl.

To write DuckDB extensions with duckdb-neo, loadable or statically linked, see crates/duckdb-neo/extensions.md or the extension template.
