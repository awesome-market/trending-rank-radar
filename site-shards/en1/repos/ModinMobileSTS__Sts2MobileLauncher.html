 About the Project

This project is an experimental, unofficial Android port and launcher framework for Slay the Spire 2. It DOES NOT contain any base game files. Instead, it provides an Android shell that allows players to import and run their legally owned PC game files on mobile devices, featuring support for Mod loading, Steam Workshop browsing/direct ID or URL opening/download tracking with anonymous public browsing and WorkshopOnAndroid-compatible access fallback, local save snapshots, Steam Cloud and WebDAV save synchronization, and launcher update checks from the About page. When an update is found, the launcher can open either the GitHub release page or the Bilibili dynamic feed.

The launcher follows Android’s language setting. Traditional Chinese is shared across Taiwan, Hong Kong and Macao; this does not change the language of the imported game.

Versions → Compatibility Packs → Online Updates checks the project's official compatibility releases and lists signed versions you can install without updating the APK. When no installed full pack matches your game, the launch prompt can offer to download a verified official pack and continue. Checks never install updates on their own, and an older copy bundled with the APK cannot silently replace a newer installed pack. Online updates require a trusted release key in the APK and a signed release; local packs, ZIP import and the offline fallback still work without them.

The first signed pack, v0.8.0, is available for OTA testing. It requires a launcher build that trusts sts2-compat-release-v1; the pack release does not include a launcher APK.

The core architecture consists of three layers:
1. Android Launcher Shell (android/): Handles game data importing, Steam login and game downloading, Steam Workshop public browsing, direct ID/URL opening, and download tracking with default compatible-access routing for networks where Steam Community/API or SteamPipe CDN direct connections time out, local save snapshots, Steam Cloud/WebDAV save syncing, and local file/MOD management. Once everything is ready, it boots up the Godot game process.
The launcher utility pages use a compact dark Material 3 shell, including toolbars, dialogs, and bottom sheets. File Browser provides clickable breadcrumbs, a clipboard banner, name/time/size sorting, add/import actions, and readable contextual multi-select controls. Logs provides source/date filtering and a Package latest action that shares the newest live godot.log and sts2.log, excluding archives. STS2 Android v0.1.14

本次更新：
- 新增游戏 v0.114.0 公测版和 v0.111.1 稳定版的独立兼容目标，保留 v0.113.x 与其他已支持版本。APK 内置官方签名兼容包 v0.8.0，共 11 个目标，离线也可使用。
- 新增“版本 → 兼容包 → 在线更新”：可检查并安装官方签名兼容包，无需重新安装启动器。缺少匹配包时可下载并继续；后台检查不会自动安装。
- 改善大量 MOD 时的启动器响应。MOD 安装正在占用目录时，启动器会在后台等待可安全继续，不再卡住界面。
- 修正尖塔补给站下载未遵循创意工坊分支的问题；“每次询问”可查看与所选分支匹配的快照。
- 修复影响 BaseLib 扩展存档的 JSON 兼容问题，并让 SkinChanger 等 MOD 能读取已导入的游戏主包路径。
- 新增 OpenGL ES 磁盘着色器缓存选项，可仅禁用粒子缓存或禁用全部；默认维持原行为，重启游戏后生效。
- 启动器支持跟随系统使用繁体中文，不改变游戏语言。AI 日志分析支持实时发现与查询日志，回答可流式渲染 Markdown。

安装：导入版不含游戏本体，需导入自己的游戏文件或从 Steam 下载；直装版内置 v0.114.0 公测本体，仅供有授权的私下测试。联机请使用相同游戏版本，不保证不同版本互通。
