 软件介绍

CefFlashBrowser 是一个自带 Flash Player 插件的浏览器，可以正常显示网页上的 Flash 内容，此外还支持打开本地 SWF 文件，管理 Flash 游戏存档等。

 下载与使用

在 Release 下载最新的软件压缩包，解压后双击 CefFlashBrowser.exe 即可使用。

 [!NOTE]
 软件运行依赖 .NET Framework 4.6.2，若运行时提示应用程序无法启动，前往这里下载安装即可运行。

 存档管理

使用SOL存档管理器，可以对游戏存档进行导出、导入、修改等操作。

 [!TIP]
 建议在修改存档之前先对存档文件进行备份，以防数据丢失。

!solmgr
!soledit

 用户脚本

CefFlashBrowser 会在符合匹配规则的网页上自动运行已启用的用户脚本，让你自定义网页内容和行为。在网页上点击 .user.js 链接即可打开安装确认窗口。也可以在主窗口的 选项 → 管理用户脚本 中选择本地文件或输入 URL 来安装脚本，并编辑脚本、切换启用状态或检查更新。

!用户脚本管理器

+ 新增用户脚本支持：自动在匹配的网页上运行已启用的用户脚本，可通过主窗口的“选项 → 管理用户脚本”打开管理器
+ 用户脚本管理器支持新建、编辑、启用/停用、删除、导入本地文件或通过 URL 安装、导出源码，并可在网页点击 .user.js 链接时弹出安装确认
+ 用户脚本编辑器提供语法高亮、代码补全、查找与替换、匹配项高亮以及对未保存草稿的标记
+ 用户脚本支持手动更新与批量更新检查，可在脚本列表或右键菜单中触发，并通过详情对话框查看元数据
+ 用户脚本列表支持拖拽排序与按名称过滤，浏览器工具栏中按脚本分组的命令菜单会显示脚本图标
+ 用户脚本的敏感权限可按页面记忆授权结果，也可在设置中指定默认的询问/允许/拒绝行为
+ 新增下载管理器窗口：支持新建下载、暂停与续传、重试、打开文件、在文件夹中显示、移除记录或删除文件，并按名称、路径或 URL 过滤
+ 浏览器发起的下载可交给程序内下载器或 Windows 下载，并可记住下载目录；下载历史持久化保存，程序重启后仍可续传
+ 浏览器窗口支持多标签浏览：标签可拖拽排序、关闭后回到来源标签、复制标签、关闭其他标签、在新窗口中打开，并支持自适应宽度和悬停预览
+ 新增“始终显示标签栏”设置，并可在设置中指定新标签页的地址
+ 标签可单独静音，可通过标签右键菜单、网页右键菜单、工具栏按钮或 Ctrl+M 切换
