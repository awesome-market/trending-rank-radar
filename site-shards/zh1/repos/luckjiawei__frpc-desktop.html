前往 Releases 下载最新软件包：

| 平台 | 软件包 |

解压 Windows 便携版 zip 后运行 Frpc-Desktop.exe。便携版需要 Microsoft Edge WebView2 Runtime，当前的 Windows 10/11 系统通常已预装。

 2.0 基于 Tauri 2 全面重构，安装包体积比 1.x 的 Electron 版本小很多。

 通过 WinGet 安装（Windows）

如果系统已安装 WinGet，可在 PowerShell 或命令提示符中运行：

powershell
winget install --id luckjiawei.frp-desktop --exact --source winget


更新已安装的版本：

powershell
winget upgrade --id luckjiawei.frp-desktop --exact --source winget


 2.0 新特性

- 基于 Tauri 2 重构：安装包更小，内存占用更低。
- 多实例：可同时运行多个 frpc 实例，连接不同的 frps 服务端。
- Cloudflare Tunnel：与 frpc 实例一起管理 cloudflared 实例。
- 全新仪表盘：只读展示运行中实例、代理数量、连接异常，并支持一键全部启动/停止。
- 界面焕新：浅色、深色和跟随系统主题，侧边栏可收起，菜单选中背景平滑滑动，地址可一键复制。菜单动画遵循系统的“减少动态效果”设置。提示、重置与删除等确认弹窗及输入弹窗统一样式，并适配浅色和深色主题；提示正文与状态图标垂直居中对齐。
- Tab 式配置抽屉：在实例页以右侧抽屉编辑配置、查看日志，无需跳转页面。frpc 配置抽屉分为“实例 / 服务器 / 传输 / Web 界面 / 日志”五个 Tab，打开时自动加载最新保存的配置，右上角仅保留关闭按钮。实例名称和启动时自动连接放在“实例”Tab，与 frpc 配置一起通过底部“保存”按钮一次提交。校验失败时会自动切换到首个错误字段所在的 Tab，并滚动、聚焦到该字段。卡片操作靠左排列，删除和导出配置直接跟在其他操作后面；导出配置可保存该 frpc 实例的 TOML，文件开头附带 Frpc-Desktop 版本号、版权及项目来源注释；“服务器”Tab 还会列出 [metadatas] 自定义元数据，可查看、修改和删除，导入的条目会在生成 frpc 配置时原样写回；删除前会在确认弹窗中展示实例信息和删除影响。
- 应用日志级别独立可调：在系统设置中调整应用自身日志的详细程度，实例的 frpc / cloudflared 日志级别按实例单独设置，两者互不影响。
- 统一的新建实例入口：点击“新建实例”后在弹窗中选择实例类型。frpc 可以手动填写、导入 frpc.toml，或粘贴 Frpc-Desktop 分享的 frp:// 配置链接；TOML 和链接导入会在同一事务中创建实例、服务端设置、代理和 Visitor，并自动打开配置抽屉供选择 frpc 程序。监控端口冲突时自动分配空闲端口；导入的 TOML 中的相对证书路径会按该文件所在目录转换为绝对路径；取消或导入失败不会留下空实例，已有实例不受影响。每个 frpc 实例卡片提供“复制链接”，分享服务器设置但不包含本机 TLS 文件路径。无需重启软件。
- SQLite 存储：自动安全导入 1.x 的现有数据。

 开发

环境要求：Node.js 22.12+、npm 和稳定版 Rust 工具链（参见 Tauri 环境准备）。

sh
npm ci
npm run tauri:dev     以开发模式运行桌面应用
npm run tauri:build   为当前平台构建安装包


 资源占用

侧栏显示 Frpc-Desktop 及其后代进程的 CPU 和驻留内存合计，包括由应用启动的 frpc、cloudflared 实例，每 3 秒刷新一次。CPU 按整机总算力归一化（0–100%）；内存为各进程驻留内存之和，共享内存页可能重复计入。macOS 中由系统服务托管的 WebKit 辅助进程不属于此进程树，暂不计入。
