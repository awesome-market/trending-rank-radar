DOCSight


  Your ISP says everything is fine. DOCSight shows the timeline.



  Self-hosted monitoring for your internet connection. DOCSight keeps DOCSIS signal history, speed tests, latency, events and notes together, so you can find out what is wrong and prove it to your provider.

 Get started

Try the demo, no modem required:

bash
docker run -d --name docsight-demo -p 8765:8765 -e DEMO_MODE=true ghcr.io/itsdnns/docsight:stable


Connect your own modem or router:

bash
docker run -d --name docsight --restart unless-stopped -p 8765:8765 -v docsight_data:/data ghcr.io/itsdnns/docsight:stable


Open http://localhost:8765. DOCSight first asks you to set an admin password; this works within 15 minutes after DOCSight starts, so restart it if you open it later. The setup then asks for your connection type, finds the modem on request and tests the connection. Configuration and history stay in the docsight_data volume. stable follows releases; latest follows the main branch.

 Features

- Signal: Home with line status, Signal Trends, Channels and Channel Timeline, Modulation, Cable Segment Utilization, Correlation
- Connection: Connection Monitor with outages and traceroutes, Speedtest Tracker, BQM, Smokeping, Gaming Quality
- Events and cases: Event Log, Incident Journal and cases, Evidence Journey, Before/After, Smart Capture, complaint letters, BNetzA measurements and TKG compensation for Germany
- Platform: Home Assistant, notifications including browser push, backup and restore, themes, community modules, AI export with local redaction, 24 languages, installable as an app

See the sample complaint report and the proof pack for an example with synthetic data.
