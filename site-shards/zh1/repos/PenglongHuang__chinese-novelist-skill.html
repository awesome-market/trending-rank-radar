chinese-novelist skill

 让 AI 为你写一部完整的中文小说





 v2.0 重构发布：引入三层递进式问答、偏好记忆系统、中断续写、三种写作模式和自动校验修复！

 查看 v1.0 → v2.0 升级说明 了解详情。




 📖 为什么用这个？

脑子里有个故事，却总卡在“然后呢”？先定人物和大纲，再逐章写到完稿。面向 Coding Agent、Personal Agent 等各类 Agent：

- 智能问答 - 三层递进式问答，支持快速跳过和随机生成
- 偏好记忆 - 保存题材、视角和文风偏好，减少重复问答
- 中断续写 - 意外中断？自动检测并从断点继续
- 多种写作模式 - 串行 / 子Agent并行 / Agent Teams，按需选择
- 检查与润色 - 逐章审读连贯性与表达，脚本检查字数，不达标时修复
- 章节衔接 - 记录人物处境与事件后果，承接未解悬念
- 小说书房 - 本地只读书房：黑白墨格界面浏览进度、正文与创作资料，随文件变化自动更新

 🚀 快速开始

安装 Skill：npx skills add PenglongHuang/chinese-novelist-skill

装好后，说一句：使用 chinese-novelist 帮我写一部小说

 支持当下主流 Agent Harness：Claude Code、Codex CLI、Gemini CLI、Cursor、Windsurf、Trae、CodeBuddy、Qwen Code、iFlow CLI、Aider、OpenCode、WorkBuddy 等均可直接安装使用，创作流程中的书房会在写作阶段自动启动，无需手动打开。

v2.4.0：本地小说书房与审读报告 v2.4.0 2026-11-24
本地小说书房

- 启动 scripts/visual/workbench.mjs 打开本地只读书房：多作品书架，大纲/人物/设定/文风/摘要/进度/正文一目了然，文件变动实时刷新。
- Agent 调用加 --detach：命令立即返回、服务留在后台（默认端口 5112，已运行自动复用，日志在系统临时目录）；写作流程第三阶段起自动启动书房，无需用户提出。
- 页面绝对只读，唯一可写是「设置」里保存工作区偏好；新增 Windows 原生目录选择框（IFileDialog，失败回退 WinForms）。

 审读报告

- 全书机械比对：节奏突变、人物在场度与断档、口头禅落实、重复短语、引号配对、编号连续等检查项，按「需修 / 建议 / 参考」分级。
- 报告按作品指纹缓存，发现问题可深链接直达对应章节正文。

 其他

- 默认工作区改为当前目录的 .chinese-novelist/；界面与 CLI 文案统一为「小说书房」。
- README 新增书房章节与截图，ROADMAP 增补 v2.4 条目。

 已知问题

- --detach --port 0 组合会误报「后台启动超时」（服务实际已在随机端口启动）；后台模式请指定具体端口，后续小 fix 处理。

 验证

- 工作台测试套件 45 项全部通过（审读引擎、目录选择框令牌校验、CLI 探活复用等）。
