 📖 项目简介

 「中医很简单，就是阴阳气血。你搞懂了，一通百通。」—— 倪海厦

汉唐中医 是一款以倪海厦《人纪》系列（伤寒论、金匮要略、黄帝内经、针灸大成、神农本草经）为理论根基的中医经方辅助工具。它将经典六经辨证体系工程化，帮助你：

- 循证辨证：以六经为纲，叠加《金匮》证候族鉴别，引导式问诊自动推导证型与主方；
- 即查即用：方剂、本草、穴位、针灸处方、医案、经典著作全部离线收录，随时随地检索；
- 有据可查：1257 例倪师医案与方剂双向联动，辨证思路可回溯；
- 素养提升：黄帝内经知识卡、紫微/易经/四柱等民俗文化工具，构建完整传统文化视野。

 🤖 问倪师AI：把倪师讲义，交给你的模型

「问倪师AI」是 App 里唯一可选的联网功能。它不是把问题直接丢给一个通用大模型，
而是先在本机讲义库检索，再把命中的原文片段连同出处一起交给你自己配置的模型作答；
讲义里没有的，它会明说「讲义里没有」，而不是替倪师编一段。

 [!TIP]
 💰 零成本起步：免费 API，5 分钟就能用
 App 不内置任何端点，也不代收费用。注册一个 OpenAI 兼容服务的免费 Key，
 填进「设置 → AI 讲义问答」即可。首选智谱 GLM-4.7-Flash：
 国内直连、免费、响应快，文本问答综合最优。智谱 / 书生 / Agnes 三家的端点、
 模型名、注意事项与逐项步骤见 免费模型配置指南。

 它和「直接问通用 AI」有什么不同

| | 通用 AI 问答 | 问倪师AI |
|:---|:---|:---|
| 回答依据 | 模型自己的参数记忆，容易把经方讲串 | 本机讲义库命中片段：伤寒 394 条 / 金匮 / 针灸 / 本草 / 医案 1257 例 / 病名对照 48 条 |
| 出处 | 通常给不出 | 片段连同出处一起进上下文，回答里的参考片段可点开原文 |
| 跑偏防护 | 靠模型自觉 | 回答里出现讲义与医案都没有的方名时，自动标注「N 处方名未在讲义片段中出现」 |
| 端点 | 厂商固定 | 你自己填 OpenAI 兼容端点，换模型只改三项 |
| 联网 | 默认联网 | 默认关闭，关闭时零网络请求 |

 一次提问，App 做了什么

1. 本地检索：按病名古今／中西医叫法、方名、关键词三级优先级，在本机讲义库找片段。
2. 组装上下文：把命中原文 + 出处 + 病名对照 + 相关方剂的禁忌要点一起交给模型。
3. 按结构作答：回答按「主证表格 → 辨证结论 → 方剂思路」组织，底部固定免责框；方剂名、药材名、穴位名都能点开详情。
4. 出处审计：核对回答里的方名是否真的出现在讲义片段中，缺的列出来提醒，避免把模型自带知识当成倪师原话。

 能力一览

- 多会话与续接：对话存本机 SQLite，退出页面、杀进程后重开还在；历史会话按「今天 / 昨天 / 7 天内 / 更早」分组，可切换、重命名、删除
- 方剂禁忌进上下文：辨到某个方时，连禁忌与要点一并给模型，能回答「什么情况不能用这个方」，而不只是「这个方治什么」
- 病名对照自动注入：古今病名、中西医叫法对照进上下文，回答下方可展开查看命中条目
- 回答内跳转：方剂、药材、穴位、参考片段都能点进对应详情页，边答边查
- 一键拉取模型列表：设置里可直接读取端点的模型列表，不用手敲模型名
- 任何兼容端点都能接：OpenRouter、本地 Ollama 等 OpenAI 兼容服务同样可用

 三步开启

1. 按 免费模型配置指南 挑一家免费服务，注册并创建 API Key
2. 「设置 → AI 讲义问答」填入 接口地址 / API Key / 模型名（可一键拉取模型列表）
3. 打开开关，回到知识库点右上角「问倪师AI」提问

 [!IMPORTANT]
 隐私边界：该功能默认关闭，关闭时 App 不发出任何网络请求；开启后也只有你主动提问时才联网，
 发送的是「检索到的讲义片段 + 你的问题」，不上传病史、不上传诊断记录；API Key 只存本机 SQLite。
 任何辨证结果与方剂建议均不可替代执业医师的诊断与治疗。

完整配置项见 ⚙️ 详细配置选项说明 · 第 2 节，
免费方案的 Key 获取路径、逐项截图与常见报错见 免费模型配置指南。
