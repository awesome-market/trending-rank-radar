Locally Uncensored

The all-in-one local AI studio for your desktop. Chat, images, video and a coding agent in one app. Install it, pick a model, go.

Free and open source. In local mode everything runs on your own machine. No Docker, no terminal, no config files. The platforms are listed under Download.

 In short

- What it is: one desktop app for AI on your own machine: chat, a coding agent, images and video. Free and open source (AGPL-3.0), no account needed for local use.
- Who it is for: anyone who wants local AI without a terminal, Docker or config files, from first try to daily use.
- Download: Windows 10 and 11 (setup.exe), macOS 14 or newer on Apple Silicon (.dmg), Linux (.AppImage, .deb, .rpm) and Android (.apk). The files are in the Download table.
- Your hardware: chat runs on most PCs with 8 GB of RAM. Images want a graphics card with 6 to 8 GB of VRAM, the bigger video models 12 GB or more.
- Not enough GPU? Optional LU Cloud runs the big models on hosted GPUs from the same app, with the Cloud switch: a credit pack for €15 with no subscription, or Hosted for €19 a month. Plans and packs. Local mode stays free.

Some antivirus engines flag unsigned NSIS installers that download other binaries, which is a false positive. The installer is built by GitHub Actions from the public source on master, and the update channel is signed against a public minisign key, so you can verify both: see SECURITY.md.

Windows shows a blue "Windows protected your PC" box? That is SmartScreen, and it is expected for now: the installer does not carry a code signing certificate yet, so Windows does not know it. Click More info, then Run anyway.

Which file do I need?

Windows 10 and 11: the file ending in _x64-setup.exe. The .msi is the same app for a system wide install.

Linux: the .AppImage runs on most distributions: make it executable (chmod +x) and start it. The .deb is for Ubuntu and Debian, the .rpm for Fedora.

macOS (Apple Silicon only, macOS 14 or newer): the .dmg. Open it and drag LU to Applications. The app is signed with an Apple Developer ID and notarized by Apple. Intel Macs are not supported.

Android 7.0 or newer (arm64): the file ending in -Android.apk. Allow installs from your browser or file app when Android asks.
