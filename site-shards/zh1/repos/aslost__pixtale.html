 💡 前言

Pixtale 是一个自托管的云端存储相册应用，支持 本地、对象存储 等方式作为存储空间，配合本项目的同步工具可自动将手机和PC设备照片同步至云端

 💻 项目预览


  
    
    
  
  
    
    
  


 🐋 Docker部署

yaml
docker run -d \
  --name pixtale \
  -p 8082:8082 \
  -v /home/pixtale/data:/app/data \
  -e ADMIN=admin \
  -e PASSWORD=123456 \
  -e JWT_SECRET=abc \
  aslost/pixtale:latest

将ADMIN PASSWORD JWT_SECRET 变量替换为自己的并执行， 浏览器访问ip:8082

更多详细部署及使用教程见 部署文档

 ✨ 功能

- 🖼️ 瀑布流列表：瀑布流无限滚动，采用游标分页+虚拟滚动优化性能

- 🔄 自动同步：配合本项目的 Pixtale Sync，可自同步至云端

- 🌄 缩略图优化：生成缩略图和高清图，优化在弱网环境下的体验

- 📷 EXIF解析：解析记录照片EXIF信息，按时间线排列照片

- 💻 响应式设计：响应式布局自动适配PC和大部分手机端浏览器

- ☁️ 聚合存储：支持本地、 对象存储作为存储空间聚合存储

- 👥 多用户：支持添加不同用户，提供多用户使用支持与管理


 🛠️ 技术栈

- 全栈框架： Next.js

- Web框架： Hono

- ORM： Drizzle

- 数据库： SQLite

- UI组件： shadcn/ui
