Minecraft 26.3, rewritten from scratch in Rust.
  Play on existing worlds and servers.

  Against Java Edition with Sodium, Lithium, FerriteCore and ImmediatelyFast on a Ryzen 7 9800X3D with an RTX 5080. More computers on the benchmarks page.


What you get

- Vanilla Minecraft: survival, creative and hardcore in every dimension, with the same terrain, mobs, villagers and redstone. Your saves open as they are.
- Multiplayer: play on vanilla and Horizon servers or over LAN, or share your world with friends by invite code. You can host a server too.
- Mods: Horizon's own mod system, with mods like zoom and a minimap, and shader packs. Browse the catalogue or make a mod.
- Beyond vanilla: terrain up to 1,024 chunks away, HDR, controller support, graphics presets and dynamic lights.
- Dedicated server: Server software for high performance, low memory usage, and near instant startup. See the server benchmark.

What you need

- Your own copy of Minecraft: Java Edition. Horizon ships no Minecraft files. It builds them from the game you bought, so install version 26.3 and start it once.
- Windows, macOS or Linux: Windows on x64 or ARM64, macOS 12 or later, Linux on x86-64.
