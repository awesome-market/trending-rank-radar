Ceru Music（澜音）

一个跨平台的音乐播放器应用，支持基于合规插件获取公开音乐信息与播放功能。

 项目简介

Ceru Music 是基于 Electron 和 Vue 开发的跨平台桌面音乐播放器工具，仅提供插件运行框架与播放功能，不直接存储、提供任何音乐源文件。用户需通过自行选择、安装合规插件获取音乐相关数据，项目旨在为开发者提供桌面应用技术实践与学习案例，为用户提供合规的音乐播放工具框架。

 技术栈

- Electron：用于构建跨平台桌面应用
- Vue 3：前端框架，提供响应式 UI
- TypeScript：增强代码可维护性和类型安全
- Pinia：状态管理工具
- Vite：快速的前端构建工具
- CeruPlugins：音乐插件运行环境（仅提供框架，不包含默认插件）

v2.6.0 v2.6.0 2026-11-27
伴唱模式（Beta）

- 从播放栏的「··· → 伴唱模式」打开，拖动滑杆即可在只听人声、原声和只听伴奏之间调节。高级面板还可以逐轨调音量、变速和升降调。
- 提供约 30 MB 的「轻量双轨」，可分别调节人声与伴奏，以及约 98 MB 的「乐器五轨」，可分别调节人声、鼓、贝斯、钢琴和其他乐器。目前人声分离对中文歌适配最好，其他语言的歌曲效果可能因曲目而异。
- 首次使用所选资源包时按需下载。澜音会先测速 GitHub 直连和代理镜像，再按测速结果尝试可用线路。「下载管理」里可以查看进度、暂停、继续、取消和删除记录。
- 模型安装后可以离线分离，两个资源包可同时安装和自由切换。软件更新和删除下载记录都会保留已安装的模型，可在伴唱高级面板单独卸载。通过 Windows 安装程序卸载澜音时，模型随应用数据一并清理。
- 快捷浮层适配浅色、深色和全屏毛玻璃，高级面板在小窗口也可以滚动。遇到分轨加载失败或超时会继续播放原声，可从面板重试。

 无感过渡与自动混音

- 重新调整了无感过渡的切入时机。澜音会提前准备下一首，尽量选择当前歌曲较安静的尾段混入。进度条会标出预计过渡区间，也能看到实际淡出和淡入的范围。
- 过渡时前一首逐渐淡出，后一首逐渐淡入，并在中段交接低频，减轻两首歌叠加时的音量突变和低音堆叠。
- 新增可选的「自动混音」。当两首歌的节拍能可靠匹配时，自动对齐节拍、临时微调下
