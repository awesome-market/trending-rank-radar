README

nightshift

Nightshift is a plugin for Claude Code, Codex, and Cursor.












Plan
Take your plan further. Before the first write, bring the hard questions into the plan room. Compare approaches, set the boundaries, and choose the evidence for each task. Record decisions and a clear definition of done so your agent carries the agreed plan into execution.


Execute
Step away while Nightshift keeps your agent on the job. You choose when to start. It keeps your agent working through the punch list until every item is checked off. Decisions don’t block progress. The agent picks a default answer and records it in the parking lot for you to review.


Review
Get reviewable results, not a marathon chat. Each item gets its own receipt. See what the agent delivered, what it tried and rejected, and which checks ran, alongside evidence, duration, and token usage. Decisions come back with the default chosen and why.






 Shipped with Nightshift

Nightshift built Nightshift. Its initial shift produced the plugin’s clock-out gate, hooks, and commands. The build record pairs the original punch list with the commits. A later Codex shift completed 11 maintenance items on one branch, with one commit per item, and shipped in v0.9.2. Original build and commits · Maintenance receipts · Merged PR 53

Two agents worked the same plan. When the Claude Code session ran out of allowance, the maintainer stopped it. Ten minutes later, Cursor resumed on the same branch with the same punch list. The shift spanned 45 elapsed hours. After review and further fixes, the maintainer merged 67 commits and closed 57 issues. Handoff timeline · Merged PR 353

For a smaller run, follow the nine-item shift that shipped inline editing and row grouping in AdaptTable v1.2.0. Overnight punch list · Merged PR 75

 Install

It installs as a native plugin, with no separate app, service, or API key. It runs on macOS, Linux, and Windows, in any project on your disk: a Git repository, or a plain folder for work that isn't code, such as a research report.

 Claude Code

text
/plugin marketplace add orwa-mahmoud/nightshift
/plugin install nightshift@nightshift


 Codex

sh
codex plugin marketplace add orwa-mahmoud/nightshift
codex plugin add nightshift@nightshift


Then review and trust its hooks, with /hooks in the CLI or, in the Codex app, the Review hooks button (the hook icon in the message box) or Settings → Hooks.

 Cursor

Open Customize → Add → From GitHub Repository, paste https://github.com/orwa-mahmoud/nightshift, select Import, and install Nightshift from the imported marketplace.
