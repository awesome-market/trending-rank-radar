Telegram bot nodes for Node-RED

This package contains a receiver and a sender node which act as a Telegram Bot.
The only thing required is the token that can be retrieved by the @botfather Telegram Bot.

  ⚠ Upgrading from V17 to V18

 V18.0.0 swaps the underlying node-telegram-bot-api library from v0.66 to v1.0.0 — a substantial rewrite that drops several legacy msg.payload.options field names. Existing V17 flows keep working transparently via a built-in compatibility shim that emits a one-time deprecation warning per node and rewrites the field on-the-fly, but the recommended migration target is the new shape. See MIGRATION.md for the full list and rewrite recipes.

 V18 is now the stable release on the latest dist-tag — Manage Palette will offer it as the current version. To upgrade:

 bash
 cd ~/.node-red
 npm install node-red-contrib-telegrambot@latest
 node-red-restart
 

 Requires Node.js = 22.19 (V19 dropped Node 20 — see MIGRATION.md). Node-RED 5 already
 requires Node = 22.9, so a supported Node-RED 5 install is on a new enough Node already.
 To roll back to V18: npm install node-red-contrib-telegrambot@18.1.1.
