Cindy 是一个开源、开箱即用的 AI Agent。连接你的多台电脑与手机，把熟悉的
Agent、模型和已有订阅放在一起，培养一个懂你工作方式的伙伴。

 所有设备，同一个 Cindy。

办公室的电脑、家里的主机、随身笔记本和手机，连在一起用。

- 换屏幕，不换任务。 在另一台设备打开同一个任务，继续对话、访问文件，不用重新搬运资料。
- 不只共享画面，也共享模型。 其他电脑上配置好的订阅、API 供应商和本地模型，开启远程访问后也能调用。
- 手机，也是电脑的遥控器。 内置远程桌面，需要时直接打开应用、输入和操作自己的电脑。

你的电脑，变身免费的服务器，全球畅联。 不用另租服务器，也不必自己搭服务。


连接与数据如何处理

远程访问自己的电脑，需要电脑在线、设备登录同一账号，并开启相应权限。
模型共享需要允许对应供应商被远程调用，远程桌面也有独立的授权与系统权限。
项目文件仍在原电脑上，可远程访问不等于整盘自动同步。云伙伴的对话、记忆、
自有 Skill 和共享附件会通过 Cindy 服务同步；模型供应商会处理发送给它的请求。
模型和服务费用仍按相应规则计费。



 熟悉的 Agent，更顺手的体验。

已经在用 Claude Code 或 Codex？Cindy 把它们和 Pi 放在一起，再加入对交互、
多设备访问、工具协作的理解。

| Harness | 带来的能力 |
| --- | --- |
| Claude Code | 熟悉的 Claude Code 工作方式，接上 Cindy 的界面与工具。 |
| Codex | Codex 的代码工作流，与其他 Agent 在同一个产品里配合。 |
| Pi | 轻量、开源、可扩展，原生支持多种模型供应商。 |

在支持的组合中选择 Harness 和模型，随任务需要切换。任务仍留在 Cindy，
跨 Harness 时会交接或重建引擎上下文，并非把不同引擎的内部状态原样搬过去。

一个不够？让她带队。 把规划、并行执行和独立 Review 交给不同 Agent，
围绕同一个目标和验收标准一起开工。

 在真实工具里，把工作做完。

使用你的文件、浏览器和软件，从交办到检查结果，都在工作的现场。
回答也不只有文字：图表、交互控件和丰富的 HTML 内容，都能出现在对话里。

把重复的事情设成自动化，或者从接入的 Slack、飞书等聊天渠道交办。
通过 Skill、插件和 MCP，继续连接自己的工具与工作方法。

 一开始就好用，任你打扮，任你培养。

- 培养自己的伙伴。 给她角色、指令、Skill 和日常工作：代码审阅、资料研究、项目跟进，都可以有专门的搭档。
- 让经验留下来。 把偏好和知识留在记忆中，把有效的方法写成可复用、可分享的 Skill。
- 把能力接进来。 从 SkillHub 发现 Skill 和插件，连接自己的工具，也可以从官方插件开始开发。
- 一起打磨 Cindy。 审计、fork、改进交互、修复问题，或者贡献一个有用的集成。客户端以 Apache-2.0 开源。

开源，不只是看得见，更是改得动。一起打造 Cindy →

规则使用，软件免费不等于模型调用无限量。

可以离线建立伙伴，并在任何模型推理前完成设置吗？

跳过登录可以在离线时进入桌面端主界面，无需 Cindy 账号。
依赖 Cindy 账号的服务需要登录；已连接的第三方 API 模型仍可使用。

- 从零创建命名伙伴需要可用模型。 在「伙伴 → + → 新建伙伴」中选择实际能运行的模型。
  准备期间会自动启动首次问候，不必等你发送第一条消息；
  运行时受理问候轮次后即标为就绪，不要求等完整回复显示。
- 内置 Cindy 即使已在列表中，也可能仍在等待模型。 首次准备未完成或失败时，
  姓名、简介、性格与「关于我的记忆」仍只读；
  模型设置仍可使用，可通过「更换模型」或重试继续准备同一个伙伴。
- 目前没有受支持的手写声明／零推理建档入口，Linux 国际版 0.1.143 也不支持：
  无法通过这种方式在任何推理前创建命名伙伴、编辑资料、性格和偏好、
  保存，并在重启后读回核对。
- 导入不等于通用声明文本格式。 Hermes／OpenClaw 导入可以先保存识别到的来源应用资料，
  再完成设置；原生伙伴包仅限随安装包提供并经过校验的清单，不接受用户自制包。
- 兼容且实际可用的本地模型仍会推理，包括普通新建伙伴的首次问候；离线不等于零推理建档。

 给开发者

本仓库包含 Cindy 的开源桌面端、手机端及其共享 packages，以 pnpm monorepo 组织。

 本仓包含什么

| 路径 | 说明 |
| --- | --- |
| apps/desktop | Electron 桌面客户端 |
| apps/mobile | Expo / React Native 手机客户端 |
| packages/ | 客户端共享能力（鉴权、device-link、agent 编排、模型供应商等） |
| apps/-bin | 桌面端附带的工具二进制，均不入库；claude-code / codex / ripgrep / pi 由 pnpm install 按平台自动下载，Android platform-tools 在 Windows 打包前按 pin 版本下载并校验 sha256 |

服务端不在本仓库： 服务端位于独立仓库，不属于本 monorepo。

| 使用方式 | 账号要求 | 可用范围 |
| --- | --- | --- |
| 远程托管 | Cindy 云端账号 | 使用 Cindy 的完整托管服务；中国大陆定价 · 国际版定价。 |
| 跳过登录 | 无需登录 Cindy 账号 | 在登录页选择「跳过登录」即可使用本机 agent 功能，应用内显示为「未登录」。依赖服务端的能力在该状态下不可用。 |

 🔑 OpenAI 账号池可合并使用
OpenAI 订阅和官方 API Key 可以并入同一个账号池，系统按模型、额度和可用性自动选号；某个账号额度用完或鉴权失败时，同一会话会交给备用账号继续，设置里可调整顺序、权重与并发上限。 @fmfsaisai
