 项目简介

Ydisks闲鱼助手是一个面向闲鱼卖家的自托管管理系统。它将账号运行、即时消息、订单、
商品、卡密库存、自动化规则、AI 回复和异常通知整合到同一个 Web 管理后台，适合需要
同时维护多个闲鱼账号或交付虚拟商品的个人与小型团队。

项目采用 Go 语言实现闲鱼登录、Cookie 续期、MTOP 请求和 WebSocket 消息链路。
扫码登录、人脸验证流程、消息连接、凭证更新和绝大部分业务逻辑均由 Go 客户端完成。
使用 Chromium 处理必须依赖浏览器环境的相关功能。

 与 Ydisks 网盘拉新助手协同使用

如果你通过网盘资料、教程包或数字资源做闲鱼推广，推荐搭配
Ydisks 网盘拉新助手 使用：先为不同商品、渠道或推广账号
创建独立短链，再在 Ydisks 控制台查看短链与目标页面的 PV、UV、趋势、排行及渠道/账号报表。
这样，Ydisks 负责识别“链接从哪里带来访问与转化线索”，Ydisks闲鱼助手负责承接账号消息、
订单和自动发货，帮助你把投放复盘与日常交付放进一套更清晰的运营流程。

Ydisks 支持管理渠道、推广账号、原始链接、推广短链与域名，适用于网盘拉新和推广投放场景；
可从 Ydisks 网盘拉新助手使用文档 开始创建推广链接并查看数据。


 适用场景

- 多个闲鱼账号的统一在线状态与消息管理
- 数字商品、兑换码、链接或图片内容的自动交付
- 付款后发货、分阶段砍价免拼、评价赠品、超时求评价等自动化流程
- 商品与订单同步、单商品单规格/多规格发布、规格图片与主图排序，以及支持逐行/默认类目、自动识别和最终兜底的表格批量铺货
- 接入 OpenAI 兼容接口实现可控的 AI 客服回复，并可在后台测试完整连接链路

 功能特性

| 模块 | 能力 |
| --- | --- |
| 账号管理 | 多账号启停、扫码登录、资料刷新、在线状态、登录审计与备注管理 |
| 凭证续期 | Cookie/token 定时续期、WebSocket 凭证更新、失效恢复、冷却与失败停用 |
| 即时消息 | 按账号隔离的在线聊天、会话列表与历史消息、闲鱼表情、文本/图片收发、官方系统消息识别、关键词回复（多表达式、包含/正则匹配、多商品范围）、默认回复及仅回复一次；商品首次回复可在买家首次咨询所选商品时自动发送一条预设文字（可附图片） |
| 自动化中心 | 拍下未付款自动改价、付款后自动发货、分阶段砍价免拼、评价后赠品、超时未评价提醒、失败任务恢复、人工处理通知与幂等检查点 |
| 账号自动任务 | 基于本地记录的买家确认收货事实执行自动评价、按北京时间每日擦亮、手动立即执行、执行记录与幂等保护 |
| 卡密库存 | 文本、批量卡密、图片和 API 四种交付类型，库存追加、批量导入、规格与延迟发送 |
| 商品管理 | 商品同步、手工关联、单商品单规格/多规格发布、规格图片与商品图片排序、CSV/XLSX/TSV 与可选 ZIP 批量铺货、关键词获取默认类目、逐行类目优先、自动识别与“电子资料”最终兜底、任务恢复与结果导出；列表同步依据 detailParams.isSKU 判断多规格，字段缺失或为 false 均按非多规格处理，不再访问详情页 |
| 发货模板 | 多条顺序消息、订单/买家/卡密/自定义变量和可复用的自动化发货内容 |
| 资源库 | 可复用的图片库与商品模板，一次发布到多个账号；模板支持从 Excel 导入（单次最多 300 行），批量铺货表格可引用共享发货模板并逐行填写变量 |
| 订单管理 | 订单同步、编辑、未付款订单改价、平台发货、补发卡密、仅确认发货及异常状态处理 |
| AI 回复 | OpenAI 兼容 API、模型发现、完整连接链路测试、“仅砍价”与“全场景客服”模式、商品级启停与专属资料、自定义提示词、议价轮次和让价范围控制，可选向 AI 提供买家本地订单阶段 |
| Agent 回复 | 把未命中关键词的买家消息转发给你自己的外部 HTTP Agent（协议 v1、可选 Bearer Token、支持轮询长耗时回复）并发送其文字/图片回复，可选携带买家订单阶段；Agent 不处理时回落到 AI 与默认回复 |
| 人工介入暂停 | 你在闲鱼 App/网页版或本系统聊天页亲自回复买家后，该会话在设定时间内暂停自动回复（只暂停 AI 或全部）；关键词规则可在买家要求转人工时通知你 |
| 销售统计 | 按时间范围统计营收，与数据看板互补 |
| 浅色/深色主题 | 跟随系统、浅色、深色三种主题，可在侧边栏或移动端“更多”抽屉切换并按浏览器记忆；品牌蓝保持不变，深色大面积背景为纯灰 |
| 运行日志 | 仅管理员可见的内存日志查看页，支持等级、来源与关键词过滤，条目带调用位置、路由、运行与请求 ID 并已脱敏 |
| 请求频率控制 | 账号级 MTOP 节流、遇风控立即中止的有界批次，以及风控后暂停该账号自动评价与擦亮的账号级阻断 |
| 数据看板 | 活跃账号、订单、营收、库存、商品销量与金额统计 |
| 通知告警 | Bark、钉钉、飞书、企业微信、Telegram、邮件和自定义 Webhook |
| 数据存储 | SQLite、MySQL、PostgreSQL，内置按方言执行的 Goose 数据库迁移 |
| 安全能力 | 管理端会话、敏感字段 AES-256-GCM 加密、日志脱敏和出站地址校验 |

 Ydisks 闲鱼助手 v1.0.16 Release Note

 新增

- 新增 Agent 回复：买家未命中关键词的消息可转发到自建 HTTP Agent，回复优先级为关键词、Agent、AI、默认回复，账号页新增“Agent 回复”页签，可保存并测试连接。
- 新增人工接管：人工回复买家后，可暂停该账号的 AI/Agent 或全部自动回复（0–1440 分钟）；关键词规则新增“通知人工”，命中后发送人工客服通知 (109)。
- AI 客服与 Agent 回复可选择获取买家订单阶段，默认关闭，只读本地订单，不含订单号、金额和收货信息 (115)。
- 所有图片回复位置支持从图片库选图：关键词、默认回复、商品首次回复、图片卡密、发货模板图片和在线聊天。
- 订单中心新增未付款订单改价。
- 账号新增“确认发货凭证”设置，可选卡密/模板全文、固定文字或不携带 (113)。
- 批量铺货支持引用共享发货模板，并用“变量.xxx”列逐行填写模板变量 (107)。
- 资源库支持从 Excel 导入商品模板，模板发布不再限制 50 行 (107)。
- 商品发布类目推荐展示完整候选，可改选类目 (111)。
- 模板发布支持选择发货地和类目。
- 新增 API 管理页面，可签发和撤销外部访问令牌；新增商品平台下架接口。感谢 @hehome200 提交 P
