 受够了 Anthropic

作为一个只是想和 Claude 对话与合作的正常用户，受够了折腾各种 VPS，指纹浏览器，环境检测，面对封号的担惊受怕和财产损失。我们提出 Claude Cage 项目：一个开箱即用的桌面程序，配置好自己的网络代理，集中管理隔离环境、时区语言和环境检查。

Claude Cage 在一个小型的 Debian 13 环境里运行官方 Claude Code 和 Claude Desktop，macOS、Windows 和 Linux 上都是同一个环境。终端、浏览器、编辑器和官方 Claude Desktop 汇集在同一个工作台，项目按需共享，网络独立管理；还可以连接自己的服务器，或用手机接续电脑上的任务。支持以下几个重点功能：

- 和主机隔离的网络设置，Cage 自己接管和代理内部的所有网络流量
- 和主机隔离的指纹设置，包括时区、语言等，支持自动与代理 IP 同步
- 针对 Claude 使用过程中的全链路适配（浏览器登录，授权，claude code 进程）
- 内置网络与隔离检查，关键检查失败或证据不完整时暂停外网；社区和第三方检测提供补充参考

 你可以用它做什么

- 在一个窗口里完成工作。 用终端运行 Claude Code，用编辑器查看改动，用 Cage 浏览器预览服务和完成登录。
- 三个平台，同一个环境。 macOS、Windows 和 Linux 上的 Cage 都使用同一个 Debian 13 环境，工具与操作方式一致。 Debian 环境
- 控制共享范围。 只共享默认工作区和明确打开的项目文件夹；主机的 Claude 登录、浏览器配置和 SSH 密钥不会自动导入。
- 看清网络状态。 内置代理管理支持导入订阅、选择节点和检查出口。关键检查未通过时，环境保持离线；代理不可用时没有直连回退。
- 下次继续使用。 工具、文件和登录状态保存在虚拟磁盘里，关闭窗口可以保留后台任务。
- 管理多个 Claude Code 订阅。 查看额度、为新会话分配账号，并在明确授权后切换账号接续历史。 Claude Code
- 从手机继续处理任务。 Android / iPhone 配对电脑，接续 Claude Code 对话与工具审批，或操作远程浏览器和 Claude Desktop。手机连接
- 把环境放到自己的服务器。 通过 SSH 部署或连接 Linux VPS，工具、任务和数据留在服务器，无需 KVM。云端部署与 SSH
- 通过私网连接设备。 在 Cage 内登录 Tailscale，查看网络中的设备，使用 SSH、Web 与其他 TCP 服务。 Tailscale 私网
- 让 Claude 使用电脑上的工具（实验性）。 默认关闭。开启后，环境里的 Claude 可以在已共享的项目目录中运行电脑上的命令，每次调用都需在系统对话框中确认，能力以插件提供。 插件

浏览器收藏、无痕会话、Cookie、扩展、密码保险箱，以及外观、资源、存储和工具更新，见完整使用文档。

 下载与安装

Cage 支持 macOS、Windows 和 Linux：macOS 14+ 的 Apple Silicon Mac、Windows 10 22H2 / 11 x64，以及 Debian 12 / Ubuntu 22.04 / 24.04 x86_64。Intel Mac、Windows ARM64 和 Linux ARM64 暂不支持。 macOS · Windows · Linux。

1. 打开项目主页，点击“下载应用”并选择平台。
2. macOS：打开安装包，将 Cage 拖入 Applications（应用程序），再从“应用程序”启动。Windows：安装说明 · Linux：安装说明。
3. 按应用内引导配置自己的代理，启动环境后打开项目。

安装包随附工作台和代理核心，无需先安装 Go、Node.js、Docker 或 Clash。首次创建环境时选择存储位置，Cage 会下载 Debian 13 镜像和开发工具。Cage 不提供代理服务或 Claude 账户。

源码与安装包公开，版本说明和校验文件见 GitHub Releases。从源码构建工作台需安装 uv，平台工具详见构建说明。环境的要求、镜像来源与数据保留方式见Debian 环境。Intel Mac 的实验性开发构建见 Intel Mac 开发说明。

功能以所用构建为准，公开安装包的能力与验证范围以发行说明为准。

macOS 和已签名 Windows 版本支持通过所选代理更新；Windows 未签名预览版与 Linux 使用安装包手动更新。更新前保存并停止任务，个人数据继续保留。 升级与卸载

 三步开始

 1. 选择代理

导入 Clash/Mihomo YAML 订阅或本地配置，选择节点并点击“应用代理”；需要中转时可配置链式代理。网络与代理

 2. 启动环境

首次启动时选择存储位置，点击“启动 Cage 环境”，按引导完成安装；进度和错误可在“操作详情”查看。以后启动复用原环境。

 3. 打开项目，运行 Claude

点击“打开项目”选择本机上的文件夹，再新建终端，输入 claude，在 Cage 浏览器中完成自己的账户授权。也可以先使用默认工作区，无需提前准备项目。完整步骤见开始使用。

这是 v0.1.8 正式版，包含 v0.1.7 之后合入主线的改动，提供 macOS、Windows、Linux 和 Android 安装包。

 主要改动

- 工作台底部时钟可在“设置 → 通用”切换 12/24 小时制，保存后立即生效，并在重新打开时保留选择。
- 降低原生环境轮询与画面传输开销，优化空闲内存回收。Windows 浏览器画面跟随查看设备的屏幕像素密度，保留清晰度和输入位置的一致性。
- 桌面应用更新支持中断续传和重试，以无数据传输的时长判断停滞。Windows 更新支持可信发布者证书续期；Linux 发现新版时提供发行页入口，仍通过系统包手动安装。
- Android 增加设置页检查更新及下载、校验和系统安装入口。旧 APK 没有“检查更新”时，需要先从官网下载新版并覆盖安装一次。
- 完善 macOS 物理出口网卡筛选、IPv6 安全检查和浏览器硬件渲染参数。图形加速是否生效仍由系统、驱动和 Chromium 决定。
- 同步主线中的项目与账户操作、登录回跳、代理恢复、macOS 屏幕共享入口和 Windows SSH 远程环境改进。
