Coopanion 是一只住在屏幕底边的桌宠，名叫 Coo。它在底边走来走去，用气泡跟你聊天，按住说话键它就能听你说话；你同意的话，它还能看屏幕、点鼠标、敲键盘，帮你操作电脑。Windows、macOS 和 Linux 都能用。

界面有简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español (Latinoamérica)、Português (Brasil)、Italiano、Русский 11 种语言。第一次启动时跟随系统语言，系统语言不在其中就用英文，之后可以在「习惯」页的「语言」里改。Coo 也用界面语言跟你说话。除简体中文和英文外，译文由模型翻译，发现不通顺的地方欢迎提 PR。



 功能

- 支持 DeepSeek、通义千问、Kimi、智谱 GLM、豆包、MiniMax、阶跃星辰、百度千帆、OpenRouter、OpenAI、Anthropic、Gemini、xAI，选一家，贴上 API Key 就能用。也可以登录 ChatGPT 账号，用你的 ChatGPT 套餐。
- 按住说话键说话，或者打字，Coo 在气泡里回你。语音默认在本机识别，也可以交给你配置的转写服务。
- Coo 会记住你。它对你的了解写在 PARTNER.md，更长的记忆按主题和日期整理。电脑上有 Git 时，Coo 改过的文字都留有历史版本；Windows 版自带 Git，macOS 和 Linux 用系统里装的 Git。
- 你允许后，Coo 可以看屏幕、点击、打字、切换窗口。这个功能默认关着，什么时候问你可以自己定；你一动鼠标或键盘它就先停手，按说话键开口能直接打断它。
- Coo 在想事情、看文件、搜索、写东西或操作电脑时，头顶会冒出对应的小图标。
- 形象可以选 Coo，或者 DeepSeek 大肥鱼（会动的鲸鱼娘，八套厂商配色，三套衣服）；别的形象包在「装扮」页导入，见形象包兼容承诺。
- Coo 有奶Coo、灯、杯、铸、心、冬等配色，头顶可以戴帽子、兽耳或光环，耳侧可以挂耳机、耳环或蝴蝶结，还有眼镜和颈饰。桌宠、气泡和字的大小分开调。
- 跟 Coo 说几点或者几分钟后提醒你，它会定好闹钟。
- 在「World 扩展 → 扩展市场」装 World，比如 QQ 机器人、画室和小游戏。
- 可以把 Coo 和气泡导出成 OBS 的「浏览器」来源，背景透明，直播时能叠在画面上。

每个版本改了什么，见 Releases。

 安装

你需要：

- Windows 10 或 11（x64）、Windows 11（Arm64）、macOS 13 及以上（Apple 芯片和 Intel 都行），或者 64 位 Linux 桌面（X11；Wayland 会话里经 XWayland 运行，有Linux一节写的限制；语音识别要 glibc 2.32 及以上，也就是 Ubuntu 22.04、Debian 12 及更新的版本）；
- 一家模型服务的 API Key，按用量付费（见费用与隐私），或者一个开了套餐的 ChatGPT 账号。

每个版本的发布页都附有 SHA256SUMS.txt，可以用来核对下载的文件。

 Windows

- 安装包：从最新发布下载 Coopanion-Setup-版本号.exe 并运行；Arm 处理器的电脑下载 Coopanion-Setup-版本号-arm64.exe。安装包没有数字签名，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。默认装在 %LOCALAPPDATA%\Programs\Coopanion，程序和数据都在这个目录里。别装进 Program Files 这类要管理员权限的目录，Coopanion 在那里写不了数据，会提示后退出。开始菜单里没有它，从桌面图标打开。
- 一行命令：在 PowerShell 里运行

  powershell
  irm https://raw.githubusercontent.com/Pal-AI-Lab/Coopanion/main/installer/install.ps1 | iex
  

  脚本按处理器下载对应的安装包。如果杀毒软件拦下了图形界面的安装，脚本会保留下载好的安装包并打印路径。可以用已下载的安装包加 /S 静默安装，或者先把 Coopanion 加进杀毒软件的白名单再装。
- 便携版：从最新发布下载 Coopanion-版本号-win-x64-portable.zip（Arm 处理器下载 …-win-arm64-portable.zip），解压到任意文件夹，运行 Coopanion.exe。数据放在这个文件夹的 data 里。整个文件夹复制一份就是另一只 Coo，记忆和设置互不影响；安装版和便携版加起来最多同时开 5 只。便携版不会自动更新，升级时把新版解压到新文件夹，再把旧的 data 拷过去。

 macOS

1. 从最新发布下载 Coopanion-版本号-mac-arm64.dmg（Apple 芯片）或 …-mac-x64.dmg（Intel），打开后把 Coopanion 拖进「应用程序」。
2. 应用没有 Apple 开发者签名，也没有经过公证，第一次打开会被拦下。先打开一次，在提示里点「完成」，再到「系统设置 → 隐私与安全性」点「仍要打开」，输入密码确认。
3. Coopanion 的图标在屏幕顶部的菜单栏里，只有打开设置窗口时才会出现在程序坞。

App Store 在前台时，Coo 会退到其他窗口后面，免得挡住购买时的触控 ID 确认。

 [!NOTE]
 第一次用到时，macOS 会分别询问麦克风（语音输入）、输入监控（说话键）、录屏与系统录音和辅助功能（操作电脑）的权限；操作电脑时切换应用，还会请求控制「System Events」。录屏、输入监控和辅助功能改完要重启 Coopanion。更新后 macOS 不会把这些授权沿用到新版本：如果开关开着却提示没有权限，用「−」把 Coopanion 从那个列表里移除，再把 /Applications/Coopanion.app 加回来，然后重启。

 Linux

1. 从最新发布下载 Coopanion-版本号-linux-x64.deb（Debian / Ubuntu）或 Coopanion-版本号-linux-x64.AppImage（其他发行版）。
2. deb：sudo apt install ./Coopanion-版本号-linux-x64.deb。AppImage：先装好发行版提供的 FUSE 2 兼容库，执行 chmod +x Coopanion-.AppImage，再运行它。

Coopanion v0.2.23

Gemini 的默认模型改为 gemini-4-hydrogen;对话页可以一键回到底部;World 设置页可以直接打开扩展详情

 新功能

- Gemini 4 型号:Gemini 的默认模型改为 gemini-4-hydrogen,推荐型号里加入 gemini-4-argon、gemini-4-carbon、gemini-4-neon。四个型号都按多模态处理(能看图、能听「投递录音」发去的录音),都有内置价目;gemini-4-hydrogen 和 gemini-4-neon 的思考强度可以到最高一档。已经建好的 Gemini 端点不会自动修改：想换成 Gemini 4,请修改端点的型号并打开多模态。新默认比原来的默认 gemini-3.5-flash-lite 贵：输入每百万 token 0.30 → 1.50 美元，输出 2.50 → 7.50 美元。
- 对话页「回到底部」:在设置窗口的对话页往上翻看更早的消息后，输入框上方出现「↓ 回到底部」,点击回到最新的消息(感谢 @tokc2327-code)。
- World 设置页直接打开扩展详情:World 设置页的标题旁多了一个 ⓘ,点击打开这个扩展的详情;关闭后回到原来的页面，还没保存的设置仍在(感谢 @kwk1001、@AKIs-z01,754)。
