 从日常管理，到按需精简

TV Studio｜瞎折腾 TV 助手 将 ADB 连接、scrcpy 投屏、APK 安装、文件管理与应用精简整合为一套图形化工作流。日常装软件、在电脑上操作电视，或梳理预装应用，都可以从同一个工作台开始。

支持 Windows、macOS Apple 芯片和 macOS Intel 芯片。应用扫描、分类与 AI 分析帮助你理解设备，具体操作由你逐项复核后决定。

 核心能力

| 能力 | 使用场景 |
| --- | --- |
| 灵活连接设备 | 支持有线、无线 IP 与无线调试配对码连接，保留连接记录，方便再次访问。 |
| 投屏与遥控 | 基于 scrcpy 查看电视画面，支持独立窗口、截屏、录屏，以及方向键、返回和音量控制。 |
| APK 与文件管理 | 导入或拖入 APK，识别应用名称和包名；浏览设备文件，完成日常管理。 |
| 应用扫描与精简 | 快速扫描建立应用清单，深度扫描补全名称；按需停用、卸载或备份 APK。 |
| 桌面管理 | 安装第三方桌面，支持 Aerial 桌面适配，提供原厂桌面 APK 备份入口。 |
| AI 辅助分析 | 支持 API、本地 AI Agent 与 AI 对话文件，通过导出、分析、导回的流程辅助复核应用。 |

 快速上手

 1. 打开电视调试功能

在电视的「设置 → 关于」中找到系统版本、版本号或产品型号，连续点击，直到出现开发者模式提示。随后回到设置，开启 ADB 调试或无线调试。菜单名称与点击次数因设备而异。

 2. 选择连接方式

| 连接方式 | 操作要点 |
| --- | --- |
| 有线连接 | 连接设备后，在 TV Studio 中选择已识别的设备。 |
| 无线 IP | 确保电脑与电视网络互通，输入电视 IP 与 ADB 连接端口。 |
| 无线配对码 | 按电视显示的信息完成配对，再使用无线调试页面上的连接端口建立连接。配对端口与连接端口可能不同。 |

连接时，在电视上确认电脑的调试授权。设备显示已连接后，即可使用投屏、遥控、截屏、录屏、APK 安装或文件管理。

 3. 按需整理电视应用

| 步骤 | 建议操作 |
| --- | --- |
| 扫描应用 | 快速扫描获取清单；需要识别应用名称时，再运行深度扫描。两次扫描更新同一份列表。 |
| 选装新桌面 | 可安装 Aerial 或其他桌面。设为默认后，先在电视上测试主页键是否正常。 |
| 复核并精简 | 按「普通精简」或「深度精简」筛选，也可参考 AI 分析。逐项核对用途，先少量停用并观察，再决定是否卸载。 |
| 处理原厂桌面（可选） | 可备份 APK、卸载或跳过。卸载前，务必确认另一套可用桌面已设为默认；部分设备会限制此操作。 |

扫描、分析与精简任务运行时，仍可使用配对、投屏、截屏、录屏和文件浏览。切换设备前会先结束旧设备上的扫描或分析；已提交的停用、卸载操作会在原设备上完成。

 AI 辅助分析

除了在软件内配置 API 或本地 AI Agent，也可以通过文件与 AI 助手协作：

1. 在「AI 对话分析」中导出任务 JSON。
2. 将文件交给 AI 助手，请其按任务要求返回 JSON。
3. 将结果导回 TV Studio，在应用列表中逐项复核后再操作。

任务文件可能包含设备地址、包名与应用列表。发送给外部 AI 前，请先检查文件内容。

 精简与恢复说明

 扫描分类与 AI 建议均为辅助信息。 不同品牌、型号、固件的系统依赖不同；错误停用或卸载系统组件，可能造成部分功能异常、黑屏或无法进入桌面。

- 保留系统底层、设置、输入法、USB、HDMI、Wi-Fi、遥控、开机引导与恢复等关键组件。被 TV Studio 识别为受保护的组件会拦截停用和卸载。
- 精简前备份重要数据，确认可以重新连接 ADB，并了解设备的恢复方式。APK 备份仅保存安装包，不包含应用数据。
- 对用途不确定的应用，先少量停用并观察。如需同时精简与安装软件，先完成精简，再执行安装。


精简后出现异常，如何恢复？

如果设备仍能连接 ADB，可先从恢复入口尝试撤销最近一次精简，或选择需要恢复的应用。恢复是否成功取决于设备与应用状态。

如果电视已无法进入桌面或连接 ADB，请按照对应品牌、型号的官方说明使用 Recovery。恢复出厂设置会清除设备上的数据与设置，应作为最后手段。

本次更新新增 macOS 客户端，修复 Windows 的自动分类问题，并在安装页加入常用软件和接口配置推荐。

新增常用软件安装
内置 Aptoide TV、Emotn Store、FlClash、Hiddify、盒子伴侣和小白文件管理器等应用。安装页采用图标卡片布局，可按需单独安装。

不同设备的系统依赖可能有差异，自动分类和 AI 建议仅供参考，精简前请自行复核卸载列表。如需精简，请在精简完成后再执行软件安装。
