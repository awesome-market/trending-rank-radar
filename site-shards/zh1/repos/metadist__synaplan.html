Build agents on your own documents and put them wherever work happens: web, WhatsApp, email, Outlook, Nextcloud and ownCloud. Mix local models with the best cloud AI, see what every answer costs, and decide what the AI is allowed to do – open source, on your server or ours.

 Own the flow

The same assistant answers on your website, in WhatsApp, by email, in Outlook and inside Nextcloud and ownCloud. Sensitive work can stay on Ollama. Everything else can go to OpenAI, Anthropic, Google, Mistral or a sovereign EU provider. Every answer shows its model and its price. A planner spends the expensive model only where it matters, and a mail or a ticket goes out only after a person approves it.

It runs in production at a yoga studio (Megaherz Yoga), a care service (SANI Pflegedienst), a public-sector cloud (National Secure Cloud) and an ecommerce solution for custom-made kitchen panels.

 Quickstart

You need: Docker with Compose v2 and 8 GB of RAM.

bash
git clone https://github.com/metadist/synaplan.git
cd synaplan
make up


Open , log in as admin@synaplan.com / admin123 and say hello. Your first message starts the Synaplan Demo – no API key needed (40 messages a day for 14 days, how it works). When you're ready, add your own key (free: Groq) or run local models with Ollama.

The first start downloads everything and takes 5–15 minutes. After that, Synaplan starts in seconds.

 [!IMPORTANT]
 These logins are for trying Synaplan on your own machine. On a server, use the installer – it creates its own admin password.

 Install it your way

| Where | How | Guide |
| --- | --- | --- |
| Published image, no git | One compose.yaml, then docker compose up -d | Published image |
| Docker GUI | Portainer, Dockge, Synology: paste the compose file as a stack | Docker GUI |
| Closed network | No route to the internet, HTTPS on your LAN address | Closed network |
| Linux server | The installer pins a release, generates secrets and runs a smoke test | On a server |
| Kubernetes | Helm charts for clusters | synaplan-charts |
| Coolify | Paste the service file, then Deploy. Not in the Coolify catalog yet | On Coolify |
| One click | RepoCloud · Elestio | – |
| Railway | Optional one-click template for the published image | Deploy on Railway |
| Public sector (EU/CH) | openDesk, Nextcloud and OpenCloud, on-premises or in an EU cloud | synaplan.eu |

A Linux server in one line:

bash
curl -fsSL https://raw.githubusercontent.com/metadist/synaplan/main/install.sh | \
  bash -s -- --mode server --domain https://ai.example.com
