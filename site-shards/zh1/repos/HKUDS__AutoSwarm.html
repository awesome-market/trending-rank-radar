AutoSwarm: All Your Agents. One AI Swarm



https://github.com/user-attachments/assets/89a077a9-168e-441f-8aac-48de321aa968

English

让你常用的 agent，带领多个 agent 协作。

将 AutoSwarm 作为轻量插件接入正在使用的 agent，由它按需组织本地多个 agent 产品协作，负责分工、沟通与结果整合。你只需像往常一样提出任务。

  

  

新：AutoSwarm Desk 桌面版（Windows 和 macOS）。 私人助理、所有 Agent、它们的工作进展和审批，都在一个窗口里。
运行安装程序即可开始：自带 Python，Windows 版会自动更新。了解功能






  


 ✨ 三个适合 AutoSwarm 的场景

- 🧩 跨产品能力互补：任务需要不同 agent 或模型的优势、工具与数据入口时，组织合适的 agent 协作完成。
- ⚡ 大量任务并行处理：例如快速阅读 100 份资料，让多个 agent 并行提炼，再由主 agent 统一汇总；也支持同时调用多个同款 agent。
- 🔍 重要任务一做一审：例如关键代码开发，由一个 agent 实现，另一个独立审查与验证，提高交付质量。

 🚀 开始使用

把本仓库地址发给你正在使用的 agent，直接说：

 请为当前 agent 安装或更新 AutoSwarm，复用已有配置，验证本地已有 agent 的可用性。

配置完成后，主 agent 会告诉你哪些助手已经可以协作。想加入其他助手，直接告诉它名称，它会负责配置和验证。

日常需要 swarm 时，在任务前加上 “使用 autoswarm”，例如：

 使用 autoswarm，阅读这 100 份资料，归纳技术路线与主要分歧。

由主 agent 自行选择协作者、灵活安排串并行。

安装与更新指南——供负责配置的 agent 阅读（点击展开）

 安装

1. 确认当前宿主及已有 Python 3.10+、CLI 安装，复用原生模型、认证、代理和项目上下文。确实缺少所需 CLI 才询问是否安装，只配置需要的 agent。
2. 首次安装使用 git clone 获取官方仓库，再安装包并为当前宿主安装 Skill；已有仓库时直接复用。以 Codex 为例：

   bash
   git clone https://github.com/HKUDS/AutoSwarm.git
   cd AutoSwarm
   uv tool install --force .
   autoswarm setup --host codex
   

   其他宿主标识：claude-code、opencode、cursor、copilot、muse、codebuddy、hermes、nanobot、dsh、grok、kimi。没有 uv 时，在专用 Python 3.10+ 环境执行 python -m pip install .，保留该解释器，不复用归档 v1 环境。
3. 读取 setup 返回路径下的 SKILL.md，其中包含完整启动参数与使用方法。App 找不到 autoswarm 时使用该启动器。在实际宿主环境运行 agents；已有 CLI 不在 PATH 时，将其绝对 argv 合并到返回的 AutoSwarm home/config.json 的 providers..command，用安装程序自己的稳定入口（shim 或固定的可执行文件），不要指向某个版本的文件夹，Agent 自己更新时会删除旧版本；保留无关配置。
4. 在实际项目中验证所需 agent，按实际情况替换示例产品与目录：

   bash
   autoswarm doctor --agent codex --probe --cwd /项目路径
   

   可重复 --agent 选择多个产品。该操作消耗模型调用，检查回复和原生续接；verified: true 才确认本次验证通过。版本检查仅发现可执行文件，原生认证列表为空不代表必须登录。遇到原生批准或提问，按已安装 Skill 的规则处理后完成验证。

Setup 安装 Skill、运行时与宿主集成；按返回说明完成重载和信任操作，再简要列出已验证可协作的助手，并说明用户可以直接提出想接入的助手名称。如果暂时没有可用协作者，提出合适的接入建议；补齐必要安装授权后，由主 agent 配置并验证。原生配置、权限及连接排障见配置与恢复指引。

AutoSwarm Desk 0.1.2 desk-v0.1.2 2026-11-26
What's new in 0.1.2
- A turn no longer stays running after the agent has finished, and Stop always ends it. Before, a process the agent started and left running (a dev server, a watcher) could keep a turn open, and Stop then stayed at "Stopping…" (86). An agent that does not stop within 15 seconds is ended outright.
- A turn that starts after you stop one (a message sent for after the turn) has its own Stop button instead of showing as stopping.
- The private assistant opens at its latest message, and coming back to it from another page shows it where you left it.
