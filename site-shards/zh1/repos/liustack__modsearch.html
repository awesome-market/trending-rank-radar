ModSearch

在官方 App 里模型能联网，切到 API 就不能了。ModSearch 把联网补回来：网页搜索、X 搜索、单页抓取。免费，免注册，免 API key。

🥇 全网最强的 DeepSeek Harness (dsh) 免费联网搜索插件 🥇

DeepSeek 和 GLM 等模型没有联网能力或联网能力羸弱。ModSearch 通过外挂方式大幅增强模型联网搜索、X 搜索、单页抓取能力。装完即用：默认引擎是 Firecrawl 的免注册通道，每月 1,000 免费 credits，不用注册账号，不用 API key，不用绑卡。

 特性

- 🥇 全网最强的 DeepSeek Harness (dsh) 免费联网搜索插件： 一条命令即刻安装 npx -y @deepseek-ai/dsh plugin --profile web add @liustack/modsearch@5.10.14。桌面版「添加插件」里填 @liustack/modsearch，不要填 GitHub 地址。细节见接入指南。
- 开箱免费，免注册。 搜索和单页抓取默认跑在 Firecrawl 免注册通道上：每月 1,000 免费 credits，没有账号、没有 API key、没有绑卡。后备通道也全部免费：Antigravity CLI 只需浏览器登录，Tavily、Exa 和免费的 Firecrawl key 各带独立的月度额度，均不要求绑卡。
- 自动故障转移。 一个通道失败或额度耗尽时自动切换下一个。
- 单引擎多密钥轮换。 Tavily、Exa、Firecrawl、Keenable 都可配置逗号分隔的多个密钥。鉴权、限流或配额失败时先轮换到下一个密钥，再按引擎链故障转移。
- 可搜索 X（推特）。 安装 Grok Build 后，可检索网页索引覆盖不到的 X 内容。
- 一次安装，多端可用。 支持 Claude Code、Codex、Pi、OpenCode。

 支持的引擎

Firecrawl、Keenable 和 You.com 零配置直接可用，其余引擎各一条命令。key 存在 ~/.modsearch/config.json（0600 权限，展示时打码）：

| 引擎 | 能做什么 | 免费额度 | 怎么开 |
| :-- | :-- | :-- | :-- |
| Firecrawl（默认） | 网页搜索 + 单页抓取 | 免注册每月 1,000 免费 credits。注册免费 key 再得独享的每月 1,000 | 无需任何操作，装完即用 |
| Keenable | 网页搜索 + 单页抓取 | 免注册每小时 1,000 次（按 IP 计，同一 IP 上所有人共用）。注册免费 key 得独享的每月 100,000 次 | 无需任何操作，装完即用 |
| You.com | 网页搜索 | 免注册每天 100 次（按 IP 计，同一 IP 上所有人共用） | 无需任何操作，装完即用 |
| Antigravity CLI | 网页搜索 + 单页抓取 | 免费，浏览器登录 | 安装 agy 并登录 |
| Tavily | 网页搜索 | 每月 1,000 credits，不绑卡 | modsearch config set tavily.apiKey  |
| Exa | 网页搜索 | 每月 $10 循环额度（约 1,400 次），不绑卡 | modsearch config set exa.apiKey  |
| Grok Build | X（推特）搜索 | 随 SuperGrok 或 X Premium 订阅 | 安装 grok 并登录 |
| local | 单页抓取 | 内置，零安装 | 无需任何操作 |

key 也可以走环境变量（TAVILY_API_KEY、EXA_API_KEY、FIRECRAWL_API_KEY、KEENABLE_API_KEY）。同一引擎可在配置文件或环境变量中写入逗号分隔的多个 key，例如 key-one,key-two。配了多个引擎就自动故障转移，好的优先。每个引擎默认都参与，可以用 modsearch config set tavily.enabled false 排除一个。想用 Tavily、Exa、Firecrawl、Keenable 兼容的第三方或自建端点？把引擎指过去即可：modsearch config set tavily.baseURL 。官方地址始终内置在代码里，不会作为默认配置写入文件。每个引擎的全部配置项见配置指南。

 安装

第一步，交给你的 AI。 skill 一装好，搜索和单页抓取就跑在 Firecrawl 的免注册免费额度上，所以安装只是一句话：

 按 https://github.com/liustack/modsearch 的 INSTALL.md 安装并配置 modsearch skill，完成后运行体检并把结果告诉我。

DeepSeek Harness (dsh) 里发同一句话即可。INSTALL.md 会认出 dsh，改走原生插件而不是 skill，让 dsh 自带的 web_search 直接跑在 modsearch 上。浏览器版由 AI 直接装好。
