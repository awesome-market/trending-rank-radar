Agent WeChat

English | 简体中文

面向人与 AI 智能体的开源微信客户端。

使用另一款微信桌面客户端、直接在终端中操作，或连接你的 AI 智能体。你可以查看会话、交换媒体文件，并基于同一套 API 构建自己的工具。Agent WeChat 直接与微信通信；其 Daemon 无需官方应用保持运行。

 快速上手

 桌面端应用

1. 从 GitHub Releases 下载适用于你所用平台的安装包。
2. 选择 使用此设备 以运行本地 Hub，或选择 连接到其他 Hub。
3. 添加微信 Profile，并按照手机上的提示完成登录。

应用内置聊天界面、原生 Hub 以及 wx CLI。安装包、系统要求、连接密钥和网络配置，请参阅桌面端指南。各平台的桌面端打包与安装后的验收情况有所不同；请根据你所用的版本，查看平台验收状态和发布说明。

 终端与 API

使用 npm 安装原生 CLI，然后启动其 Daemon：

bash
npm install -g @agent-wechat/cli
wx --json version
wx serve


请允许该软件包的安装脚本运行，以便下载并校验原生可执行文件。其他安装方式包括 pnpm、独立二进制文件和 Docker。如需进行语音和视频预处理，请在运行 Daemon 的主机上安装 FFmpeg 与 FFprobe；桌面应用已内置这两个组件。

如果你已有受支持的 Linux 版微信 官方 Profile，请先关闭官方应用并备份其文件，然后在另一个终端中运行：

bash
wx auth login --official
wx accounts list
wx chats list
wx messages list filehelper --limit 5


Daemon 使用该 Profile 期间，请保持官方应用关闭。如需创建独立的新 Profile，请参阅连接你的账号。新 Profile 不会获取你完整的旧聊天记录。如果有多个账号，请使用 --account ID_OR_ALIAS 选择其中一个。

连接成功后，即可查看会话并保存附件：

bash
wx contacts find Alice
wx messages list CHAT_ID --limit 20
wx messages media CHAT_ID MESSAGE_ID --output ./saved-image.jpg


更多内容请参阅 CLI 示例、API 文档和部署方式。

 微信功能支持

| 领域 | 支持能力 |
| --- | --- |
| 会话 | 支持私聊与群聊；浏览和搜索本地保存的历史记录；查看未读数，并将会话标为已读。 |
| 消息 | 收发文本、图片、视频、文件和语音消息；撤回符合条件的自己发送的消息，并显示收到的撤回通知。 |
| 图片与视频 | 预览并下载可用的画质版本，包括原图和原始视频；发送压缩图片或全分辨率原图，以及普通画质或原始画质的视频。 |
| 语音消息 | 播放收到的语音消息，并将音频发送为原生语音消息。较长的音频可以拆分为多条语音消息；较长语音消息的播放验证仍不完整。 |
| 语音通话 | 在插件中启用语音通话功能后，可通过 wx calls CLI 或 OpenClaw 插件 拨打和接听微信一对一语音通话。桌面端语音通话即将推出。 |
| 富文本内容 | 查看引用消息、链接卡片元数据和合并转发的聊天记录。合并转发会转换为文本；其中嵌套的附件保留为占位符。 |
| 微信视频号 | 接收视频号卡片，查看封面、发布者、描述和时长，并下载视频号视频。 |
| 表情 | 接收表情，包括动态原图。将图片、GIF 和 MOV/MP4 片段保存为自定义表情；调整“我的表情”的顺序或移除其中的表情；浏览并添加符合条件的免费官方表情包，并将表情包导出为 GIF；从“我的表情”或已添加的表情包中发送表情。发送使用 GIF 原图；不支持付费表情包。 |
| @ 提醒 | 发送真实的群成员 @ 提醒，或在允许的情况下 @所有人；解析收到消息中的 @ 提醒元数据。 |
| 好友管理 | 通过微信号查找用户、发送和通过好友申请，以及删除联系人并保留聊天记录。可为每位好友设置「仅聊天」「不让对方看我的朋友圈」和「不看对方的朋友圈」。 |
| 联系人与群聊 | 查找联系人和群聊，搜索群成员，读取群成员列表和头像，并刷新已保存的元数据。 |
| 群管理 | 在账号权限允许的范围内，创建、重命名和退出群聊，添加或移除成员，设置你在群内的昵称，清空群公告，以及设置消息免打扰。部分资料更新仍为局部更新。 |
| 会话管理 | 置顶或取消置顶受支持的会话；开启或关闭普通联系人和群聊的消息免打扰。 |
| 媒体存储 | 为每个账号配置自动下载，保存已校验的媒体文件，并查看传输进度和媒体不可用状态。 |
| 桌面端 | 会话搜索与会话分类、媒体查看、引用消息跳转、@ 选择器、表情选择器、系统原生文件保存、托盘行为和系统通知，界面支持英文和简体中文。平台验收状态见上文。 |
| 自动化 | 使用 wx CLI 或经身份验证的 HTTP API；跟随可重放的事件流，并查看发送和下载任务。 |

媒体的可用性取决于接收来源、支持的格式和大小限制。搜索仅覆盖已保存的历史记录，不包含远端的全部历史。详见消息类型、媒体、表情、群聊和联系人与隐私。

 使用现有的官方 Profile

Agent WeChat 可以直接读取现有的 Linux 版微信官方 Profile（无需迁移），并继续执行受支持的写入操作。它保留账号身份，并使用其中已保存的会话、联系人、群聊和媒体。

| Profile 数据 | 读取 | 写入 |
| --- | --- | --- |
| 消息 | 已保存的历史记录及受支持的富文本内容 | 新收到的消息和已被接受的外发消息；受支持的撤回更新 |
| 联系人 | 已保存的联系人、头像、好友申请记录和隐私设置 | 受支持的同步更新、好友申请记录、联系人删除和隐私设置变更 |
| 群聊 | 群详情、成员列表、群名称和消息免打扰设置 | 受支持的同步字段和群操作结果；部分更新仍为局部更
