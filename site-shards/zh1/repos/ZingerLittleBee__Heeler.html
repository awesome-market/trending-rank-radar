Heeler




在 iPhone 和 iPad 上掌控你自己机器上运行的编程 Agent。

支持 Herdr TUI、Herdr 桌面端（herdr-core）和 tmux，对 Rex 的支持为实验性。










English | 简体中文 | 繁體中文 | 日本語



---

Heeler 是 iPhone 和 iPad 上独立、开源的 Agent 控制台，也是一款 herdr 移动客户端，用于操作 Claude Code、Codex 和其他编程 Agent。Agent 继续在你自己的机器上通过 Herdr TUI、Herdr 桌面端（herdr-core）或 tmux 运行，Heeler 通过 SSH 直连，代码不经过我们的服务器。一眼看出哪个 Agent 在等你，用原生 Chat 或真实终端回复，Agent 进入 Blocked 或 Done 时收到加密通知。

 功能

- Console：所有机器上的 Agent 汇成一个实时列表，Blocked 排最前，可按 Host 过滤。
- Chat：以原生消息阅读 Agent 的对话，用按钮回答 Blocked 的 Agent。支持 Claude Code、Codex、Pi、Oh My Pi、Grok Build、OpenCode 和 Antigravity CLI。Chat 教程
- 实时终端：libghostty 渲染的 Agent 真实终端，支持原生历史回看和选择；也可以在 Agent 的目录打开普通 shell。
- 通知与实时活动：Agent 进入 Blocked 或 Done 时收到端到端加密的推送，锁屏和灵动岛上实时显示 Agent。中继读不到内容。隐私说明
- Usage：Claude Code 与 Codex 的 Usage Limits 及重置时间，最多 30 天的 Token Usage 和估算 API 费用，以及主屏和锁屏小组件。Usage 教程
- Composer：用完整的 iOS 键盘或语音起草，一次 Send 投递。工具键盘提供 Agent 控制键、Skills 和 Snippets，还可以附上照片或最大 64 MiB 的文件。Voice Input 教程
- 随处可连：内置 Tailscale、ZeroTier、EasyTier 和 tailcat，手机无需安装 VPN 应用。不可直连的机器可以走跳板机，一台 Host 可以有多条路由。Overlay Network · 跳板机 · 多条路由
- 其他：扫码配对、Worktrees、查看已暂存和未暂存文件的 Changes、30 个主题，以及支持 Magic Keyboard 快捷键、多窗口和拖放的 iPad 版。

 安装

从 App Store 或 TestFlight 安装 Heeler。机器上需要开启 SSH，并运行下面任意一种后端：

| 后端 | 运行平台 | 教程 |
| --- | --- | --- |
| Herdr TUI | macOS、Linux | 扫码配对 |
| Herdr TUI 0.9.3 及以上 | Windows 原生环境 | Windows 配置 |
| Herdr 桌面端或 herdr-core | macOS、Linux、Windows 原生环境 | 连接 herdr-core |
| tmux 3.3 及以上 | macOS、Linux | 连接 tmux |
| Rex（实验性，需要 0.1.20 之后的 Heeler） | macOS、Linux | 连接 Rex |

 添加机器

先开启机器上的 OpenSSH 服务器（macOS 上是 系统设置  通用  共享  远程登录）。

扫码配对。 在运行 Herdr TUI 的 macOS 或 Linux 机器上（herdr 0.7.5 及以上、Node 20 及以上）执行：

bash
herdr plugin install ZingerLittleBee/Heeler --ref plugin --yes
herdr plugin action invoke heeler.pair


用应用扫描弹出的 Pairing Code，机器即被添加为 Host，地址、host key 指纹和 SSH 密钥一并就绪。机器上没有 herdr、只运行 herdr-core 或 tmux 时，执行 npx -y heeler-pair@latest 可以显示同样的 Pairing Code（需要 Node 20 及以上，以及 0.1.20 之后的 Heeler）。扫码配对教程

或者输入地址。 适用于所有后端。在 Hosts 中轻点 +，输入地址和 SSH 用户，Heeler 会列出这台机器上运行的 Herdr TUI、herdr-core、每个 tmux 服务器和 Rex。一个 Host 可以同时带其中的多个。连接 herdr-core · 连接 tmux · 连接 Rex · Windows 配置

不在同一网络时。 通过内置的 Overlay Network（Tailscale、ZeroTier、EasyTier、tailcat）、跳板机或 Cloudflare Tunnel 连接，并给 Host 配置多条路由，在家和在外都能连上。

 连接原理

Heeler 只需要 SSH 访问和一个运行中的后端：不改服务器，连接本身也不需要额外安装软件包。

- Herdr TUI：经 stream-local 转发直连 herdr.sock，使用 herdr 的 JSON API，终端运行在 SSH PTY 上。OpenSSH 默认允许这种转发，但 Fedora 或 RHEL 上的 SELinux 可能会拦截。
- herdr-core：与 core 的套接字之间只有一条分帧链路。
- tmux：通过控制模式按 Pane 接入，与桌面客户端并存，Agent 状态由 Claude Code 钩子上报。
- Rex（实验性）：与已在运行的 Rex 服务器的套接字之间有一条 WebSocket 链路，每个打开的终端另用一条通道。Heeler 绝不会启动 Rex，Rex 上也没有通知、实时活动和 Usage。
