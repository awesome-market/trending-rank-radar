README

CNEquity · 中国市场金融数据湖
  免注册、免 Token · 复权与 PIT 内置 · 保留退市股 · 行级溯源 · MCP 原生

CNEquity 是开源的中国 A 股本地数据湖：整理沪深京股票行情、公司事件、财务与期货期权数据，面向量化研究、量化交易与回测。86 个数据集经 DuckLake 湖目录原子发布到本地 Parquet，支持按覆盖台账增量续跑，也能通过 MCP 让 AI 直接查 A 股。

 为什么用 CNEquity

和常用取数工具的区别（设计取舍见整体设计）：

| | AKShare | Tushare Pro | Baostock | CNEquity |
|---|---|---|---|---|
| 账号与 Token | 不需要 | 注册 + Token，按积分开放 | 不需要，匿名登录 | 基础采集不需要；可选接入 Tushare 等付费源回填 |
| 数据落盘与增量 | 调用方自己做 | 调用方自己做 | 调用方自己做 | DuckLake 湖目录 + 文件即分区 Parquet，覆盖台账驱动增量与续跑 |
| 退市股与 PIT 财报 | 取决于接口 | 取决于接口 | 部分提供 | 版本化历史股票池保留退市股，财报按披露时点严格 PIT |
| 行级溯源与版本复现 | 无 | 无 | 无 | 每行带 source、data_version、fetched_at，支持固定修订与读取凭证 |
| 给 AI 用 | 自己封装 | 自己封装 | 自己封装 | cne mcp 只读接入 |

 快速开始

需要 Python 3.11+（依赖 DuckDB 2.0+，支持 macOS / Linux / Windows），基础采集不需要账号或 token。小内存或小磁盘机器可先看资源配置建议。

① 一分钟试用。 用真实数据源抓 5 只股票最近 30 个交易日，建在独立目录里，不影响以后的正式湖（离线环境可用 cne init --profile sample 生成合成样例湖）：

bash
pip install cnequity
cne init --profile demo    约 1 分钟；结束时打印行情表、查询示例和接给 AI 的命令
cne serve --config configs/cnequity.demo.toml    在浏览器里打开上面的控制台


② 让 AI 直接查 A 股。 把湖以只读方式接给 Claude、ChatGPT、Codex、Gemini CLI、Cursor、VS Code 等支持 MCP 的客户端（--config 用绝对路径）。以 Claude Code 为例：

bash
claude mcp add cnequity -- cne mcp --config /abs/path/to/configs/cnequity.demo.toml


各家客户端的写法见 MCP 接入指南；ChatGPT 只接公网网址，用 cne mcp --http --token 加隧道接入。然后直接问：「宁德时代最近 30 个交易日的最高收盘价是哪天？」

!在 Claude Code 里通过 cne mcp 查询 A股：宁德时代最近 30 个交易日的最高收盘价

真实 MCP 工具调用与返回；收盘价为未复权价。

③ 建正式湖。 沪深京全市场、最近 3 年：

bash
cne init      开始建正式湖，支持中断续跑
cne check     检查数据是否完整、可用


python
from cnequity.query import load

bars = load("daily_bars", symbols=["600519.SH"])
print(bars.tail())


之后每天运行一次 cne run daily 保持更新。想要更长的历史（cne init --profile full），或了解 init 的范围与续跑方式，见快速开始。

 能用它研究什么

| 你的问题 | 数据与入口 |
|---|---|
| 跨分红、送转后的历史收益 | daily_bars + adj_factors · 行情与复权 |
| 某个调仓日已经知道哪些财报信息 | financial_statement_items · 财报的时点口径 |
| 历史股票池、退市前行情 | instruments、trading_status、delisting_events · 历史股票池与 profile |
| 估值、资金流、行业轮动 | valuation_metrics、资金面与结构数据 · 查询与研究 |
| 期货期限结构、期权链与 Greeks | 逐合约行情和派生数据 · 分钟线与衍生品 |

 数据范围

支持 86 个数据集（78 个采集数据集、8 个派生数据集），按用途分为 L0–L9。支持档位、主键、历史起点和来源见数据集目录与字段与单位。

| 层次 | 研究用途 | 代表数据集 |
|---|---|---|
| L0 | 基础参考 | 证券主数据、交易日历、交易状态、曾用名、可转债与高管资料 |
| L1 | 行情 | 日线、指数、可转债行情、涨跌停价、复权因子、可选分钟线与分笔、退市事件 |
| L2 | 公司事件 | 公司行为、公告索引、业绩预告与披露预约、股东增减持、股份回购、可转债转股与强赎 |
| L3 | 基本面 | 财报、主营构成、估值、股本、股东人数与十大股东、高管薪酬、一致预期与券商预测 |
| L4 | 资金面 | 北向资金与十大成交、融资融券、龙虎榜、游资名录与明细、涨停与连板天梯、筹码分布、大宗交易、资金流 |
| L5 | 结构行业 | 指数成分、行业与板块成分、行业指数 |
| L6 | 宏观 | 宏观指标、市场宽度 |
| L7 | 舆情与轮动 | 新闻、快讯、互动易问答、情绪、人气与最强板块、板块行情与资金流、财经日历 |
| L8 | 风险合规 | 股权质押、解禁日程、监管事件 |
| L9 | 衍生品 | 期货与期权合约、逐合约行情、商品日线、期货会员持仓、连续合约、Greeks、分钟线 |

分钟线、分笔、期货/期权，以及资金流、新闻、人气榜等尽力而为与可选数据集默认关闭，需要时可在配置中打开。

CNEquity 0.25.0 已发布至 PyPI。开源 A 股本地数据湖，用于量化研究、回测与 AI Agent。

bash
python -m pip install --upgrade cnequity==0.25.0


- 升级步骤（不兼容变更）： 升级后运行一条命令：cne upgrade --apply（不加 --apply 先预览）。它先检查这台机器能不能完成升级（湖目录需要的 DuckDB 扩展、磁盘空间），检查未通过时停止迁移并报告原因；然后把湖的记录备份到 backups/upgrade-/，把每个已发布的数据集登记进湖目录、逐行核对，全部一致后才切换，再运行其余还欠的迁移（其中 revision-records 把修订记录导入湖目录，drop-generations 删除旧发布方式留下的目录，不可恢复，见下），全程显示进度。支持硬链接时链接数据文件，否则需要空间复制；中途停下可以重跑，从停下的地方继续。升级完成前 cne run、cne backfill、cne derive、cne repair --apply 都拒绝写入并提示运行 cne upgrade，读取不受影响，定时任务在升级后的下一次运行自动恢复。升级会清理旧布局，需要回退时使用升级前
