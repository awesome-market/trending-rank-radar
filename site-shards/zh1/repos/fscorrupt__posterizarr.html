README

Automated Artwork &amp; Native Dynamic Overlays for Plex, Jellyfin &amp; Emby
  
    Generate consistent posters, seasons, backgrounds, title cards, and collections — while keeping your clean source artwork untouched on disk.

      🎨 Automated Artwork
      Generate matching posters, seasons, title cards, backgrounds, collections, and clearlogos via TMDb, TheTVDB, Fanart.tv, and Plex.
    
    
      ✨ Native Dynamic Overlays
      Import Kometa-style YAML, preview badges live, share portable bundles via the Community Gallery, and composite in memory — no extra container, clean sources untouched.
    
  
  
    
      📺 Plex, Jellyfin &amp; Emby
      Direct sync, real-time WebSocket plugins with optional Plex Direct Sync, AniMetaFill, Asset Title Review, local IMDb ratings, and Plex Image Cleanup. (Silo: experimental)
    
    
      ⚡ Web UI &amp; Automation
      All-in-one Web UI with guided setup, built-in Scheduler, native Tautulli, Sonarr, and Radarr webhooks, Testing Mode, and safe Dry Run.
