README

Don't rewrite it in Rust. Rewrite the 5% that's slow.


  



  
  
  
  
  
  
  


Rewriting a whole app in Rust costs months, minute-long compiles and gigabytes of target/. Most of the runtime sits in a few functions anyway.

fast-anything finds those functions, has your coding agent port only them to Rust, proves the port gives the same results on real recorded calls, and swaps it in. One command, fully reversible.



 Install

sh
npm i -g @el4cteo/fast-anything       or: cargo install fast-anything


Ports are compiled with your Rust toolchain (rustup).

 Use

sh
fast-anything go --agent claude -- python app.py      or: -- node app.ts / bun app.ts / deno run -A app.ts / ruby app.rb / java App.java / mvn exec:java / gradle run / go run . / php app.php / clang -O2 main.c / Rscript app.R


Or step by step:

| command | what it does |
|---|---|
| scan --  | profiles the app, ranks functions by time × how portable they are |
| port [id] | records up to 500 real calls, creates a one-function Rust crate + TASK.md |
| verify | release-builds the port and replays every recorded call |
| enable / disable | swaps the Rust in or out (one marked block, removed byte for byte) |
| bench | times the whole app in rotated rounds of original, original again (an A/A control for noise) and Rust; wall and CPU time |
| report | markdown + SVG card for your PR |
| doctor | checks Rust, your runtimes and your agents |

--agent takes claude, codex, or any command that reads a prompt on stdin. Without it, hand TASK.md to whatever you use.

 Proof, not vibes



That port looked right but compared bytes instead of characters. 148 of 500 real calls caught it. On top of the recorded calls, fast-anything derives extra cases and lets the original answer them: edge cases (NaN, ±infinity, -0.0, zero and ±1, non-ASCII text, empty and up to 16× bigger inputs) and shrunk inputs (tiny and random slices). Nothing is enabled until every case matches: same values (floats within 1e-9 of their size or of the largest value in the same list, -0.0 not 0.0), errors where the original errors. A port that is right but slower per call than the original (calling into Rust costs more than the work saved) isn't enabled either. FAST_ANYTHING_DISABLE=1 runs the original any time.

Every 5th recorded call (from 5 calls up) is held out of the crate folder the agent works in: verify replays it too but reports a mismatch there without the values, so a port that special-cases the calls it was shown still fails.

Real runs on an i5-10500, Windows 11 (C and C++: a 4-core GitHub Actions Linux runner). Reproduce them from examples/.
