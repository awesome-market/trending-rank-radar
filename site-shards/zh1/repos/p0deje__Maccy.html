 Maccy

English | 简体中文




Maccy 是一款轻量级的 macOS 剪贴板管理器。它会保存你的复制历史，让你快速浏览、搜索并再次使用之前复制过的内容。

Maccy 支持 macOS Sonoma 14 及更高版本。

 安装

从 releases 页面下载最新版本，或使用 Homebrew 安装：

sh
brew install maccy


 使用方法

1. 按下 SHIFT (⇧) + COMMAND (⌘) + C 弹出 Maccy，或点击菜单栏中的图标。
2. 输入你想查找的内容。
3. 要选中并复制历史记录中的某个项目，按 ENTER、点击该项目，或使用 COMMAND (⌘) + n 快捷键。
4. 要选中历史记录项目并直接粘贴，按 OPTION (⌥) + ENTER、OPTION (⌥) + CLICK 点击该项目，或使用 OPTION (⌥) + n 快捷键。
5. 要选中历史记录项目并以纯文本（无格式）粘贴，按 OPTION (⌥) + SHIFT (⇧) + ENTER、OPTION (⌥) + SHIFT (⇧) + CLICK 点击该项目，或使用 OPTION (⌥) + SHIFT (⇧) + n 快捷键。
6. 要删除某条历史记录，按 OPTION (⌥) + DELETE (⌫)。
7. 要查看历史记录项的完整文本，将鼠标悬停等待几秒即可显示提示框。
8. 要将历史记录项置顶（固定在列表顶部），按 OPTION (⌥) + P。该项目会移至顶部，并分配一个随机但永久的快捷键。再次按 OPTION (⌥) + P 可取消置顶。
9. 要清除所有未置顶的项目，在菜单中选择 _清除_（_Clear_），或按 OPTION (⌥) + COMMAND (⌘) + DELETE (⌫)。要清除包括已置顶在内的全部项目，按住 OPTION (⌥) 并在菜单中选择 _清除_，或按 SHIFT (⇧) + OPTION (⌥) + COMMAND (⌘) + DELETE (⌫)。
10. 要暂停 Maccy 并忽略新复制的内容，按住 OPTION (⌥) 点击菜单栏图标。
11. 要仅忽略下一次复制，按住 OPTION (⌥) + SHIFT (⇧) 点击菜单栏图标。
12. 要自定义行为，打开“偏好设置…”（Preferences…）窗口，或按 COMMAND (⌘) + ,。

 进阶用法

 忽略复制内容

你可以让 Maccy 忽略所有新复制的项目：

sh
defaults write org.p0deje.Maccy ignoreEvents true  默认为 false


这在你需要走流程复制敏感数据时非常有用。可以先将 ignoreEvents 设为 true，复制完数据后再改回 false。

你也可以按住 OPTION (⌥) 点击菜单栏图标。若只想忽略下一次复制，按住 OPTION (⌥) + SHIFT (⇧) 点击即可。

 忽略自定义复制类型

默认情况下，Maccy 会忽略被视为机密或临时性的特定复制类型。默认列表始终包含以下类型：

 org.nspasteboard.TransientType
 org.nspasteboard.ConcealedType
 org.nspasteboard.AutoGeneratedType

此外，默认配置还包含以下类型，但你可以删除或覆盖它们：

 com.agilebits.onepassword
 com.typeit4me.clipping
 de.petermaurer.TransientPasteboardType
 Pasteboard generator type
 net.antelle.keeweb

你可以在设置中添加其他自定义类型。要查看某个应用使用了哪些自定义类型，可以使用免费工具 Pasteboard-Viewer。下载并打开该应用后，在你想忽略的应用中复制一些内容，然后在左侧边栏查看对应的自定义类型。这里有一个用该方法忽略 Adobe InDesign 的示例。

 加快剪贴板检查间隔

默认情况下，Maccy 每 500 毫秒检查一次剪贴板，这对大多数用户来说已经足够。如果你想加快检查频率，可以通过 defaults 命令修改：

sh
defaults write org.p0deje.Maccy clipboardCheckInterval 0.1  100 毫秒


 常见问题

 在历史记录中选择项目后为什么没有自动粘贴？

1. 请确保已在“偏好设置”中开启“自动粘贴”（Paste automatically）。
2. 请确保已将“Maccy”添加到“系统设置” - “隐私与安全性” - “辅助功能”中。

 设置打开 Maccy 的快捷键时，提示该快捷键已被某项系统设置占用怎么办？

1. 打开“系统设置” - “键盘” - “键盘快捷键”。
2. 找到占用该快捷键的位置。例如，“转换文本为简体中文”（Convert text to simplified Chinese）位于“服务” - “文本”下。
3. 停用该快捷键或移除已分配的组合键（截图参考）。
4. 重启 Maccy。
5. 在 Maccy 设置中重新分配快捷键。

 如何恢复被隐藏的底部菜单？

1. 打开 Maccy 窗口。
2. 按 COMMAND (⌘) + , 打开偏好设置。
3. 在“外观”（Appearance）部分启用“显示底部菜单”。

如果由于某种原因无法生效，请在“终端”中运行以下命令：

sh
defaults write org.p0deje.Maccy showFooter 1


 如何忽略来自通用剪贴板的复制内容？

1. 打开“偏好设置” - “忽略” - “忽略剪贴板类型”。
2. 添加 com.apple.is-remote-clipboard。

 快捷键在密码输入框中失效了，该如何解决？

如果你的快捷键会输入字符（例如 Option+C → “ç”），macOS 的安全机制可能会在密码框中拦截它。可以使用 Karabiner-Elements 将快捷键重新映射为其他组合，如 Cmd+Shift+C。查看
