README

Plugins, agents, and skills for AI coding tools




Use one collection of plugins, agents, skills, and commands across Claude Code, OpenAI Codex CLI, Cursor, OpenCode, Antigravity CLI, GitHub Copilot, and Pi. A harness is the coding tool that loads and runs the components.

Contributors write each component once, in Markdown, in the Claude Code plugin format. Adapters under tools/adapters/ generate the format each harness reads, map model aliases to that harness's models, and translate tool permissions where the harness supports them. CI regenerates the artifacts for every harness, validates them, and runs the OpenCode, Antigravity CLI, and Pi artifacts through their installed CLIs. The capability matrix lists what each harness supports, and ARCHITECTURE.md describes the design.

The catalog contains 94 plugins, including 92 local plugins and 2 external entries. The local source contains 202 agents, 185 skills, and 105 commands. Plugins cover Python and JavaScript development, code review, testing, infrastructure, security, and other work.

 Multi-harness support

Choose the harness you use and follow its setup route. Available components depend on the installation route and the harness's capabilities.

| Tool | Installation | Components and limits |
|---|---|---|
| Claude Code | Plugin marketplace | Source agents, skills, and commands; plugin-specific hooks and MCP configuration |
| OpenAI Codex CLI | Native marketplace or generated artifacts | Native source skills; generated TOML agents and commands as skills use a separate route |
| Cursor | Plugin marketplace | Source agents, skills, and commands, with curated project rules |
| OpenCode | make install-opencode | Generated agents, skills, and commands, with translated tool permissions |
| Antigravity CLI | make install-antigravity | Generated plugins containing agents, skills, and commands |
| GitHub Copilot | make install-copilot | Generated agent profiles and skills; commands also become invocable skills |
| Pi | make install-pi | Generated skills and prompt templates; agents require a subagent extension |

See the capability matrix for model mappings, tool permissions, hooks, and installation differences.

For individual skills, use a skills-only installer and select your coding tool.

 How it works

A plugin groups related agents, skills, and commands under plugins/. For example, python-development contains three agents, sixteen skills, and a scaffolding command. The chosen harness loads the installed components according to its own discovery and invocation rules.

Contributors maintain one Markdown source in the Claude Code plugin format. Native registries point to that source where supported, and adapters generate the formats needed by each harness. Commands may become skills or prompt templates, and agent formats, model choices, and tool permissions vary by harness.
