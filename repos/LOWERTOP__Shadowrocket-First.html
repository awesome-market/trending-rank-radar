 ShadowStore 资源中心

 
 
 ShadowStore 是一个专为 Shadowrocket 打造的开源社区资源聚合检索平台，仓库地址是：ShadowStore，发布页地址是：shadowstore.dpdns.org。发布页提供 资源索引、资源检索、一键安装、一键复制 等功能，集中收录和整理公开资源，目前已收录超过 1000 款模块及其他资源。网页支持添加快捷方式至主屏幕，并提供应用图标显示，为用户提供更加便捷、沉浸的使用体验
 
 相关资源均直接引用自原始开源仓库。特别鸣谢 奶思、zirawell、iab0x00 等开源作者

 Shadowrocket 本仓文件

 [!NOTE]
 
 本章主要是为 特定软件或服务 所制作的模块、规则集等自制内容
 各模块基本都包含有 编辑参数 选项，可 进入编辑参数 进行调整

 Discord 自动翻译

 本模块基于 MITM 机制，自动拦截 Discord 频道与帖子历史消息的拉取接口，智能识别纯外文内容（自动跳过纯表情、链接及已有大段中文的消息），合并后调用 Google 免费翻译接口生成双语对照，支持浏览历史消息及上滑加载。新消息由于走 WebSocket 实时流式长连接，可能需通过重新进入频道触发刷新。支持在 编辑参数 内自定义翻译条目数量与目标语言
 
 

 红果果皮箱

 本模块主要以规则的方式去除 红果短剧 的部分广告并放行可能影响其他应用的地址
 另外提供同时包含 红果短剧、包子漫画网页版 及 小蚁摄像机 等去广告功能的清洁模块
  模块仅为自用，不承诺完全去除相应服务的广告
 
 
 

 携程去广告

 携程去广告模块，纯 jq 实现、无需脚本，过滤携程 App 的开屏广告、首页弹窗和信息流广告，并可拦截广告埋点。支持 编辑参数，开屏、弹窗、信息流等去广告功能均可通过参数独立开关，默认全部开启
 
 

 特来电增强

 阻断开屏广告聚合与各家广告 SDK，屏蔽 App 广告位接口，可选屏蔽福利中心推广位与统计埋点。支持 编辑参数 
 
 

 米家3D打印增强

 本模块以 编辑参数 的方式设置可选隐藏该应用的底部各标签栏，包含 首页、社区、创意、消息 以及 我的 页面。若隐藏 首页 后，进入应用并加载完成后的默认界面将切换至下一个未隐藏的标签页
 
 

 浩辰CAD看图王

 本模块以规则屏蔽的方式拒绝该软件可能用到的广告连接，本模块未使用重写、脚本等需要 MITM 的方式
 
 

 Qing净化增强

 本模块以 编辑参数 的方式构建。可移除开屏广告、阻断火山引擎与 MobTech 隐私追踪、禁用 HTTPDNS；可在编辑参数页面启用本地解锁真实视界、隐身消息配额满载、动态媒体下载解锁及强制透视附近的人隐藏活跃时间等
 
 

 咪咕直播源模块

 群友 "---///"")/" 咨询了一个 APTV 全运营商使用移动咪咕直播源观看 IPTV 的问题。原方案是 PIXMAN 的 Coding 提供的 自制DNS映射 方案，并由 YanG-1989 优化，以解决非移动用户访问咪咕源的错误解析问题。本仓借鉴以上内容制作了本模块，理论上应该支持任意网络环境使用咪咕直播源观看 IPTV。模块提供 编辑参数 功能，包含部分参数调整选项。若使用上存在问题可以尝试在 DNS 覆写 中添加 114.114.114.114

 

 DeepSeek

 DeepSeek 在某些特定地区必须使用手机号注册和登陆使用，本仓提供分流模块和代理规则，可以解锁使用邮箱、谷歌账号等方式注册与登录该服务。同时，模块中屏蔽了部分 存疑 地址，也支持在 编辑参数 内设置分流的代理节点或分组
 
 
 

 Talkatone

 本模块包含去广告规则，能够去除软件内的第三方广告。除模块外还提供 去广告规则集 以及 全局代理规则集
  现阶段 Talkatone 针对使用者 IP 的审查趋于严格，其使用了 xmpp.tktn.be 这个地址对节点进行质量判断，用户可在 编辑参数 内对 节点质量检测 和 代理分流策略 分别尝试不同的代理节点或分组，分流策略默认已设置为代理，原则上可以不做调整，但节点质量检测需要自行测试并设定为特定节点方可正常使用
 
 
 

 Emby分流控制策略

 本模块为 Emby 使用场景设计，基于 Shadowrocket 编辑参数 功能实现。模块对 服务器访问 与 元数据/字幕 请求进行分流控制，旨在同时提升 播放稳定性 与 刮削成功率。同时支持补充最多 3 个非常见的 Emby 服务器域名
 
 模块需要通过 编辑参数  的方式分别指定：
 
  Emby 实际播放、Web、API 请求所使用的策略
  海报、评分、演职员信息、字幕等元数据服务所使用的策略
 
 适用场景包括但不限于：
  Emby 服务器直连、元数据走代理的常见组合
  多 Emby 私服并存的分流管理
  国内外混合字幕 / 元数据源的稳定访问
 
 

 Wi-Fi Calling

 Wi-Fi Calling 相关 测试配置，包含适用于美国、英国等地区 SIM 卡的相关模块和规则集。模块内置有代理分组，使用正则表达式自动将所需的地区节点选取到该分组，并使用 URL-TEST 的类型自动进行节点选择。以下模块均提供 编辑参数 功能，包含部分可选参数调整选项
 
   香港地区：适用于 CSL、CMHK、3 HK 的香港 SIM 卡，可选模块或规则集。相关规则来源于 ous fifty
 
   美国地区：适用于 Ultra Mobile，原则上也适用 T-Mobile 的 SIM 卡，可选模块或规则集
 
   英国地区：原则上适用于 Giffgaff、CMLink 以及沃达丰的 SIM 卡，可选模块或规则集。Giffgaff 的开启条件相对苛刻，查看 官方要求，查看 开启教程，已知 iOS 26 及以上系统因苹果启用更多限制，导致无法单纯通过模块开启 Wi-Fi Calling
 
 
 
 
 
 
 
 

 苹果助手

 本模块以苹果下载加速功能为主，包含 苹果商店下载加速 与 系统升级加速 功能，应该可以改善部分地区下载更新相对缓慢的情况。模块提供 编辑参数 功能，可根据说明自行测试和修改相关参数
