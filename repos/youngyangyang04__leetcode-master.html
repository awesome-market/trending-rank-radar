 🚀 如何使用本攻略

1. 从头开始：按模块顺序「数组 → 链表 → 哈希表 → … → 图论」。
2. 带着问题学：每个模块先看「理论基础」，再刷对应题单。
3. 及时复盘：刷完一个模块，阅读「总结篇」，形成知识闭环。
4. 语言不设限：题解以 C++ 讲解为主，配多语言代码，思路通用。

 建议：新手先刷「数组/链表/哈希/字符串」，再进阶到「二叉树/回溯/贪心/动态规划/图论」。
