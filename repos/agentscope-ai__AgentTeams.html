README

English | 中文 | 日本語

AgentTeams 是一个开源的协作式多智能体运行平台。让多个 Agent 在一个受控、可审计的房间中协作，人类全程可见、随时可介入。采用 Manager-Workers 架构，Manager 统一调度多个 Workers，专注于企业内的人和 Agent、Agents 之间的协作场景。

AgentTeams 不再实现 Agent 运行时本身，而是编排和管理多个 Agent 容器（Manager 和众多 Workers）。
- 🧑‍💻 设计了 Manger-Workers 架构：不用真人去管理每个干活的 Worker Claw，实现由 Agent 管理 Agents。
- 🤝 多运行时协作：OpenClaw、QwenPaw、Hermes 和实验性的 DeepSeek Harness Worker 可以在同一个 IM 房间中协作，并通过 Matrix 保持过程可见。
- 📚 引入 MinIO 共享文件系统：用于 Agent 之间的信息共享，大幅降低多 Agent 协作带来的 Token 消耗。
- ⛑️ 引入 Higress AI Gateway：流量入口和各类凭证风险降低了，减少了用户对原生龙虾在安全上的顾虑。
- 🎨 使用 Element IM 客户端+Tuwunel IM 服务器（均基于 Matrix 实时通信协议）：节省钉钉、飞书 IM 的接入和企业内的审批成本，方便用户快速体验在 IM 的交互环境中体验模型服务的"爽感"，同时支持以 OpenClaw 原生的方式接入 IM。
- 🧬 集成 AgentLoop ：提供 Agent 全栈观测与审计、Agent 评估与实验、Agent 资产管理与持续优化等能力。

AgentTeams 1.2.7 Release Notes

AgentTeams 1.2.7 重点完善一键安装与保留数据升级，统一六种 Harness 的镜像命名和版本，并将 Tracing 扩展为跨 Agent、团队、会话和任务的通用排障能力。默认搭配 Dashboard v1.4.1。

 新增与增强

 一键启动与升级

- 简化本地安装流程，支持先启动工作区，再通过 Dashboard 配置 Manager 模型。
- 完善保留现有数据和配置的升级流程，修复镜像选择、版本检测和 Bash / PowerShell 默认值不一致的问题。
- 默认推荐 Core v1.2.7 与独立版本 Dashboard v1.4.1；保留显式版本、自定义镜像以及不安装 Dashboard 的选择。

 六种共享 Harness

- OpenClaw、QwenPaw、Hermes、DeepSeek、OpenHuman、Codex 统一使用 agentteams-harness-xxx:v1.2.7 镜像，提供 linux/amd64 和 linux/arm64。
- Manager 与 Worker 复用 Harness 镜像，不再发布专用 Manager 镜像。本版本 Manager 支持 OpenClaw 和 QwenPaw，其余四种为 Worker 运行时。
