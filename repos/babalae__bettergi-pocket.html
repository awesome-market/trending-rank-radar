BetterGI Pocket

更好的原神（BetterGI）的 Android 口袋版。通过悬浮球在游戏上方提供屏幕识别、自动对话和地图追踪。

 功能

- 悬浮球：授权后以气泡形式显示在其他应用之上，可拖动、展开面板
- 屏幕共享：捕获游戏画面，用于模板识别（Android 14+ 可选择单个应用）
- 自动对话：识别剧情对话后自动点击选项；可选「快速点击跳过」以点击屏幕下方继续
- 地图追踪：点击开始，在悬浮窗口中筛选、多选路线或整个目录，可执行对应路线的自动采集功能。地图追踪期间请勿人工操作游戏，可能会导致后续所有无障碍点击失效
- 启动原神：打开已安装的客户端，可选在未检测到游戏时自动启动一次

地图追踪设置支持通过可搜索的下拉多选框配置行走位、生存位短／长战技及水、雷、风、火元素采集的候选角色；可调整优先级、清空和恢复默认，按已选顺序匹配当前队伍。队伍通过角色头像识别，要求单人四人队伍。设置说明、标定范围和验证记录见 队伍识别与元素采集。

支持国服官服、Bilibili 服、国际服、云原神及部分渠道服。

地图追踪当前标定来自 3040×1904 的安卓平板，地面采集已实测。其他分辨率、飞行和攀爬仍需验证；适配方法与已知限制见 真机调试经验。挖孔屏及游戏「UI 边界偏移」的适配机制和验证范围见 多分辨率与 HUD 自动锚定。

 使用说明

 两种 arm64 安装包

- 完整版（full）：支持自动剧情和地图追踪，内置「地方特产」路线。
- 剧情版（story）：支持自动剧情，以及屏幕共享、悬浮窗、启动游戏等配套功能；不含地图追踪。

从 Releases 下载所需版本的 APK：

| 安装包 | 功能 |
| --- | --- |
| bettergi-pocket-arm64-story.apk | 自动剧情 |
| bettergi-pocket-arm64-full.apk | 自动剧情 + 地图追踪 |

 首次使用

1. 安装并打开应用，按提示开启悬浮窗权限
2. 先在应用设置中找到 更好的原神 进行单次授权
3. 在系统设置中开启无障碍服务「更好的原神」（用于模拟点击、判断原神是否在前台）
4. 点开悬浮球，打开共享屏幕，在系统弹窗中选择原神画面
5. 按需打开自动对话等开关
6. 使用地图追踪时，点击开始打开路线与设置悬浮窗口。点目录名称进入，勾选目录会选中全部子目录的路线，也可多选单个文件；选好后点击执行，运行期间点击停止结束队列。筛选框使用系统输入法，可直接输入中文目录或路线名，也支持拼音、首字母和编号（拼音需要 Android 10+）；设置页可调整小道具间隔、显示坐标。先确认游戏 UI 与当前标定匹配，且路线上的物品尚未采集

地图追踪设置页可切换默认地图匹配方式（模板匹配 / SIFT，初始为模板匹配）。路线未填写匹配方式或值为空时跟随设置，路线指定的方式优先；路线列表会显示实际算法和来源，坐标显示也使用该默认设置。

自动使用小道具支持独立启用开关，使用间隔可通过系统数字键盘输入秒数（如 0.5），最多 3 位小数。输入后自动保存，关闭开关会保留间隔。

清理后台后若提示无障碍异常，关闭后再重新打开该服务即可。

 常见问题

 遇到“受限制的设置”无法点击？

如果系统提示“受限制的设置”或“出于安全考虑，此设置目前不可用”，请按以下步骤解除限制：

1. 进入应用详情
    - 返回「设置」主页，点击「应用设置」 → 「应用管理」。

2. 找到目标应用（更好的原神）
    - 在列表中搜索并点击打开需要授权的那个应用详情页。 

3. 允许受限制的设置
    - 在应用详情页中，点击右上角的菜单（一般是三个点）或向下滚动，找到并开启 “允许受限制的设置”。

!image\.png

4. 重新授权
    - 返回无障碍页面，即可正常开启该应用的无障碍服务。


 清理手机后再次启动APP无法进行模拟点击？

BetterGI Pocket v1.0.2 v1.0.2 2026-11-08
本次更新

相较于 v1.0，本次新增 Android 地图追踪，并重做悬浮窗与路线管理界面。自动剧情功能继续保留，同时提供剧情版和完整版两种安装包。

地图追踪期间请勿人工操作游戏，可能会导致后续所有无障碍点击失效

 新增功能

- 地图追踪（完整版）：移植 BetterGI 的地图定位与路线执行能力，内置「地方特产」路线，支持自动传送、转向、地面行走、途中拾取与终点停留拾取，可单独开启坐标显示。
- 路线浏览与批量执行：在悬浮窗口中按目录浏览、多选单条路线或整个目录，依次执行选中的路线；支持中文、编号搜索，Android 10 及以上还支持拼音和首字母搜索。执行队列支持定位、移除、清空及撤销清空。
- 队伍识别与角色配置：识别四人队伍，支持按优先级配置行走角色、生存位短按／长按战技，以及水、雷、风、火元素采集候选角色。
- 地图追踪设置：支持模板匹配与 SIFT 切换，路线指定算法优先；支持自动使用小道具的独立开关和自定义间隔。

 界面与体验改进

- 重做主控制面板、路线页、设置页和角色选择页，优化小屏布局、输入法交互、运行进度及日志显示。
- 加入游戏 HUD 自动标定，改善挖孔屏、「UI 边界偏移」和头像位置变化下的识别与触控坐标适配，改善雪景中的主界面识别。
- 修复地图地区面板识别与地区名称匹配；调整地图缩放和拖图流程，先确保普通
