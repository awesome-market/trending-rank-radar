FigCraft


  Interface design and prototyping: open source, collaborative and built in pure Rust.
  Frames, auto layout, components and variants, vector networks, styles, variables and prototypes,
  in a native app that opens instantly and works offline. Open source, and yours.

      🎛️ Familiar by design
      The toolbar, layers panel, Design panel, menus and shortcuts sit right where your hands expect them.
    
    
      ⚡ Native and fast
      A Rust engine with a persistent document model: edits touch only what changed, so creating a node in a 20,000-node file takes a fraction of a millisecond. No Electron, no web view.
    
    
      🔌 Offline and private
      Your files are plain .figcraft archives on your own disk. No account, no telemetry, and nothing leaves your computer unless you share a file (what sharing sends where). SVG, PNG, JPG, WebP and PDF in and out; .fig files open (best effort), and so do designs exported as the public REST API file JSON, with their prototypes and variables.
    
    
      🤖 Agent-ready
      Every menu item, tool and drag is a command, so the same engine runs from the UI, the CLI, a JSON control channel or an MCP server.
