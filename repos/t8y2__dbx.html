 为什么选择 DBX？


  
    
      🪶 25 MB，极致轻量
      无需 Java 运行环境，无需 Python 虚拟环境，不内嵌 Chromium。DBX 是单个小巧的二进制文件——下载、安装、连接。DBeaver 依赖 Java；TablePlus 是 Freemium。DBX 全平台可用，无需额外运行时。
    
    
      🤖 AI 原生集成在编辑器里
      选中一张表，描述你想要什么，直接得到 SQL——无需在工具之间复制粘贴。支持 Claude、OpenAI，或通过 Ollama 使用本地模型。内置安全检查会在执行前审查 AI 生成的 SQL。
    
  
  
    
      🔌 MCP 协议：你的数据库，AI 就绪

DBX v0.6.70 v0.6.70 2026-11-12
新功能

- 侧边栏新增「激活数据库节点时自动展开侧边列表」开关，连接和表较多时可保留侧边树原有展开状态。 (contributed by @GuryYu) (PR 14418)
- 设置 → 导航新增「表节点单击定位，双击新开」选项，开启后单击已打开的表直接切换到对应标签页，双击始终新开。 (contributed by @ThugKd) (PR 14550)
- MongoDB 集合标签页右键菜单新增「复制标签页」，副本打开同一集合并继承筛选、排序等浏览条件，可独立修改。 (contributed by @ThugKd) (PR 14759)
- 数据表格条件过滤新增「不以…开始」和「不以…结束」两个筛选操作符。 (contributed by @xiaou61) (PR 14479)
- 插件工作台新增 copyImage 能力，可将插件生成的 PNG 图片直接复制到系统剪贴板。 (contributed by @CSXFanMeng) (PR 14719)
- SQL Server 自动补全在 FROM/JOIN 之后支持补全表值函数（TVF）。 (contributed by @yiqiui) (PR 13394)
