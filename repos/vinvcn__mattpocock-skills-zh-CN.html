给真正工程师用的 Skills（简体中文版）



Matt Pocock 的 mattpocock/skills：第三方简体中文本地化，非官方仓库。这些 agent skills 是他每天用于真实工程工作的，不是 vibe coding：小、易改、可组合，适用于任何模型。

本仓库定期同步上游，并额外支持 DeepSeek Harness（dsh）插件安装，安装后以 /zh- 调用任意技能（上游没有的能力，详见 dsh-plugin/README.md）。

 30 秒安装


  


bash
npx skills@latest add vinvcn/mattpocock-skills-zh-CN


选择你想安装的 skills，以及要安装到哪些 coding agents。首次安装时请确保选择 /setup-matt-pocock-skills，然后在 agent 中运行它来完成 issue tracker、labels 和 docs 目录配置。

skills.sh 与 plugin 方式每个 agent 只选其一：两种都装会让每个 skill 被安装两次。

或者在 Claude Code 中运行：


/plugin marketplace add vinvcn/mattpocock-skills-zh-CN
/plugin install mattpocock-skills@mattpocock


或者在 DeepSeek Harness（dsh） 中安装为插件（上游没有的安装路线）：

sh
dsh plugin --profile web add @vinvcn/dsh-mattpocock-skills-zh


安装后以 /zh- 调用任意技能，例如 /zh-grilling。详见 dsh-plugin/README.md。

 关于这个中文版

文档和技能说明已翻译；目录名、技能名、命令、代码块、路径和工具标识保持不变，以免破坏安装和运行行为。

中文版本不只是为了阅读方便。对中文母语用户来说，中文说明能减少概念转换成本；对以中文为主要交互语言或中文语料优化的模型来说，中文 prompt 和 skill instructions 也更容易贴合中文上下文，减少中英混杂带来的歧义。

本仓库按内容刷新方式同步上游，不同步上游 Git 历史或仓库管理状态。同步翻译由 Codex 执行，人工审核每一次更新后由维护者通过 PR 纳入 main；维护规则见 .skills/translate-skill/SKILL.md。

翻译策略是 skill-guided content localization：把上游 mattpocock/skills 当作英文内容来源，只翻译自然语言说明，保留目录名、skill name、frontmatter key、命令、代码块、路径、URL、package/tool/API identifiers 和行为关键 labels。用户可见的安装路径统一保持为 vinvcn/mattpocock-skills-zh-CN。

 原版 README 翻译

我每天用于真实工程工作的 agent skills，不是 vibe coding。

开发真实应用很难。GSD、BMAD、Spec-Kit 这类方法试图通过接管流程来帮你。但它们在接管流程的同时，也拿走了你的控制权，并让流程里的 bug 更难解决。

这些 skills 被设计得小、易改、可组合。它们适用于任何模型，背后是数十年的工程经验。你可以 hack 它们，让它们变成自己的东西。

如果你想跟进这些 skills 的更新，以及我后续创建的新 skill，可以加入大约 60,000 名开发者订阅的 newsletter：

订阅 Newsletter

 安装（30 秒 setup）

Plugin 会自我更新；skills.sh 把可编辑文件复制进你的项目，更新由你手动完成。每个 agent 只选一种方式：两种都装会让每个 skill 被安装两次。

 1. 获取 skills


Claude Code

bash
claude plugin marketplace add vinvcn/mattpocock-skills-zh-CN
claude plugin install mattpocock-skills@mattpocock


默认自动更新。上游英文原版位于官方 marketplace（claude plugin install mattpocock-skills@claude-plugins-official）；中文版通过本仓库自己的 marketplace 安装。




Codex

bash
codex plugin marketplace add vinvcn/mattpocock-skills-zh-CN
codex plugin add mattpocock-skills@mattpocock


启动时自动更新。




GitHub Copilot（CLI 与 VS Code）

bash
copilot plugin marketplace add vinvcn/mattpocock-skills-zh-CN
copilot plugin install mattpocock-skills@mattpo
