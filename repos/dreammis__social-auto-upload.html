social-auto-upload

!Python
!License
!Release



social-auto-upload 是一个面向内容创作者和运营者的多平台发布工具，提供统一 CLI 和供 Codex、OpenClaw、Claude Code 等 Agent 使用的 Skill。

支持的视频、文章、图文发布平台及对应入口见下表。

CLI 命令按平台维护在 sau_commands/，发布流程位于 uploader/。日常变更记录见 CHANGELOG.md，稳定版本通过 GitHub Release 发布。
