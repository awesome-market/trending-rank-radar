 什么是 AgentScope Java 2.0？

AgentScope Java 2.0 是面向企业级、分布式、生产环境的智能体框架，提供与模型能力相匹配的核心 Harness 抽象，可支持长期、稳定、安全可控的智能体任务执行。

- 事件系统 → 统一的事件流，32 种类型化事件，服务于前端实时渲染与 human-in-the-loop。
- 权限系统 → 工具调用决策机制：允许 / 用户审批 / 拒绝。
- Middleware → 基于 AOP 模式的 hook 事件拦截机制，灵活扩展推理-行动循环。
- Workspace 与沙箱 → 在隔离环境中执行工具 —— 本地、Docker、Kubernetes 或 AgentRun 云沙箱。
- 多智能体编排 → 多种子智能体定义模式，agent_spawn / agent_send + 事件流实时转发。
- 分布式部署 → 真正的分布式 session 与 memory 管理（Redis / MySQL / PostgreSQL / OSS / COS），跨副本 session 恢复。
- 智能体进化 → 提供 Agent 全栈观测与审计、Agent 评估与实验、Agent 资产管理与持续优化等能力。

 快速开始

 安装

 AgentScope Java 需要 JDK 17 及以上版本。

 Maven

xml

    io.agentscope
    agentscope-harness
    2.0.3



2.0 中模型提供商已拆分为独立扩展模块，需额外引入所需的模型依赖。例如使用 DashScope：

xml

    io.agentscope
    agentscope-extensions-model-dashscope
    2.0.3



其他可选：agentscope-extensions-model-openai、agentscope-extensions-model-anthropic、agentscope-extensions-model-gemini、agentscope-extensions-model-ollama。详见模型文档。

文本和图片的类型化分类可使用 OpenAI Decisions，需要包含该扩展的 2.1.0-SNAPSHOT 构建。

如果希望直接使用 ReActAgent 的推理和工具 API、自行组合工程能力，可依赖 agentscope-core 和所需模型扩展。
