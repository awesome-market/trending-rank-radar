 🐯 平台简介

芋道，以开发者为中心，打造中国第一流的快速开发平台，全部开源，个人与企业可 100% 免费使用。

 有任何问题，或者想要的功能，可以在 _Issues_ 中提给艿艿。

 😜 给项目点点 Star 吧，这对我们真的很重要！

!架构图

 Java 后端：master 分支为 JDK 8 + Spring Boot 2.7，master-jdk17 分支为 JDK 17/21 + Spring Boot 3.5，master-jdk25 分支为 JDK 25 + Spring Boot 4.x
 管理后台的电脑端：Vue3 提供 element-plus、vben(ant-design-vue) 两个版本，Vue2 提供 element-ui 版本
 管理后台的移动端：采用 uni-app 方案，一份代码多终端适配，同时支持 APP、小程序、H5！
 后端采用 Spring Cloud Alibaba 微服务架构，注册中心 + 配置中心 Nacos，定时任务 XXL-Job，服务保障 Sentinel，服务网关 Gateway，分布式事务 Seata
 数据库可使用 MySQL、Oracle、PostgreSQL、SQL Server、MariaDB，以及达梦、人大金仓、瀚高等国产数据库，基于 MyBatis Plus、Redis + Redisson 操作，详见 信创兼容与数据库支持
 消息队列可使用 Event、Redis、RabbitMQ、Kafka、RocketMQ 等
 权限认证使用 Spring Security & Token & Redis，支持多终端、多种用户的认证系统，支持 SSO 单点登录
 支持加载动态权限菜单，按钮级别权限控制，Redis 缓存提升性能
 支持 SaaS 多租户，可自定义每个租户的权限，提供透明化的多租户底层封装
 工作流使用 Flowable，支持动态表单、在线设计流程、会签 / 或签、多种任务分配方式
 高效率开发，使用代码生成器可以一键生成 Java、Vue 前后端代码、SQL 脚本、接口文档，支持单表、树表、主子表
 实时通信，采用 Spring WebSocket 实现，内置 Token 身份校验，支持 WebSocket 集群
 集成微信小程序、微信公众号、企业微信、钉钉等三方登陆，集成支付宝、微信等支付与退款
 集成阿里云、腾讯云等短信渠道，集成 MinIO、阿里云、腾讯云、七牛云等云存储服务
 集成报表设计器、大屏设计器，通过拖拽即可生成酷炫的报表与大屏

v2026.10(jdk25)：扩展信创与多数据库兼容，App 端支持音视频通话，增强系统稳定性 v2026.10(jdk25) 2026-10-31
本月概要：
 【信创】扩展国产数据库接入，补充国产应用服务器与缓存中间件的兼容、接入说明。
 【数据库】完善 PostgreSQL、Oracle、SQL Server 等数据库的 SQL 兼容与初始化脚本。
 【移动端】IM 音视频通话支持 App、微信小程序接入，完善 Android、iOS 运行与打包发布说明。
 【IoT】新增设备影子、消息透传与 JavaScript 数据解析，支持 IoTDB 存储，完善设备状态管理。
 【管理后台】Vue2 完成 19 个业务模块对齐，新增手机确认扫码登录，优化多套管理后台的首屏加载与交互体验。
 【部署与集成】补充 Docker Compose、Kubernetes、Jenkins 部署说明，提供分库分表、分布式事务及限流熔断的可选接入，增加 RustFS 存储配置。
 【稳定性】修复工作流、支付、商城、CRM、MES 等模块的用户反馈问题，完善权限校验、文件下载安全及大整数编号处理。
