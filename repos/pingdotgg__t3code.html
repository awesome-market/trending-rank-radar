T3 Code

The open-source control plane for coding agents.


  Download ·
  iOS ·
  Android ·
  Web ·
  Docs ·
  Discord



  
    
  


T3 Code runs the coding agents on your machine and gives them one fast interface. Start a thread at your desk, then approve the next step from your phone.

It works with Claude Code, Codex, Cursor, OpenCode, Grok Build, Antigravity, Kiro, Pi, Muse Code, fx, and any ACP agent. If an agent is set up on your computer, T3 Code can control it.

 What you get

- Your subscriptions. T3 Code does not resell tokens. It drives the agents you are already signed in to.
- Every agent in one place. Change models in the middle of a thread. Let Claude hand a task to Codex.
- Desktop, web, and phone. One server, and every client shows the same threads. There are apps for iOS and Android.
- Remote ready. Run agents on any machine. Connect over your local network, Tailscale, or T3 Connect.
- Git built in. Each thread can work in its own worktree. Review the diff, then commit, push, and open a pull request with one button.
- Fast. Performance is a feature here. We measure it, and we treat a dropped frame as a bug.
- Open. MIT licensed. If you don't like something, fork it.

 Install

 Desktop app

Download T3 Code for macOS, Windows, or Linux. You can also use a package manager:

| Platform       | Command                                                              |
| -------------- | -------------------------------------------------------------------- |
| macOS          | brew install --cask t3-code                                        |
| Windows        | winget install T3Tools.T3Code or scoop install extras/t3code     |
| Arch Linux     | yay -S t3code-bin                                                  |
| Nix            | nix profile add github:NixOS/nixpkgs/nixos-unstablet3code         |
| Debian, Ubuntu | .deb from Releases |

 Command line

This installs the t3 command. Run t3 to start the server and open the web app.

bash
curl -fsSL https://t3.codes/install.sh | sh


On Windows, in PowerShell:

powershell
irm https://t3.codes/install.ps1 | iex


To try it once without an install, run npx t3@latest.

 Phone

Get the app from the App Store or Google Play. Then follow remote access to connect it to your computer.

 Sign in to an agent

T3 Code needs one agent that is installed and signed in. For example, install Claude Code and run claude auth login, or install Codex CLI and run codex login.

Provider setup has the steps for each agent. Install T3 Code covers nightly builds, AppImage, WSL, and NixOS.

 "Wait, what are you selling me?"

Nothing. We built T3 Code because we wanted the best possible development experience with agents. We were inspired by existing solutions like the Codex desktop app, Conductor, Claude Desktop and Cursor Glass, but none met our bar.
