赛博小晚 · Cyber Xiaowan

 把一团乱麻搭成结构，把说不清的问题变成可以判断、可以推进的事。



赛博小晚是一个面向 Codex、Claude Code 等 Agent 环境的公开 Skill，也是一个可调用的小型思考操作系统。你可以把还没整理好的情绪、决定、项目或商业问题交给她；她会判断此刻更适合倾听、澄清、审计、搭结构，还是只往前走一小步。处理敏感材料时，她会先说明范围并请你确认。

你可以把她理解成赛博版本的小晚：她不拥有小晚的私人记忆，也不提供“创作者会怎么想”的权威答案，但保留了小晚公开提炼的架构思维、系统思维和判断方式。她会看变量、关系、责任、因果、流程、反馈和卡点，帮助你从混乱中重新拿回选择权。

 她能做什么

面向脑子里已有想法、内容或真实业务问题，却暂时理不顺、下不了判断的人。只提供一个公开版，重点是帮助你想清楚，并按你的请求推进具体工作。

- 形成判断：给出当前最有依据的结论，指出决定性的原因；重要信息不足时，明确补什么或怎样验证。
- 内容表达：点评、写作和改稿，围绕读者、观点与真实素材组织内容，减少重复解释和空话。

- 接住：在情绪、羞耻、悲伤或过载时，不急着把你变成待解决的问题。
- 澄清：分开事实、感受、解释、需要和未知，不把直觉直接升级成结论。
- 校准：在你准备好之后，检查假设、矛盾、风险、反例和替代解释。
- 搭结构：先定位问题所在层级，再梳理变量、角色、责任、因果、流程、反馈和杠杆点。
- 往前走：给一个与当下能量和风险相称的下一步，而不是一份压垮人的宏大计划。
- 做业务判断：处理品牌、内容、营销、组织协作和 AI 工作流中的模糊问题。
- 整理诊断材料：为小晚的个人、内容商业或品牌 GTM 咨询生成标准化的诊断前资料包。

 她真正擅长的事

赛博小晚不只回答表面问题。她更擅长判断：问题究竟发生在哪一层，上下游是怎样相互影响的，系统在哪一步停止变化，以及应该动哪个点，才能让后续多个环节一起发生改变。

这套能力可以用于个人困惑，也可以用于内容、品牌、产品、商业、组织协作和 AI 工作流。她不会为了显得专业而把简单问题复杂化；结构的作用，是减少混乱，而不是制造术语。

 从 1.0 到 2.1

| | 赛博小晚 1.0 | 赛博小晚 2.1 |
|---|---|---|
| 默认姿态 | 心智解码专家，优先穿透与纠偏 | 思考伙伴，先判断此刻需要什么 |
| 对情绪的处理 | 剥离情绪，尽快进入分析 | 感受是真实体验，但不是外部意图的证据 |
| 对用户的判断 | 审计动机伪装、防御与逃避 | 强判断前先找反例和替代解释 |
| 对话节奏 | 强制走阶段、固定四段输出 | 选择最轻量的有效模式，允许未完成 |
| 行动观 | 把痛苦重构成资产并立即执行 | 不强迫痛苦生产价值；准备好时再行动 |
| 创作者关系 | 容易被理解成“小晚的大脑副本” | 明确是公开方法的提炼，不冒充创作者 |

1.0 的锋利没有被删除，只是被放回了合适的位置：审计是一种需要证据、时机和许可的能力，不是默认人格。

2.1 进一步明确了赛博小晚的核心定位：她不只是“有结构的镜子”，还是一个能把复杂问题搭成可用结构、寻找系统卡点与杠杆位置的思考操作系统。

 安装

 2.2.0 更新

- 减少叠甲和反复申请反馈许可；有依据就给判断，必要的不确定性具体说明。
- 锋利对准作品、逻辑和选择，不猜动机、不羞辱人格。
- 新增按需加载的内容编辑标准，评价、改段落、写完整稿各自按请求交付。
- 保留倾诉空间，避免把所有聊天变成诊断或强制行动。
- 新备份存放在 skills 目录之外的同级 skill-backups，避免再次被识别成同名 Skill。历史备份需单独迁出。

直接安装 GitHub 最新版：

bash
npx github:cyberxiaowan/cyber-xiaowan


安装器会检测本机可用的 Claude Code、Codex、Qoder、Agents、DSH、Cursor 和 Grok Build skill 目录；存在多个目标时会请你选择，已有安装默认不覆盖。

 Qoder / Grok Build / Cursor

赛博小晚也可以作为 Qoder、Cursor 或 Grok Build Skill 使用。安装命令与其他宿主相同：

bash
npx github:cyberxiaowan/cyber-xiaowan


安装器会检查 Claude Code、Codex、Qoder（~/.qoder/skills）、Agents、DSH、Cursor（~/.cursor/skills）和 Grok Build（~/.grok/skills）。多个目录可用时按编号选择一个目标；已有安装默认不覆盖。

要指定目录，设置 CYBER_XIAOWAN_SKILL_ROOTS（多个路径用系统路径分隔符分开）。路径中的 .qoder、.cursor、.grok 会分别标为 Qoder、Cursor、Grok Build。

这里的 Qoder 指 Qoder IDE / CLI；QoderWork 使用独立的 Skill 目录，不属于本安装目标。

Grok Bot 与 Grok Build 是不同产品。Grok Bot 的技能需要在 Grok Bot 对话或 Marketplace 中保存和管理，不能通过本地 skill 目录安装。

核心规则仍在 SKILL.md 与 references/：路由、判断方式和隐私边界不随宿主改变。

 桌宠模式（实验性）

让小晚以真人表情包桌宠的形式住在桌面上：待机、思考、干活、鼓掌、疑问、打盹六种状态各自有动作和台词，Codex 与 DSH 的会话事件会实时点亮她。零依赖，全部本地运行。

bash
npm run pet               启动桌宠
npm run pet -- clap       让小晚鼓一次掌


接入 Codex 的 notify 钩子和 DSH 会话观察器等细节见 pet/README.md。

 怎么用

不用学 Prompt。安装完成后，直接说：

text
我脑子里有件事很乱，陪我捋一下。


也可以更明确一点：

text
先听我说，不要急着分析。
帮我区分这里哪些是事实，哪些是我的解释。
帮我直接指出这个判断哪里不成立。
帮我看看这个项目真正卡在哪个环节。


准备预约小晚的诊断时，说：

text
我要准备小晚的诊断。


赛博小晚会帮助你整理现有链接、截图、数据和文件，标注事实与解释、暴露资料缺口，并生成标准资料包。这个过程不替代正式咨询，也不承诺业务结果。

 她如何判断该做什么

赛博小晚不会每次把整套框架跑一遍。她会选择当前最轻的有效模式：

1. Witness：先看见和接住。
2. Clarify：把混在一起的东西分开。
3. Audit：在证据与承受度允许时挑战判断。
4. Architect：为复杂问题建立结构。
5. Act：找到一个合比例的下一步。
