ZoneMinder
==========





All documentation for ZoneMinder is now online at https://zoneminder.readthedocs.org

 Overview

ZoneMinder is an integrated set of applications which provide a complete surveillance solution allowing capture, analysis, recording and monitoring of any CCTV or security cameras attached to a Linux based machine. It is designed to run on distributions which support the Video For Linux (V4L) interface and has been tested with video cameras attached to BTTV cards, various USB cameras and also supports most IP network cameras.

 Installation Methods

 Install from a Package Repository

This is the recommended method to install ZoneMinder onto your system. ZoneMinder packages are maintained for the following distros:

- Ubuntu via Isaac Connor's PPA
- Debian from their default repository 
- RHEL/CentOS and clones via RPM Fusion
- Fedora via RPM Fusion
- OpenSuse via third party repository
- Mageia from their default repository
- Arch via the AUR
- Gentoo via Portage Overlays

If a repository that hosts ZoneMinder packages is not available for your distro, then you are encouraged to build your own package, rather than build from source.  While each distro is different in ways that set it apart from all the others, they are often similar enough to allow you to adapt another distro's package building instructions to your own.

 Run with Docker

Official images for amd64 and arm64 are on Docker Hub
as zoneminder/zoneminder, and on the
GitHub Container Registry
as ghcr.io/zoneminder/zoneminder. CI rebuilds them every day from the zmrepo packages.

- latest: the newest release. It moves to each new minor release (1.40, 1.42) when zmrepo publishes it.
- 1.38, 1.38.6 and so on: pin a release series or an exact version.
- dev: nightly builds of master. Don't run them on a system you rely on.
- Each tag has an -es version with the event server (zmeventnotificationNg): latest-es, 1.38-es.

The zmdockerfiles repo has a compose file that runs
ZoneMinder with MariaDB, and an optional object detection container:

bash
git clone https://github.com/ZoneMinder/zmdockerfiles.git
cd zmdockerfiles
cp .env.example .env      set ZM_DB_PASS, MARIADB_ROOT_PASSWORD and TZ
docker compose up -d


Then open http://localhost:8080/zm. File Docker issues in the zmdockerfiles repo.

were published for any distribution. 1.38.6 links stdc++fs where the compiler needs it,
so RPM packages are available again. Debian and Ubuntu packages were unaffected.
