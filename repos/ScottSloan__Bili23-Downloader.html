    开源、免费、跨平台的 B 站视频下载工具




 ⚡ 程序特性

| 特性 | 详细说明 |
| :--- | :--- |
| 🖥️ 跨平台支持 | 完美兼容 Windows（含 Win 7）、Linux 和 macOS 三大桌面操作系统。 |
| 🎨 现代 UI 设计 | 基于 Fluent Design 设计语言，支持浅色 / 深色主题无缝切换，原生适配高分屏，并会记住窗口位置与大小，下次启动自动恢复。 | 
| 🚀 多线程与加速| 原生集成多线程并行下载、断点续传及网络异常自动重试机制，提供极致的下载速率，同时支持全局下载限速。因网络错误失败的任务会自动重新排队重试，间隔逐次延长并显示重试倒计时，可在设置中关闭或调整次数。 |
| 🔗 多类型解析 | 全面支持：投稿视频、番剧、电影、课程、会员购课程、互动视频、音乐（au/am）、UP主空间、收藏夹、每周必看、订阅合集、追番追剧、稍后再看、历史记录等。 |
| 🔍 批量与检索 | 支持一次粘贴多条投稿视频链接批量解析；个人空间、收藏夹、历史记录与稍后再看支持关键词搜索（可选择只筛选当前页或搜索全部内容）；解析完成后还可按预设条件自动勾选下载项；解析记录支持按标题、链接搜索，并可按内容类型筛选。 |
| ⚙️ 音视频自定义| 画质：8K、4K、4K SDR 增强、HDR、杜比视界等 音质：Hi-Res 无损、杜比全景声等 编码：AVC、HEVC、AV1下载前可实时预览本次将要下载的媒体内容，所选编码不存在时会醒目提示实际下载的编码；这些选项也可直接在设置界面中调整并随配置保存。 |
| 💬 弹幕与字幕 | 弹幕：xml、ass、json字幕：srt、lrc、txt、ass、json支持自定义弹幕与字幕样式、指定字幕语言，并可将 ass 格式的弹幕和字幕嵌入 mkv 容器中。 |
| 🖼️ 封面与章节| 无损保存原图质量（jpg、png、avif、webp），原生支持将封面嵌入最终的视频文件（可选嵌入后删除原图），并支持写入视频的章节信息。 |
| 🧩 NFO 元数据 | 自动刮削并生成符合 Kodi、Jellyfin、Emby 等媒体中心标准格式的本地媒体元数据。 |
| 📁 分类与命名 | 内置强大规则引擎，可为投稿视频、番剧、课程、互动视频、收藏夹、个人空间、历史记录、稍后再看、每周必看、音乐等类型分别设置命名模板与多级目录分类存储模式。命名规则采用可视化编辑，一条规则即可同时适配单P与多P视频。 |
| 📦 封装格式转化| 智能音视频流混合提取，支持封装输出为 mp4 或 mkv，充分满足不同播放设备的兼容需求，合并与转换过程实时显示进度。 |
| 📊 下载管理 | 下载列表显示进度百分比与预计剩余时间，以标签展示画质、编码、音质、格式与附加内容；支持按标题、文件名、UP 主、合集名、BV 号搜索，并可按状态与媒体类型筛选，批量操作只作用于当前显示的任务。 |
| 🚫 重复下载检测| 自动记录下载历史，再次下载相同内容时给出提示并可直接跳过，避免重复占用带宽与磁盘空间；解析列表中已下载过的条目会以绿色对勾标出。 |
| 🌐 网络与代理 | 支持不使用代理、使用系统代理、手动设置三种代理模式，首次启动自动检测出口地区以选择合适的 CDN 节点，并支持自定义 User-Agent 与 Host。 |
| 📋 剪贴板监控 | 自动识别复制到剪贴板中的 B 站链接（包括启动前就已复制的链接），确认后即可直接进入解析下载流程。 |
| 🤖 AI 客户端接入 | 内置 MCP 服务器（默认关闭），支持 HTTP 直连与 stdio 桥接，可让 AI 客户端解析链接、创建和管理下载任务，并为单次任务指定画质、音质、编码等下载选项。 |
| 🌍 国际化支持 | 内置多语言界面，开箱可用：简体中文、繁体中文、English。 |
| 🔒 账号安全登录| 支持快捷安全的扫码登录、短信验证登录与 Cookie 登录。 |
| 📖 完全开源免费| 基于 GPL-3.0 协议发布，代码完全开源、无内购、无广告，拥抱社区共建。 |

2.21.0 (2026-10-22)
 新增
- 解析记录支持按标题、链接搜索，并可按内容类型筛选
- 解析列表中下载记录里已有的项目以绿色对勾标出，可在解析列表设置中关闭
- 下载列表显示下载进度百分比与预计剩余时间
- 下载列表以标签显示画质、编码、音质、格式与附加内容，封面角标标明媒体类型与时长
- 下载列表支持按标题、文件名、UP 主、合集名、BV 号搜索，并可按状态与媒体类型筛选；筛选时顶栏的批量操作只作用于当前显示的任务

 优化
- 优化下载列表显示效果
- 文件大小按单位调整显示精度：KB 取整，MB 保留一位小数，GB 保留两位小数

 修复
- 修复使用附带的 FFmpeg 时，仅下载音频无法输出 m4a 文件的问题
- 修复 macOS 上退出程序时崩溃的问题
- 修复从源码运行时检查更新报错的问题
- 修复下载列表中新加入的任务不按所选排序方式排列的问题
- 修复部分 CDN 节点返回错误数据区间，导致下载的视频花屏、音画不同步的问题
- 修复 ASS 弹幕样式中的滚动时长与静止时长设置不生效的问题
