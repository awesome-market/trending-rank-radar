 受够了 Anthropic

作为一个只是想和 Claude 对话与合作的正常用户，受够了折腾各种 VPS，指纹浏览器，环境检测，面对封号的担惊受怕和财产损失。我们提出 Claude Cage 项目：一个开箱即用的桌面程序，配置好自己的网络代理，集中管理隔离环境、时区语言和环境检查。

Claude Cage 让你在熟悉的系统里与 Claude 一起工作：Mac 上用 macOS 虚拟机，Windows 上用 Windows 虚拟机，也可以选择轻量的 Linux 环境。终端、浏览器、编辑器和官方 Claude Desktop 汇集在同一个工作台，项目按需共享，网络独立管理；还可以连接自己的服务器，或用手机接续电脑上的任务。支持以下几个重点功能：

- 和主机隔离的网络设置，Cage 自己接管和代理内部的所有网络流量
- 和主机隔离的指纹设置，包括时区、语言等，支持自动与代理 IP 同步
- 针对 Claude 使用过程中的全链路适配（浏览器登录，授权，claude code 进程）
- 内置网络与隔离检查，关键检查失败或证据不完整时暂停外网；社区和第三方检测提供补充参考

 你可以用它做什么

- 在一个窗口里完成工作。 用终端运行 Claude Code，用编辑器查看改动，用 Cage 浏览器预览服务和完成登录。
- 用熟悉的系统开发。 选择 macOS、Windows 或 Linux 客机，使用对应平台的工具；也可自动匹配本机系统版本，下载官方镜像并创建独立环境。 选择客机系统
- 控制共享范围。 只共享默认工作区和明确打开的项目文件夹；主机的 Claude 登录、浏览器配置和 SSH 密钥不会自动导入。
- 看清网络状态。 内置代理管理支持导入订阅、选择节点和检查出口。关键检查未通过时，环境保持离线；代理不可用时没有直连回退。
- 下次继续使用。 工具、文件和登录状态保存在虚拟磁盘里，关闭窗口可以保留后台任务。
- 管理多个 Claude Code 订阅。 查看额度、为新会话分配账号，并在明确授权后切换账号接续历史。 Claude Code
- 从手机继续处理任务。 Android / iPhone 配对电脑，接续 Claude Code 对话与工具审批，或操作远程浏览器和 Claude Desktop。手机连接
- 把环境放到自己的服务器。 通过 SSH 部署或连接 Linux VPS，工具、任务和数据留在服务器，无需 KVM。云端部署与 SSH
- 通过私网连接设备。 在 Cage 内登录 Tailscale，查看网络中的设备，使用 SSH、Web 与其他 TCP 服务。 Tailscale 私网

浏览器收藏、无痕会话、Cookie、扩展、密码保险箱，以及外观、资源、存储和工具更新，见完整使用文档。

 下载与安装

Cage 支持 macOS、Windows 和 Linux：macOS 14+ 的 Apple Silicon Mac、Windows 10 22H2 / 11 x64，以及 Debian 12 / Ubuntu 22.04 / 24.04 x86_64。Windows 11 客机需要支持 Hyper-V 的 Windows 11 专业版、企业版或教育版主机；其他受支持的 Windows 主机可使用 Debian 或 Ubuntu 22.04。Intel Mac、Windows ARM64 和 Linux ARM64 暂不支持。 macOS · Windows · Linux。

1. 打开项目主页，点击“下载应用”并选择平台。
2. macOS：打开安装包，将 Cage 拖入 Applications（应用程序），再从“应用程序”启动。Windows：安装说明 · Linux：安装说明。
3. 按应用内引导配置自己的代理，启动环境后打开项目。

安装包随附工作台和代理核心，无需先安装 Go、Node.js、Docker 或 Clash。首次创建环境时选择客机系统与存储位置，再准备对应的官方系统镜像和开发工具。macOS、Windows 系统按各自许可使用；Cage 不提供系统授权、代理服务或 Claude 账户。

源码与安装包公开，版本说明和校验文件见 GitHub Releases。系统选择、镜像来源与数据保留方式见客机系统指南。

功能以所用构建为准，公开安装包的能力与验证范围以发行说明为准。

macOS 和已签名 Windows 版本支持通过所选代理更新；Windows 未签名预览版与 Linux 使用安装包手动更新。更新前保存并停止任务，个人数据继续保留。 升级与卸载

 三步开始

 1. 选择代理

导入 Clash/Mihomo YAML 订阅或本地配置，选择节点并点击“应用代理”；需要中转时可配置链式代理。网络与代理

 2. 启动环境

首次选择客机系统或“自动匹配本机系统版本”，再选择存储位置。点击“安装客户机”或“启动 Cage 环境”，按引导完成安装与授权；进度和错误可在“操作详情”查看。以后启动复用原环境。

 3. 打开项目，运行 Claude

点击“打开项目”选择本机上的文件夹，再新建终端，输入 claude，在 Cage 浏览器中完成自己的账户授权。也可以先使用默认工作区，无需提前准备项目。完整步骤见开始使用。

 使用前了解这些边界

- 共享项目中的修改和删除直接影响本机原文件，包括 Git 操作。请使用版本控制或备份，并核对提交结果。
- 同一份 Cage 配置中的项目共用所选客机系统、工具、账户与文件系统，项目之间没有独立隔离。更换客机系统需要独立安装，原环境的数据继续保留。
- 默认公网出站支持 IPv4 TCP，DNS 通过同一代理；公网 UDP、IPv6、ICMP 及主机和局域网直连受限。主动启用 Tailscale 后，可按私网权限连接设备。

 从候选版升级

先保存工作并退出 Cage，再安装对应系统的正式版。继续使用原有配置、账户和客机磁盘。打开工作台后，如果提示更新环境工具，可在“设置 → 环境版本”中完成更新。

- 重新打开已有环境。 基础模板缺失或安装未完成时，已有虚拟机仍可从自己的磁盘启动。创建或重置环境需要可用模板，重置会在停止或删除原环境之前完成这项检查。
- 下载大工具包。 支持分段的服务器最多可用 4 个连接并行下载。中断后可以复用已保存的进度；服务器不支持分段时自动回退为单连接。下载完成后仍会校验整个文件。实际提速幅度取决于线路和服务器限速。
- 在终端使用 GitHub。 新环境默认安装 GitHub CLI，已有环境更新工具后也可使用。在 Cage 终端运行 gh auth login，用自己的 GitHub 账号授权后即可按仓库权限处理提交、PR 和 Issue。终端使用说明
- 安装官方最新 Claude。 Claude Code 和 Claude Desktop 在实际下载安装时解析官方最新版本，已安装的更新版本会保留。下载或验证失败时可修复网络后重试，
