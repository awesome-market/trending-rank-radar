 🎯 Overview

KTransformers is a research project focused on efficient inference and fine-tuning of large language models through CPU-GPU heterogeneous computing. The project now exposes two user-facing capabilities from the kt-kernel source tree: Inference and SFT.

Latest release

KTransformers v0.7.2 v0.7.2 2026-10-15
KTransformers v0.7.2: DeepSeek-V4-Flash LoRA Fine-Tuning

KTransformers v0.7.2 adds LoRA fine-tuning for the April DeepSeek-V4-Flash checkpoint. Routed experts remain in native MXFP4 on CPU, while attention and other non-expert modules run on GPU.

 🚀 Highlights

- Native MXFP4 routed-expert LoRA forward and backward, without expanding the frozen expert weights to BF16.
- LLaMA-Factory SFT integration with checkpoint saving and SGLang adapter inference.
- Python 3.11 and 3.12 Linux x86-64 wheels.
