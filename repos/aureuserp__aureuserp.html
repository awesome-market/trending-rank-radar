 🚀 Introduction

Aureus ERP is a comprehensive, open-source Enterprise Resource Planning (ERP) solution designed for Small and Medium Enterprises (SMEs) and large-scale organizations. Built on Laravel 13, the most popular PHP framework, and FilamentPHP 5, a cutting-edge admin panel framework, Aureus ERP offers an extensible and developer-friendly platform for managing every aspect of your business operations.

Whether you're managing accounting, inventory, HR, CRM, or projects, Aureus ERP provides a modular approach that grows with your business.

   🏗️ Modern Architecture

 📦 Requirements

Ensure your development environment meets the following requirements:

 Server Requirements
-   PHP: 8.3 or higher
-   Database: MySQL 8.0+, MariaDB 10.6+, or PostgreSQL 16+
-   Web Server: Apache 2.4+ or Nginx 1.18+

 Development Tools
-   Composer: Latest version (2.0+)
-   Node.js: 18.x or higher
-   NPM/Yarn: Latest stable version

 Framework Versions
-   Laravel: 13.x
-   FilamentPHP: 5.x
-   Livewire: 4.x
-   TailwindCSS: 4.x
