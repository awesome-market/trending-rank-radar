README

Notion SDK for JavaScript



A JavaScript and TypeScript client for the Notion API. This reference covers the SDK's methods, options, and helpers.

!Build status


 Installation

bash
npm install @notionhq/client




 Usage

 [!NOTE]
 For setup steps, see Notion's getting started guide.

Client accepts an integration token or an OAuth access token.

js
const { Client } = require("@notionhq/client")

const notion = new Client({
  auth: process.env.NOTION_TOKEN,
})


Make a request to any Notion API endpoint.

js
;(async () = {
  const listUsersResponse = await notion.users.list({})
  console.log(listUsersResponse)
})()


 [!NOTE]
 See the complete list of endpoints in the API reference.

Request methods return a Promise with the response. For example:

ts
{
  results: [
    {
      object: "user",
      id: "d40e767c-d7af-4b18-a86d-55c61f1e39a4",
      type: "person",
      person: {
        email: "avo@example.org",
      },
      name: "Avocado Lovelace",
      avatar_url:
        "https://secure.notion-static.com/e6a352a8-8381-44d0-a1dc-9ed80e62b53d.jpg",
    },
    // ...
  ]
}


Endpoint parameters are grouped into a single object. You don't need to remember which parameters go in the path, query, or body.

js
const myPage = await notion.dataSources.query({
  data_source_id: "897e5a76-ae52-4b48-9fdf-e71f5945d1af",
  filter: {
    property: "Landmark",
    rich_text: {
      contains: "Bridge",
    },
  },
})


 Markdown versions

Enhanced Markdown (v1) is deprecated. API versions through 2026-03-11 still default to v1. The next API version will default to v2 and reject requests that specify v1. Notion plans to retire v1 on older API versions about three months after that release.

Set markdown_version: "v2" on Markdown reads and writes now to test your integration before you upgrade. Migrate to Notion-flavored Markdown

js
const { markdown } = await notion.pages.retrieveMarkdown({
  page_id: pageId,
  markdown_version: "v2",
})


 Per-request beta flags

Pass betas to a typed endpoint to opt that call into one or more API betas. The SDK sends the flags in one comma-separated Notion-Beta header. Omitting betas or passing an empty array sends no beta header.

js
await notion.dataSources.query({
  data_source_id: dataSourceId,
  betas: ["status-group-filters-2026-10-06"],
  filter: { property: "Status", status: { group_equals: "In progress" } },
})


This query matches every status option in the “In progress” group. Status group filters beta

TypeScript suggests the current flags known to this SDK. You can also pass a newer flag by its full name and revision date. The API checks whether each flag is valid. Beta versions
