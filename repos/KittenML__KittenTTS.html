README

Kitten-TTS


  



  
  
  
  


  New: Free Kitten-TTS 2 API available at  https://platform.kittenml.com

Kitten-TTS is a series of sota open-source text-to-speech models, built by KittenML. Its flagship model, Kitten-TTS 2, is a
1.7B-parameter 1-bit TTS model with in-context voice cloning and expression control. It provides SOTA quality while being so efficient that it runs realtime on CPUs and consumer GPU's!

The library also ships our existing lightweight V0.8 models,
15M-80M parameters, which run on CPU without a GPU. Both families load through the same
KittenTTS(...) constructor.

Commercial support is available. For integration assistance, custom voices, or enterprise licensing, contact us.

 Features

- Voice cloning -- Clone any speaker from 5-30 seconds of audio, no fine-tuning
- 115 built-in voices -- Including the eight from KittenTTS 0.8
- Multilingual -- 20 languages: English, Arabic, Chinese, French, German, Hindi, Italian, Portuguese, Russian, Spanish, Japanese, Korean, Turkish, Dutch, Swedish, Danish, Finnish, Swahili, Greek, Hebrew
- Expression control -- [emotion] tags, inline  tags, and (((emphasis))) spans
- Decoding presets -- Trade stability against expressiveness per request
- Long-form text -- Sentence-aware chunking with seamless joins
- Text preprocessing -- Numbers, currencies, dates, units and abbreviations expanded automatically
- 24 kHz output -- High-quality audio at a standard sample rate
- Runs without a GPU
- Runs real time on a CPU -- Check Running on CPU
- Optimized C++ inference for CPU -- Our fork of llama.cpp
- Several times realtime on Apple silicon -- Check Running on a Mac

python
m = KittenTTS("KittenML/kitten-tts-2-nano")                     ONNX, int8
audio = m.generate("Guten Morgen.", voice="Paul")               a German voice
m = KittenTTS("KittenML/kitten-tts-2-nano", backend="torch")    PyTorch, float32
