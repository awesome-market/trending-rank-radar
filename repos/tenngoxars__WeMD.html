 功能

写作

- 支持 GFM、表格、代码高亮、数学公式、Mermaid 图表和滑动图组
- 一键格式化：中英文之间加空格、标点转全角、引号转直角引号「」、清理多余空白，每条规则可单独开关
- 搜索替换支持正则和全词匹配

排版

- 内置十余款文章主题，可用可视化设计器调整，也可直接写 CSS
- 预览公众号深色模式下的效果，接近微信实机表现（算法原理）
- 界面支持亮色和深色两种模式

AI 写作辅助

- 选中一段文字改写：润色、精简、口语化、换语气，或输入自定义要求
- 全文审阅：从开头、结构、节奏、表达和结尾五个方面给出修改建议
- 起标题：按多个方向生成标题候选
- 填入自己的 API Key 即可使用，请求从浏览器直接发到服务商，不经过 WeMD。支持 DeepSeek、Kimi、通义千问、硅基流动、模力方舟、OpenAI、OpenRouter 和自定义 OpenAI 兼容服务

发布

- 一键复制到公众号，粘贴后尽量保持预览效果
- 导出 HTML，或按手机宽度导出 PNG 长图
- 图床支持官方图床、七牛云、阿里云、腾讯云和 S3 兼容服务

本地优先

- 文章存放在浏览器或你选择的本地文件夹里，无需注册登录
- 本地文件夹模式支持多级目录，文件树可一键展开或折叠

 开始使用

 在线使用

打开 edit.wemd.app 即可写作，文章只保存在本地。

网页版支持 PWA：在 Chrome 或 Edge 地址栏点击安装图标，就能把 WeMD 安装到桌面或手机主屏，安装后可离线写作（上传图片仍需联网）。

 桌面版

从 Releases 下载对应平台的安装包：

| 平台                   | 安装包                        |
| ---------------------- | ----------------------------- |
| macOS（Apple Silicon） | WeMD--arm64-mac.zip |
| Windows                | WeMD.Setup..exe     |
| Linux                  | WeMD-.AppImage      |

Intel Mac 暂无安装包，可以使用网页版或从源码构建。


首次打开遇到提示？

- macOS 提示「应用已损坏」：在终端执行 xattr -cr /Applications/WeMD.app
- Windows 提示「未知发布者」：点击「更多信息」，再点「仍要运行」
- Linux 无法运行：先设置可执行权限 chmod +x WeMD-.AppImage



 Docker 部署

bash
docker compose pull
docker compose up -d


启动后访问 http://localhost:8080。默认使用 ghcr.io/tenngoxars/wemd-web:latest 镜像，需要固定版本时：

bash
WEMD_IMAGE=ghcr.io/tenngoxars/wemd-web: docker compose up -d


 使用「本地文件夹」存储

浏览器只在 HTTPS 或 localhost 下开放读写本地文件夹的能力，且需要 Chrome、Edge 等 Chromium 内核浏览器。通过 http://服务器IP:8080 访问时，存储模式里的「本地文件夹」不可用，只能使用浏览器存储。

- 部署在自己电脑上：用 http://localhost:8080 访问即可。
- 部署在服务器上，有域名：用 Caddy、Nginx 等反向代理配置 HTTPS。
- 只在局域网使用，没有域名：在 Chrome 打开 chrome://flags/unsafely-treat-insecure-origin-as-secure，填入 http://服务器IP:8080 并重启浏览器。每台电脑需单独设置。

Latest release

WeMD v1.6.1 v1.6.1 2026-11-04
新功能

- 「检查更新」按钮：桌面版侧边栏底部新增「检查更新」按钮，支持手动检查并获取最新版本。

 优化

- 编辑区正文更宽：正文区域最大宽度从 760 px 放宽至 1000 px。窗口拉宽时两侧留白更少，一行可展示更多文字。

 修复

- 阿里云、腾讯云图床自定义域名生效：修复了配置自定义域名后，上传生成的图片链接未采用该域名的问题。已保存的域名无需重新填写。
- 七牛图床移除不可用区域：移除了已不可用的「亚太-首尔」存储区域。此前选用过该区域的用户，打开图床设置时按提示重新选择即可。
- Safari 导出长图不再缺图：修复了在 Safari 等 WebKit 内核浏览器中导出长图时，Mermaid 图表与图片内容可能显示为空白的问题。
- 桌面版不再卡在「正在加载文章」：修复了本地存储异常时，桌面版无法进入工作区的问题。

 变更

- 为升级 v2.0 做好配置迁移准备：下一代桌面端 v2.0 将采用全新轻量架构（安装包将降至 10 MB 以内）。为确保后续升级无缝衔接，v1.6.1 新增了配置自动备份机制。建议在未来升级到 v2.0 之前，先安装并打开一次 v1.6.1，原有的 AI Key、图床及偏好设置将在升级 v2.0 时自动继承。（注：v1.6.1 仍为现有版本架构，正常提供全平台安装包）。
