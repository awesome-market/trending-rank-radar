 👉 新仓库：hlmd/postman-chinese-injector

---

 Postman 怎么设置成中文？（7.x ～ 12.x 通用）

Postman 官方界面只有 English 和日本語，没有中文。要用中文界面，请使用本仓库的接替项目 postman-chinese-injector：

1. 完全退出 Postman；
2. 任选一种方式运行汉化程序：
   - 直接下载：到 新仓库 Release 下载对应平台的可执行文件，运行即可；
   - npm：npx postman-chinese-injector
   - Scoop（Windows）：scoop bucket add hlmd https://github.com/hlmd/scoop-bucket 后执行 scoop install hlmd/postman-chinese-injector
   - Homebrew（macOS / Linux）：brew install hlmd/tap/postman-chinese-injector
3. 重启 Postman，界面就变成中文了。之后可以在「设置 → 通用 → 语言」里切换简体、繁體或英文。

网页版：安装新仓库提供的 Chrome / Edge 扩展。完整说明、常见问题和卸载方法都在 👉 新仓库 README。

 不要再把本仓库的 app.zip 放进新版 Postman：新版的程序结构已经变了，放进去不会生效，还可能导致 Postman 启动异常。

 2.安装中文包

 先决条件
1. 安装Postman
2. 下载对应版本的中文包

 Windows
1. 下载对应版本的 app.zip
2. 进入Postman安装地址/版本/resources目录
    桌面找到Postman应用程序右键 - 打开文件所在位置 再进入app-../resources  
    默认安装地址：C:/Users/用户名/AppData/Local/Postman  
    示例：C:/Users/用户名/AppData/Local/Postman/app-8.8.0/resources  
    !resources目录
3. 复制app.zip到resources目录
    将app.zip解压到当前文件夹 会生成一个app目录  
    进入app目录看到以下图就可以了  
    !app目录
4. 重启Postman就可以了

 操作GIF
!Postman设置为中文


 Mac
1. 下载对应版本的 app.zip
2. 解压 app.zip
3. 进入 访达/应用程序/Postman.app/Contents/Resources/
    进入访达/应用程序找到Postman.app右键查看包内容，再进入Contents/Resources
4. 替换app文件夹
    如果目录下没有 app 文件夹，那么直接解压 app.zip 得到 app 文件夹即可  
    将app.zip解压出来的app文件夹复制到Resources目录，替换原本的app文件夹  
    可以先删除或重命名原本的app文件夹
5. 重启Postman就可以了

 Linux
1. 下载对应版本的 app.zip
shell
 下方为Github地址 将版本号替换为对应版本号，例如：8.8.0
wget https://github.com/hlmd/Postman-cn/releases/download/版本号/app.zip

2. 解压&&替换app文件夹
shell
 Postman安装地址 自行替换
unzip -o -d Postman安装地址/app/resources app.zip
