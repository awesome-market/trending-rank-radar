Tuist

Tuist is a build platform for engineering teams and their coding agents. It works with Xcode, Gradle, Bazel, Elixir, and Rust builds. Features vary by toolchain: Rust compilation caching is experimental, and Once support is in canary.

- 🚝 Cache: Reuse build artifacts across machines and CI.
- ✅ Selective testing: Skip test targets that haven't changed in Tuist-generated Xcode projects. Selecting individual XCTest/XCUITest tests is in early access.
- 📦 Registry: Resolve Swift Package Index packages faster.
- 📈 Build insights: Track your projects, builds, and test runs.
- 📱 Bundle insights: Analyze your built apps and find ways to shrink them.
- 📲 Previews: Share app builds with a link.
- 🗂️ Generated projects: Define Xcode projects in Swift and keep them easy to manage.

 Get started

Read the documentation to install Tuist and set up your first workflow. For questions, join the community forum. Our handbook explains how we work.
