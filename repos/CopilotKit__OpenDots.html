OpenDots

 Always-on AI coworkers that move between text, calls, and Slack.

An open-source template for persistent AI agents, each with its own computer. Available on Web and Mobile.

Built with CopilotKit and AG-UI. · Get started · Overview · Architecture · Features · Contributing




!Alpha



Host OpenDots on your own infrastructure. Conversations require CopilotKit Intelligence: use the hosted service, the local Docker evaluation, or a licensed self-hosted deployment. Clone this template and customize it however you want.

OpenDots is now available as a UX skin in OpenBot, a more robust version with sign-in, per-Bot permissions and an audit trail, maintained by CopilotKit. This repo stays a community-maintained starter for building your own project.

 OpenDots and OpenBot

OpenDots also ships as a skin in OpenBot, CopilotKit's open-source agent platform, alongside OpenMuse and OpenDuet. Pick it there and you get OpenDots's look, with everything OpenBot does underneath.

| If you want to                                                             | Start here                                                                                        |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Try OpenDots, or fork its interface                                        | This repo: Get started                                                            |
| Run it for your team, with sign-in, per-Bot permissions and an audit trail | OpenBot, then Settings → Skin → OpenDots |
| Have us stand it up inside your company                                    | Talk to an engineer  |

OpenDots, OpenMuse and OpenDuet are community maintained, and issues and pull requests are welcome in each repo. OpenBot is the one the CopilotKit team maintains and ships fixes to.

 Overview

OpenDots is a starting point for building your own agent workspace. Clone it, define your Dots, connect your services, and adapt the interface and tools to your needs.

A template, not a hosted product. You run the application and configure its infrastructure. The template is in early development; the Features section below describes what's included and distinguishes local verification from connected-service testing.
