青简 Qingjian

好好输入，顺便多认识一个词。


  
  
  
  
  
  
  
  
  



  
  


青简是一款输入法。你可以像平常一样打字：输入拼音、选择候选、写完整句；候选旁的一条译词，让语言学习自然发生在日常输入里。译词始终只是辅助信息，不会盖过你要输入的文字。

https://github.com/user-attachments/assets/d145fde9-a641-4543-8b15-dd7a2685de3d

视频演示了青简在 macOS 上的整句输入、候选重排和候选译词。

 下载与开始使用

- macOS、Windows：下载青简；安装步骤见使用文档。
- Linux：提供 Fcitx5 和 Fcitx4 源码安装，使用系统默认候选面板；目前需要手动启动后台服务，详见 Linux 安装说明。
- Android：预览版，功能比桌面版少；arm64 的 APK 在 GitHub Releases 下载，启用步骤见 Android 说明，从源码构建见 apps/android。

官方发布渠道：目前只有以下几个，其他地方的「青简」都不是官方发布的。

- 官网下载页
- GitHub Releases
- 每版更新日志里给出的夸克网盘链接

青简目前没有上架任何包管理器。

macOS 与 Windows 版本仍处于测试阶段。安装后先选中青简，在「偏好设置 / 设置 → 通用」选择想学习的语言，就可以开始输入。第一次使用可从第一次输入读起。

 输入时，你会看到什么

text
1  开发        development
2  编程        programming
3  架构        architecture


候选旁一次只显示一种学习语言的译词。目前可以选择英语、日语、西班牙语、越南语或德语，也可以关闭译词显示。青简还支持整句输入、简拼、拼写纠错、双拼、五笔等输入方式；本地整句模型会在停顿后调整句子候选。

「统计」页还会显示今天、最近 7 天和累计的输入量，以及学习语言的词汇记录。详细用法见输入功能、译词与生词、本地统计和按键与快捷键。

 数据与隐私

拼音转换、词库查询、本地模型和输入习惯学习在你的设备上完成。输入量与词汇统计也只保存在本机，不会上传；青简不需要账号。输入日志与统计分开保存，日志可在设置中关闭或清空，不影响统计。检查更新会向官网请求版本列表，可在设置中关闭。

可选的云联想默认关闭。开启后，青简会把当前输入和附近的文字直接发送给你自行填写的 AI 服务商，以获取候选或整句补全；请求不经过青简的服务器。发送范围与本机保存的数据，见数据与日志。

 文档、反馈与参与开发

- 使用文档：安装、设置、输入、卸载与常见问题。
- 反馈问题或建议；也可以加入 QQ 内测交流群。
- 想参与开发？从开发文档和开发约定开始。

青简 0.3.3 v0.3.3 2026-11-07
GitHub 下载慢可以用网盘： 夸克网盘

- 造词更聪明：逐字选一次就记成词，下次打整段或简拼都排第一；分几次选完的整句（20 字以内）也记住；一次就选中的陌生词（几个词拼成、6 字以内，比如 jiaoyizhongxin 的「交易中心」）也记住，下次打 jyzx 直接出（875）
- 简拼第一页就有单字，全拼选过的词打简拼也排前面；记住的整句排在模型生成的整句前面
- 敲左括号、左引号、左书名号时右半边一起补上，光标停在中间，中间打完字再敲右半边会跳过补上的那个；英文模式另有开关、缺省关（Windows、Android，928）
- 中文标点开着也能让指定的符号保持半角，比如写代码常用的反引号   ：在「设置 → 中英文」的「保持半角的符号」里填上（Windows、macOS、Linux，893）
- 打字时可以切到只列单字：Windows 按 Ctrl + D，Android 在展开的候选面板点「单字」，这一段打完自动切回（848）
- 双拼可以同时认全拼，同一段输入里两种打法混着用，在设置里打开（374）
- 越南语 Telex 第三输入法：双击 Shift 在中英与越南语之间切换，候选旁显示中文（Windows、macOS，835）
