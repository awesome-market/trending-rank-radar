Game Cheats Manager

获取更多信息，请访问我们的官方网站 https://gamezonelabs.com。

告别在各类可疑网站中苦苦寻觅，也无需再管理无数的浏览器标签页。Game Cheats Manager (GCM) 将来自多个平台的单机游戏修改器汇集到一个干净整洁且开源的面板中。支持中英文双语搜索，一键下载，剩下的全部交给应用自动处理。

---

 核心功能

 多源合一，尽在一个应用
获取社区中最值得信赖的修改器，告别死链失效的烦恼：
 风灵月影: 行业标杆，修改器界最广为人知的来源。
 小幸姐: 专注于国产/亚洲游戏，通常提供更为高级的功能。
 CE 脚本 (CT 表): 庞大的 Cheat Engine 脚本社区资源库，涵盖海量游戏。
 GCM 专属: 我们亲自制作和整理的开源修改器，专为一些相对小众的游戏提供。
 社区上传: 由我们的用户直接提交的修改器。无论你是自己制作的还是发现了我们未收录的资源，经过人工安全审核后，所有人都能立即使用。

 双语即时搜索
输入中英文游戏名称即可立即查看结果。数据在本地跨所有来源同步，无延迟按来源或游戏进行筛选。

 双击即可下载
找到心仪的修改器了？双击即可。GCM 将处理一切后续工作：下载文件、解压、标记版本，并将其整理归档到独立命名的文件夹中——同时还能智能防止重复下载。

 每次启动自动更新
游戏一更新，修改器就失效？GCM 会在每次启动应用时于后台静默检查更新，确保你的修改器库始终保持最新状态。

 Windows Defender 智能白名单
由于修改器会修改游戏内存，经常会触发杀毒软件的误报。GCM 内置了一键白名单助手，安全地将你的修改器文件夹添加到 Windows Defender 的排除项中，防止文件被误删。

 反作弊智能提示
对于部分包含反作弊机制的单机游戏，GCM 能够自动识别，并在下载完成后立即为你提供详细的绕过步骤说明。

 社区驱动
制作了自己的修改器？或者发现了我们遗漏的宝藏？直接通过应用一键上传。经过安全审核后，你的贡献将面向整个社区发布。

---

 安装指南

1. 前往我们的 最新发布 (Latest Release) 页面。
2. 下载最新的 Windows (64位) 安装包。
3. 运行安装程序并按照屏幕上的指示进行操作。
4. 启动 GCM，开始你的游戏之旅！

---

 进阶使用与选项

虽然 GCM 的设计理念是开箱即用，但你完全可以通过应用内菜单掌控你的体验：

 修改器管理: 启用/禁用各个来源，并配置修改器和数据文件的自动更新。
 本地导入: 电脑里已经存了一大堆修改器？直接将它们导入 GCM (注：手动导入的修改器不支持自动更新)。
 自定义路径: 更改修改器的保存位置，并在应用内一键打开下载目录。
 个性化设置: 调整应用主题、语言，并查看与项目相关的链接。

---

 支持与反馈

如遇问题、有新功能建议或希望参与贡献，请访问 Issues 页面，或通过 Discord/QQ（链接见页面顶部）加入我们的社区。

注：所有修改器严格且仅限用于单机游戏模式。
