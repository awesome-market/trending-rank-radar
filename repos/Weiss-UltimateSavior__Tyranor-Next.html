README

基于 Tyranor 模拟器逆向重写 的多引擎视觉小说（Galgame）模拟器，面向 Android 平台。具体功能与兼容边界见 SPEC.md。

游戏页搜索栏旁的筛选按钮可按引擎类型和游玩状态筛选标题搜索结果，或按字母、括号标签、引擎、最近游玩排序；筛选按钮与搜索栏随列表滚动一起收起，滚回顶部后一起显示。筛选与排序会保留到下次启动；筛选抽屉会按横竖屏可用高度调整。

内置引擎播放器及游戏视频窗口固定为标准横屏，不随设备旋转或 180° 翻转；Artemis 不再提供反向横屏选项。外置播放器的窗口方向最终由对应 APK 控制。

内置引擎宿主共用黑底、主题色转圈的启动加载界面。各宿主在其窗口内容可呈现后退出加载，启动失败时提示返回重试；外置 APK 引擎和模拟器只负责交棒。实现边界与验收见 统一启动加载计划。

一级页面（首页、游戏、引擎、设置）保留原有标题栏；二级页面统一提供加粗返回箭头和标题，支持点击返回与系统返回手势。

「应用设置 → 界面动效」可即时切换增强（默认）与普通。增强档提供页面水平侧推、列表与控件弹簧反馈、浮层景深和提示胶囊；普通档保留原有转场。Android 14 / API 34 及以上支持通过主界面左缘系统返回唤出侧栏；较低版本的系统返回沿用原有离页行为，仍可用页面内左缘右滑打开侧栏。

输入框聚焦时保留前导图标回弹，文本区域不参与缩放，避免粉色水滴光标柄反复闪现；仍支持点击定位、长按选词和拖动选择柄。

普通与增强动效均保持叠层弹窗的背景遮罩连续：关闭确认框返回管理弹窗，以及侧栏、封面搜索、裁剪之间的窗口交接，不会因上层遮罩退场而短暂露出全亮背景。嵌套窗口开始关闭时，下层面板立即恢复亮度，页面遮罩由下层继续保持，无需等待上层退场结束。

抽屉上再开弹窗时，抽屉面板会被遮罩，底层页面维持原暗度；关闭上层后立即恢复抽屉亮度。

设置主页面的扫描卡片在扫描深度滑杆下方提供「外观主题」切换，选择后即时生效并持久化。

内置引擎游戏的累计时长仅在首页最近打开卡片的标题下方左对齐显示，采用最多一位小数的小时格式（如 0.1h、100h），格式化后为 0h 时隐藏，底部文字遮罩保持原高度；按前台运行时间记录，切后台及锁屏暂停；加载、标题菜单、自动播放和游戏内视频计入，历史时长不补算。外置引擎、模拟器和安卓游戏不统计。
