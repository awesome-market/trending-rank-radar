 Surya

Surya is a 689M param document OCR and layout VLM with these features:

- Accuracy - scores 85.9 on OmniParseBench, the highest of the open models under 1B parameters we have scored, and 83.7% on olmOCR-bench
- Speed - throughput of 4.5 pages/s on one H100 at 192 DPI, 1.7x Surya 2 with MTP (see Throughput)
- Multilingual - scores 74.9% on an internal benchmark set of 91 languages (more here)
- Layout analysis (Table, Picture, SectionHeader, Equation, Form, etc.) with reading order and token-count estimates
- Tables as HTML (, , , ) with merged cells as colspan / rowspan
- Zero heavy local ML dependencies - surya-ocr is a lightweight client/orchestrator that talks to vllm (Docker / Podman), llama-server (llama.cpp), or mlx_vlm.server (Apple Silicon)
