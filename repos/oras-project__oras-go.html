ORAS Go library





oras-go is a Go library for managing OCI artifacts, compliant with the OCI Image Format Specification and the OCI Distribution Specification. It provides unified APIs for pushing, pulling, and managing artifacts across OCI-compliant registries, local file systems, and in-memory stores.

 [!Note]
 The main and v2 branches follow Go's Security Policy and support the two latest versions of Go (currently 1.26 and 1.27).

v3.0.0 v3.0.0 2026-11-01
ORAS Go v3.0.0 is the first stable release of the v3 line. It adds a configuration layer compatible with containers/image, a client builder, registry mirrors, policy and signature verification, content verification, and new push modes. It also reorganizes remote-registry configuration so that a registry owns the settings its repositories share.
