🦌 DeerFlow - 2.0

English | 中文 | 日本語 | Français | Русский | Português | 한국어






 2026 年 2 月 28 日，DeerFlow 2 发布后登上 GitHub Trending 第 1 名。非常感谢社区的支持，这是大家一起做到的。

DeerFlow（Deep Exploration and Efficient Research Flow）是一个开源的 super agent harness。它把 sub-agents、memory 和 sandbox 组织在一起，再配合可扩展的 skills，让 agent 可以完成几乎任何事情。

https://github.com/user-attachments/assets/a8bcadc4-e040-4cf2-8fda-dd768b999c18

 [!NOTE]
 DeerFlow 2.0 是一次彻底重写。 它和 v1 没有共用代码。如果你要找的是最初的 Deep Research 框架，可以前往 1.x 分支。那里仍然欢迎贡献；当前的主要开发已经转向 2.0。

 一句话交给 Coding Agent 安装

如果你在用 Claude Code、Codex、Cursor、Windsurf 或其他 coding agent，可以直接把下面这句话发给它：

text
如果还没 clone DeerFlow，就先 clone，然后按照 https://raw.githubusercontent.com/bytedance/deer-flow/main/Install.md 把它的本地开发环境初始化好


这条提示词是给 coding agent 用的。它会在需要时先 clone 仓库，优先选择 Docker，完成初始化，并在结束时告诉你下一条启动命令，以及还缺哪些配置需要你补充。

 通过 Web 注册共享模型

管理员可在 设置 → 模型 → 添加模型 中选择厂商，仅填写 API Key 和
模型 ID。后端预置 OpenAI、Anthropic、DeepSeek、百炼/通义千问、火山/豆包、
Moonshot/Kimi、智谱/Z.AI、MiniMax 和阶跃星辰（StepFun）的端点、认证与适配器，地域和 Coding Plan
使用明确区分的选项。模型 ID 不受内置枚举限制；内部名称自动生成且保持稳定。
新模型默认启用，保存后自动刷新聊天及 Agent 的模型选择器，无需重启 Gateway。

已有地址继续通过 自定义 OpenAI-compatible 查看、编辑和使用，也支持无认证
接口。高级设置保留显示名称、上下文窗口、输出限制和视觉能力覆盖；未知模型不
自动声明能力。编辑时 API Key 留空表示保留同一连接的密钥，切换厂商或地址须
重新填写。清除预设模型密钥前应先停用模型。连接测试不保存草稿，并使用与聊天
相同的协议及模型工厂；真实请求可能产生费用。

YAML 同名模型优先，已有任务保留原配置快照。托管模型使用原有加密目录，必须
备份整个 $DEER_FLOW_HOME/managed-models/，同时保存匹配的 catalog.enc 和
key；丢失密钥应恢复备份，不要删除目录或重建密钥。
详见配置参考。

 快速开始

 配置

1. 克隆 DeerFlow 仓库

   bash
   git clone https://github.com/bytedance/deer-flow.git
   cd deer-flow
   

2. 运行安装向导（推荐）

   在项目根目录（deer-flow/）执行：

   bash
   make setup
   

   这会启动一个交互式向导，引导你选择 LLM provider、可选的 web 搜索工具，以及 sandbox 模式、bash 权限、文件写入等执行/安全偏好。它会生成一份最小化的 config.yaml，并把 API key 写入 .env，大约 2 分钟完成。

   随时可以运行 make doc
