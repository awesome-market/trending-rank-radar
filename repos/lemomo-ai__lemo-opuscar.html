Lemo-Opuscar

99 种影片风格，交给你的编程 agent。挑一个风格，带上你的故事，agent 用代码把整支片做出来。

▶ 打开画廊 · English README · English gallery



官方仓库：github.com/lemomo-ai/lemo-opuscar · 作者 Lemomo（@lemomo_ai）



 [!IMPORTANT]
 这一版经 Claude Fable 5.2 审计和改进。

 本插件为 Claude 专用。 Claude Fable、Opus、Sonnet 都能用，推理强度（effort）建议选 high（在 Claude Code 里输入 /effort high）。其他模型适配度不高，请谨慎使用。

 怎么用

1. 挑一个风格。 在画廊里按画面像什么去找，或者按你要做的东西搜：科普、发布、新闻、MV。
2. 看它的 demo。 每个风格都有一支用代码做的短片，风格页里还有静帧、适合做什么，以及 agent 会照着做的 STYLE.md。
3. 告诉你的 agent。 先装一次 skill，再用一句话说：

text
用霓虹灯管风格给我做一支关于我家咖啡园的片子。


风格用中文名、英文名或文件夹名都行，全部风格见风格索引。还可以加上时长、旁白的声音，或者你自己的照片和音乐：

 用油画厚涂风格做一支 30 秒的片子，讲我家那只每天在窗台等我下班的橘猫。

 用点云测绘风格做一支 40 秒的片子，讲我们镇后山那座废弃的采石场，数据用公开的激光扫描。

 安装

装成 skill（推荐）。 在终端里：

sh
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab


之后在任何目录都能用。第一次使用时，它会把指南、工具和风格提示词下载到 ~/lemo-opuscar，所有片子共用这一份；每支片子的工程，从源码到成片，都放在你发起时所在的文件夹里。其他 agent 可以把 plugin/skills/lemo-opuscar/ 复制到它们的 skills 目录。

或者 clone 仓库。 片子做到仓库里的 films//。

sh
git clone https://github.com/lemomo-ai/lemo-opuscar.git
cd lemo-opuscar
claude


 更新和卸载

更新，然后重启 Claude Code（~/lemo-opuscar 里的库会在下一次做片时自动更新）：

sh
claude plugin marketplace update lemolab && claude plugin update lemo-opuscar@lemolab


想让它自动更新：在 Claude Code 里输入 /plugin，进 Marketplaces，选 lemolab，点 Enable auto-update（lemolab 这类第三方 marketplace 默认不自动更新，要自己打开）。

用 clone 的：git pull，然后跑一次 sh plugin/skills/lemo-opuscar/scripts/setup.sh deps（只更新有变化的核心包；装过配音或音乐包的，改跑 … deps voice music）。

更新后照常说要做什么片；想把风格改成自己的，看下面。

卸载，然后删除 ~/lemo-opuscar：

sh
claude plugin uninstall lemo-opuscar@lemolab


你自己的风格存在 ~/lemo-my-styles/，更新和卸载都不会删；不要了就自己删掉这个文件夹。一直卡住就提个 issue。

 接下来会发生什么

还没想好也没关系：装成 skill 的，输入 /lemo-opuscar:lemo-opuscar 直接启动。它先问你用什么语言，再问这次想做什么：用库里的风格做片、把风格改成你自己的，或者用你存过的风格。

它开工前只问你一次：主题里它定不了的事；你有没有自己的配音、音乐或其他素材；要不要先看分镜故事板（要看的话，它会停一次，给你看用真实风格画出来的关键镜头；不看就直接做完成片）。

然后 agent 会读三份指南，像一个小工作室一样开工。指南是英文写给 agent 看的，你用中文跟它说就行，片子的配音和字幕默认跟你用的语言一致。

| 文件 | 给 agent 的东西 |
|---|---|
| DIRECTOR.md | 怎么导：故事、声音、节奏、镜头、表演、自检 |
| TECHNIQUE.md | 怎么做：逐帧渲染、配音、配乐、混音 |
| styles//STYLE.md | 这个风格长什么样、听起来什么样；故事由你定 |

每一支片子都是 agent 写代码导演、作画、配乐、混音的：🎨 Canvas 和 WebGL 页面逐帧渲染，🎵 用免费采样库写的原创配乐，🎙️ TTS 语音合成配音。不用视频生成，也不用素材库画面。

 开始之前

- 一支片子 agent 大约要做 30–60 分钟，token 用量不小。
- 需要 Node 20+、ffmpeg 7+ 和 Python 3.11+（或 uv），其余由 agent 安装。Ubuntu 24.04 自带的 ffmpeg 是 6.1，版本太旧，请换成静态版。
- 有三个风格的人物要用生图工具画，需要你自己提供（黑白漫画分格、文字闪切、搞笑历史卡通，在风格清单里标 ✦）：登录了能生图账号的 Codex CLI，或者你手上别的生图工具。没有的话这三个风格没法开始；其余风格都用不到。
- 默认输出 1920×1080、24 fps（有些风格自带帧率，比如 30 fps），其他尺寸可以指定。

 改成你自己的风格

每个人想要的都不一样：有自己的品牌色、logo、IP 和账号调性。现在你可以把库里的风格改成只属于你的，或者从空白做一个库里没有的。走的就是我自己往库里加新风格的流程。


库里的风格 · 瑞士动态排版平面网格、一个信号色、动作卡着节拍。
我的风格 · 材质网格 · ▶ 31 秒 demo 片留下瑞士排版的网格、节拍和字体，换成陶土、塑料、绒布、玻璃和铬的实物：俯视是一张海报，镜头一倾全是实物。


启动 skill 后在入口里选，或者一句话直接说：

 我想把浮世绘风格改成我自己的版本。

 从空白开始，做一个黑板粉笔画的风格，暖一点、慢一点。

改库里的风格，它会列出全部风格和画廊链接，你打字说改哪一个。从空白开始，就用你自己的话描述想要的样子，也可以给一张
