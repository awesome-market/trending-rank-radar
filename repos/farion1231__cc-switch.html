CC Switch v4.0.31

本版本新增受管应用腾讯 WorkBuddy：自定义模型写进 WorkBuddy 自己的模型配置，在 WorkBuddy 里直接就能选；还能在多个 WorkBuddy 账号之间切换，切换前先看到每个号的套餐、剩余积分和到期时间。界面新增德语，README 也有了全部八种界面语言的版本。

另外修复了 Claude Code 经路由连 OpenAI Responses 格式的中转时，会话被同一个中转分到不同 Azure 资源后每一轮都报 400、再也继续不了；经路由连 Gemini Native 格式上游时，并行工具调用报 400、缓存命中率很低；macOS 托盘悬停提示一直挂在屏幕上；Codex 续接的旧对话用量从不导入等问题。
