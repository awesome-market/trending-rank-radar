 记录，不必打断当下的思路

一个想法刚出现时，可能只有一句话、一段录音、一张截图，或者一个暂时没时间阅读的链接。保存它们之前，你不必先想好标题、目录和文章结构。

NoteGen 把记录和整理分成了两个阶段。

有内容时先把它留下来。需要整理时，再选出属于同一个主题的记录，把它们组织成一篇结构清楚的 Markdown 笔记。之后可以继续修改、补充，完成自己的写作。

AI 不是来替你写完一切，而是帮助那些零散但有价值的内容，在被遗忘之前变成一篇完整的笔记。

 NoteGen 如何工作

1. 先把内容记录下来

   随手记下一句话，录一段声音，保存截图、图片、链接、文件或待办事项。

2. 挑选真正相关的材料

   按标签、时间或类型筛选记录，把属于同一个主题的内容选出来。

3. 把记录整理成笔记

   选择模板，或者直接描述你想写什么。NoteGen 会根据选中的材料生成总结、报告、文章或其他结构化内容。

4. 继续完成自己的写作

   在编辑器里检查、修改和补充内容。AI 生成的只是草稿，最终文件仍然是一篇可以自由编辑的 Markdown 文档。

 一些真实的使用方式

- 开会时记录几句话、录一段音、截两张图，会后统一整理成会议纪要。
- 阅读时先保存链接和零散摘录，周末再把它们整理成一篇主题笔记。
- 按标签筛选最近一周的记录，快速准备周报或工作总结。
- 围绕一个主题收集图片和文档，再基于这些材料提问和写作。

记录不是一篇没写完的笔记。它更像写作之前的原材料。

 以普通 Markdown 文件为基础

你完成的笔记会以普通 Markdown 文件保存在自己选择的工作区中。

可以继续使用 NoteGen 编辑，也可以用其他 Markdown 编辑器打开；可以把文件放进 Git，可以复制、迁移和备份，不需要先从专有格式中导出。

NoteGen 做的是在这些文件之外补充记录、AI、搜索和整理能力，而不是把你的笔记锁进另一个平台。

编辑器支持：

- 表格、任务列表、代码块、数学公式、图表和文章大纲
- Markdown 源码模式与可视化编辑
- 文本查找与替换
- 图片、附件、链接和文件引用
- 导出与打印
- 文件历史和工作区管理

 在需要时使用 AI

NoteGen 可以连接你自己配置的 AI 服务与模型。聊天、写作、嵌入、图片识别、OCR 和音频任务可以分别选择模型。

你可以让 AI：

- 把选中的记录整理成结构化笔记
- 续写、缩写、扩写、润色或翻译已有内容
- 围绕笔记、记录、图片和知识库进行对话
- 回答问题前先检索本地材料
- 根据笔记内容生成图表和画布
- 使用 Agent 模式处理更长的任务

AI 是写作过程中的工具，不是最终作者。生成结果可以继续修改，不满意的内容也可以直接删掉。

 让写过的内容重新派上用场

很多笔记完成后，就再也没有被打开过。

NoteGen 可以为工作区中的文件建立知识库，把语义检索和本地文本搜索结合起来。发起对话时，可以引用一篇笔记、一组记录或整个知识库，不需要反复复制原文。

如果需要更复杂的工作流，还可以使用：

- 向量索引与混合检索
- 自定义嵌入和重排序模型
- 长期记忆与可复用提示词
- MCP 服务
- 可安装的 Skills
- 用于处理笔记和文件的 Agent 工具

 不只适合线性文档

有些内容用文章表达很清楚，有些内容更适合画出来。

NoteGen 提供独立的画布工作区，可以创建和编辑：

- 流程图
- 思维导图
- 时间线
- 自由绘制内容
- 数据图表
- 根据笔记生成的可视化结构

AI 生成的画布不会变成一张无法修改的图片，其中的节点、文字和连线仍然可以继续编辑。

 按自己的方式同步

笔记默认保存在本地。需要跨设备使用时，可以选择自己信任的服务进行同步。

目前支持：

- GitHub
- GitLab
- Gitee
- Gitea
- S3 兼容存储
- WebDAV

不使用云同步时，也可以通过本地备份保存数据。

 开始使用

1. 根据自己的系统下载 NoteGen。
2. 选择一个目录作为 Markdown 工作区。
3. 添加第一条记录，或者直接创建一篇笔记。
4. 需要使用 AI 功能时，再配置相应的模型服务。
5. 阅读使用文档，了解同步、知识库、MCP、Skills 和其他设置。

不需要先完成所有配置，才能开始写第一篇笔记。
