README

Power Platform Skills

Plugins from Microsoft that teach AI assistants, such as GitHub Copilot and Claude Code, to build on Power Platform.

Browse the plugins and install them with one click

You describe what you want in your own words, such as "Create a Power Pages site with React for a job board" or "Why did the last run of my approval flow fail?".
Your assistant asks follow-up questions, shows you what it plans to do, and asks before it runs commands or changes files.
Then it does the work, from creating tables to publishing the result to your Power Platform environment.

 What can I build?

| I want to... | Plugin | Try asking |
| --- | --- | --- |
| Build a website | Power Pages | "Create a Power Pages site with React for a job board" |
| Build a business app | Model-driven apps | "Build an app for tracking service requests" |
| Build or change a canvas app | Canvas apps | "Edit my Canvas App to add a new screen for reports" |
| Build a web app with code | Code apps (preview) | "Create a code app for tracking customer requests" |
| Build a phone app | Mobile apps (private preview) | "Build me a small notes app" |
| Add native phone features to a canvas app | Power Apps Mobile extensions (preview) | "Design a native barcode scanning feature for my wrapped canvas app" |
| Automate work | Power Automate | "Create a flow that emails me when a new item is added to my SharePoint list" |
| Work with Dataverse data | Dataverse | "Import this CSV into the contacts table" |
| Find where a process slows down | Process Intelligence | "Which steps cause the most waiting in this process?" |
| Build custom controls for forms and views | PCF (preview) | "Create a PCF star rating control for a model-driven form" |
| Build tools and widgets for AI assistants | MCP Apps | "Show account revenue as a bar chart" |

The plugin website shows what each plugin needs and more things to ask.

 Before you start

- Choose an AI assistant. Use the GitHub Copilot app, GitHub Copilot CLI, or Claude Code.
- Get a Power Platform environment. You'll need permission to create or change resources in it.
  For learning and experiments, start with a free developer environment rather than an environment with live apps or data.
- Install Node.js. The quick installer and most plugins need it to run.

Check your chosen plugin's page for any additional tools, such as the Azure CLI or the .NET SDK.
Requirements vary by plugin, so you don't need to install every tool up front.

 Installation

 Quick install (recommended)

Open a terminal and run one command.
It installs every plugin into Claude Code and GitHub Copilot CLI, whichever you have.

Windows (PowerShell):

powershell
iwr https://raw.githubusercontent.com/microsoft/power-platform-skills/main/scripts/install.js -OutFile install.js; node install.js; del install.js


macOS, Linux, or Windows (cmd):

bash
curl -fsSL https://raw.githubusercontent.com/microsoft/power-platform-skills/main/scripts/install.js | node
