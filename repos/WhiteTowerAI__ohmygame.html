用 AI 做游戏的开源工作室。

描述你想做的游戏，Agent 会写设计文档、做美术、写代码，亲自试玩确认能跑通，再发布成一个谁都能打开的链接。设计文档、图片、视频、3D 和音频都和代码放在同一块画布上，不用在五六个工具之间来回切换。

 [!NOTE]
 OhMyGame 目前处于 Beta 阶段，难免有粗糙的地方。遇到问题欢迎告诉我们。

OhMyGame 不内置模型。首次启动时，连接一个模型服务商，或者选择你已经在用的编程 Agent：见首次运行。

 功能

- 让 Agent 来做游戏。 Agent 起草设计文档、编写代码、在实时预览里运行游戏，然后亲自上手玩，发现问题就尝试修复。
- 所有素材在一块画布上。 用 AI 生成图片、视频、3D 模型、动画、配音、音效和音乐，在同一块画布上整理，直接用进游戏。
- 发布成一个链接。 任何人都能在浏览器里玩，游戏也会出现在社区里。多人游戏的房间，以及玩家的登录、存档和排行榜，也会一起上线。
- 用插件扩展。 插件可以教 Agent 新技能、给它新工具，也可以给应用添加面板和项目类型。内置插件已覆盖 Godot、Unity、Unreal Engine、Blender、Aseprite、Tiled，以及微信小游戏、抖音小游戏等平台。也可以自己做插件。
- 自带 Agent。 用 Claude Code、Codex 或 OpenCode 来驱动 OhMyGame，也可以接入 40 多家模型服务商，用你自己的密钥。不按次收费。反过来也行：通过 MCP，在你的 Agent 里使用 OhMyGame 的画布、媒体生成和试玩能力。模型 · 外部 Agent

 你可以做什么

我们团队用 OhMyGame 做的三款游戏：


  
    
    
    
  
  
    互动电影
    岛屿建造
    卡牌构筑 Roguelike
  


网页游戏（Phaser、Three.js、React Three Fiber）最适合入门。互动故事适合做视觉小说、互动电影和剧情游戏。General Game 不限引擎和技术栈。网页游戏可以做成多人联机，从棋牌到实时对战，和朋友在线一起玩，不用自己架服务器，详见多人联机。去玩玩别人做的游戏。

 从源码构建

需要 Bun 1.4.2+ 和 Node.js 22.19+。

bash
git clone https://github.com/WhiteTowerAI/ohmygame.git
cd ohmygame
bun install --frozen-lockfile
bun run dev             网页渲染端 + 本地守护进程
bun run dev:desktop     或者 Electron 桌面应用


从源码构建的版本不发送任何遥测数据。分支、检查和可选的云端配置见 CONTRIBUTING.md。

 隐私

你的项目和 API 密钥都留在本机，提示词直接发给你选择的服务商。只有发布游戏时才需要账号。正式版会发送使用数据和崩溃报告，可以在 设置 → 关于 中关闭。见日志与诊断。

 参与贡献

欢迎提 Issue 和 PR。从 dev 拉分支，PR 也提到 dev；main 只用于发版。先读 CONTRIBUTING.md，可以从 help wanted 的 Issue 入手。安全问题请按 SECURITY.md 私下报告。
