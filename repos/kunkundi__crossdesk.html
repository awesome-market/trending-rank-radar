README

轻量、跨平台的远程桌面，支持电脑、浏览器、移动端和终端连接，用桌面墙集中查看与操控多台设备。
  官方网站 · 下载客户端 · 打开 Web 客户端 · English




















CrossDesk 让你从电脑、浏览器、手机或终端（桌面 CLI）连接远端电脑，也能通过桌面墙（DeskHub）集中查看与操控多台设备。项目基于 MiniRTC，支持自托管。

主要功能 · 下载与平台支持 · 快速连接 · 终端 CLI · IP 直连 · 可信设备 · 界面预览 · 使用指南 · 自托管 · 构建与反馈 · 赞助



 主要功能

- 跨平台远控： Windows、macOS、Linux 桌面互控，浏览器及原生 iOS / Android 客户端访问电脑；鸿蒙 PC 与移动端处于开发阶段。
- 局域网 IP 直连： 桌面客户端通过 IP、端口和六位密码连接，无需云端信令服务；支持独立端口、记住密码及按模式显示近期设备。
- 终端主控： 在终端中通过设备 ID 观看和操控远程桌面，支持 ANSI / Kitty / Sixel 画面、局部缩放与平移、持续本地命令模式及 Pi 扩展，可单独构建。
- 桌面墙：多设备实时预览、分组、放大操控、群控和批量文件分发。
- 画面与声音： H.264 / AV1、硬件编解码、远端音频，以及会话内画质和帧率调整；可用能力随平台与设备而异。
- 日常协作： 多显示器切换、键鼠与组合键、文本剪贴板、文件传输。
- 可信设备： 桌面端可选开启可信设备限制，在连接密码之外校验设备身份；支持复制、粘贴配对信息，提前添加允许访问本机的设备。
- 部署与运维： P2P 直连、TURN 中继、SRTP 媒体加密、自托管，以及 Windows 登录前远控和 Linux 无头运行。



 下载与平台支持

从 官方网站 或 GitHub Releases 下载与你的系统和 CPU 架构匹配的安装包；也可直接打开 Web 客户端。

| 平台 | 支持范围与安装要求 |
| --- | --- |
| Windows | 控制 / 被控；Windows 10+，x64；.exe 安装包，也支持便携构建 |
| macOS | 控制 / 被控；macOS 14.0+；按 Intel / Apple Silicon 选择 x64 / arm64 .pkg |
| Linux | 控制 / 被控；Ubuntu 20.04+、glibc 2.31 基线；amd64 / arm64 .deb |
| iOS / iPadOS | 仅控制；iOS 16.0+；发布包为未签名应用，需自行签名，或使用 Xcode 构建安装 |
| Android | 仅控制；Android 8.0+，arm64；下载已签名 APK 安装，或自行构建 |
| 鸿蒙 PC（开发版） | 控制 / 被控；API 26，arm64；使用 DevEco 构建并签名 HAP，仍在进行真机验收 |
| 鸿蒙手机 / 平板（开发版） | 仅控制；API 20+，arm64；使用 DevEco 构建并签名 HAP，仍在进行真机验收 |
| Web | 仅控制；支持 WebRTC 的浏览器；无需在控制端安装客户端 |
| 终端 CLI（开发版） | 仅控制；分发目标为 macOS / Linux（x64、arm64）和 Windows（x64）；通过 npm 安装 或从源码构建，平台验收范围见 CLI 说明 |

系统要求按当前源码与构建配置整理，具体安装包以对应 Release 说明为准。各客户端的功能范围见 终端 CLI 与 移动端与鸿蒙。

- Linux： 已有桌面选普通版 crossdesk-linux-…deb；需要独立 Xfce 桌面的服务器选 crossdesk-virtual-desktop-xfce-…deb。两者选择其一，安装与启动方法见 使用指南 和 无头运行。
- macOS： 首次运行时按提示授予屏幕录制及辅助功能权限；前者用于桌面采集，后者用于远程键鼠输入。权限说明
- iOS / 鸿蒙： 签名与构建步骤分别见 iOS 和 鸿蒙，不要将未签名产物当作可直接安装的应用。



 快速连接

 通过设备 ID 连接

1. 准备被控电脑。 安装并运行 CrossDesk，切换至 ID 连接模式，等待显示“已连接服务器”，查看“本桌面”中的本机 ID 和密码。
2. 发起连接。 在另一台电脑的 CrossDesk 中输入被控电脑的 9 位 ID，点击“连接”；也可使用原生移动端或 Web 客户端。
3. 验证密码。 输入被控电脑当前的连接密码，等待远程画面出现。桌面端可勾选“记住密码”，后续从“近期连接”重连。

使用自建服务器时，两端需要接入同一服务。新版桌面端使用设备密钥登录服务器，请先升级服务端：新 ID 注册时绑定公钥，旧 ID 首次升级时验证原密码后绑定；绑定后，针对该 ID 的错误密码尝试不会阻塞正常签名登录。远程控制仍需输入连接密码；新版控制端也验证设备签名，密码失败按控制端及“控制端 → 目标”计数，不再累计被控端的总失败次数，避免他人的错误尝试锁住目标。身份备份与兼容要求见 设备登录说明。更多连接、密码及浏览器操作见 使用指南；连接失败、黑屏或无法操作键鼠时先查阅 常见问题。



 通过局域网 IP 直连

1. 切换模式。 两台电脑均运行支持 IP 直连的桌面客户端，点击左上角模式按钮切换到 IP 直连模式。若按钮未显示，在 设置 → 常规 → 网络连接 中勾选 启用 IP 直连 并保存。
2. 填写地址。 在控制端输入被控电脑显示的 IP:端口，例如 192.168.1.20:52888 或 [2001:db8::20]:52888，点击“连接”。只输入 IP 时使用默认端口 52888；请以对方界面显示的实际端口为准。
3. 输入密码。 输入被控电脑在 IP 直连模式下显示的 6 位英文字母或数字密码，可勾选“记住密码”。切换模式时，“近期连接”同步切换为对应模式的设备记录。

两台电脑需要在局域网内可互相访问；网络可以有外网，也可以没有外网，直连会话不依赖云端信令服务。主窗口可直接切换本机 IP、修改端口和密码，默认开启所有 IP 接口监听，支持 IPv4 和 IPv6，支持通过 VPN 等接口连接，可在设置的“网络连接”中调整；关闭设置中的“启用 IP 直连”会停止监听、断开 IP 直连会话并隐藏模式按钮。详见 IP 直连使用指南。



 仅允许可信设备连接（可选）

桌面端的可信设备限制默认关闭，适用于 ID 连接和 IP 直连。开启后，控制端仍需通过原有密码验证，并持有可信名单中设备的配对私钥；仅知道 ID 和密码不能通过这项限制。

1. 在控制端复制配对信息。 打开 设置 → 常规 → 隐私保护 → 管理可信设备，在 本机配对信息 中点击 复制配对信息。
2. 在被控端添加控制端。 打开同一管理界面，将收到的信息粘贴到 添加可信设备 输入框，点击 添加 即可加入，无需再次确认，也无需先建立远程连接。
3. 在被控端开启限制。 返回设置
