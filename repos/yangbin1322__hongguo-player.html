!红果短剧电脑版: 沉浸式刷剧



 🖥️ 为什么做这个?

手机刷短剧很方便. 但已经坐在电脑前的时候, 为了看几集还要拿起手机, 或者专门开一个安卓模拟器, 多少有点麻烦.

所以做了这个真正适合电脑用的红果短剧客户端: 鼠标滚轮刷剧, 方向键切换, 看完自动下一集, 还能开个小窗边工作边追剧.

 ✨ 主要功能

- 🎬 沉浸式刷剧: 推荐 / 分类刷剧, 鼠标滚轮或方向键切换, 边刷边预加载
- ▶️ 自动连播: 看完自动播放下一集、下一季, 记住上次看到哪
- 🔍 找剧方便: 搜索 (带输入联想)、多维度筛选 (含已完结 / 连载中)、排行榜、新剧推荐与上新日历
- 📌 追更提醒: 追的剧更新了、预约的剧上线了, 打开程序就提醒你
- 📱 竖屏模式: 竖屏短剧时窗口收窄到刚好包住画面, 不留两侧黑边
- ✨ 画质: 默认最高画质, 可开画质增强 (锐化 / 漫剧动漫增强 Anime4K); 画面和窗口比例接近时自动铺满
- 💬 互动: 弹幕 (点赞 / 回复 / +1)、评论 (在画面右侧展开) 与剧评, 和手机端互通
- ❤️ 追剧管理: 收藏、点赞 (可按真人剧 / 漫剧 / AI剧筛选)、观看历史、预约, 都能搜索和批量删除
- ⌨️ 键盘快捷键: 默认与抖音网页版一致, 可以自己改
- 🪟 小窗模式: 窗口置顶, 边工作边追剧; 隐身模式下鼠标移开自动暂停隐藏
- 🙈 干净的画面: 鼠标不动时控制条、点赞栏自动隐藏, 全屏看剧不挡画面
- 🔗 分享: 一键复制分享链接 (手机红果 App 可直接打开); 复制别人的分享链接后自动识别播放
- 💻 Windows + macOS: Mac 同时支持 Intel 与 Apple 芯片
- ⚡ 解码兜底: 硬件解码不可用时自动改用软件解码, 不会只有声音没有画面
- 🔄 自动更新、浅色 / 深色主题

Windows

1. 下载压缩包, 解压到一个文件夹后双击 红果短剧.exe, 无需安装. 压缩包里还有:
   - MicrosoftEdgeWebview2Setup.exe: WebView2 运行时安装程序
   - HEVC视频扩展-双击安装.appx: HEVC 视频扩展
   - 使用说明.txt

   请和程序放在一起: 首次运行如果系统缺少 WebView2 运行时 或 HEVC 视频扩展, 程序会用它们自动安装 (WebView2 需要联网).
2. 若提示 "Windows 已保护你的电脑", 点 更多信息 → 仍要运行 (程序没有购买代码签名证书).
3. 以后有新版本时程序会提示, 点 "立即重启更新" 即可自动更新 (只替换 红果短剧.exe).

 Releases 里的 hongguo-版本号-windows-amd64.exe 是主程序本身, 供自动更新使用; 新安装请下载 zip.

macOS

1. 解压得到 红果短剧.app, 拖到 "应用程序".
2. 应用未签名, 首次打开如提示 "已损坏" 或 "无法验证开发者", 在终端执行:
   
   xattr -cr /Applications/红果短剧.app
   
   然后再打开.

 ❓ 常见问题

需要登录吗? 要钱吗?

免费, 不登录也能刷剧; 收藏、点赞、观看历史未登录时保存在本机. 用手机号登录后与手机端红果 App 同步.

杀毒软件报毒 / 程序被删了?

是误报. 本程序没有购买代码签名证书, 新版本刚发布时也还没有 "信誉", 再加上自动更新会替换自己的程序文件, 这些行为容易被安全软件的机器学习规则 (如 Windows 安全中心的 !ml) 当成可疑程序. 程序不会收集你的账号密码, 也不会改系统设置.

- Windows 安全中心: 打开 "病毒和威胁防护" › "保护历史记录", 找到被拦的红果短剧点 还原 / 允许; 再到 "病毒和威胁防护设置" › "排除项" › 添加排除项 › 文件夹, 选择程序所在的文件夹.
- 360 安全卫士: 木马查杀 › 右下角 恢复区 里恢复, 再到 信任区 添加程序所在文件夹.
- 火绒: 隔离区里恢复, 再在 "信任区" 添加程序文件夹.
- 建议把程序放在单独的文件夹 (如 D:\红果短剧\), 不要直接放桌面或 D 盘根目录, 方便加排除项; 加了排除项后, 以后自动更新出来的新版本也不会再被删.

提示 "获取播放地址失败: 服务端返回了空内容" / 突然播放不了?

红果的接口经常调整, 旧版本可能突然就播不了了, 请更新到最新版: 程序内 设置 › 关于与更新 › 检查更新, 或到上面的下载页 / 蓝奏云下载最新的 zip. 更新到最新版还不行, 请在程序里点 "反馈" 告诉我们.

提示 "设备自动注册失败" / "后端未就绪"?

程序首次启动要向红果注册一个设备, 连不上红果服务器时就会这样, 一般是网络环境的问题:

1. 先关掉 VPN / 代理 / 加速器, 再点重试.
2. 用了广告过滤软件, 或路由器 / 自定义 DNS (如 AdGuard) 的, 请把 log.snssdk.com、snssdk.com 加入白名单. 1.2.22 起被 DNS 拦截时会自动改用公共 DNS 绕过去.
