 让 AI 为你写一部完整的中文小说

 📖 为什么用这个？

脑子里有个故事，却总卡在“然后呢”？先定人物和大纲，再逐章写到完稿。面向 Coding Agent、Personal Agent 等各类 Agent：

- 智能问答 - 三层递进式问答，支持快速跳过和随机生成
- 偏好记忆 - 保存题材、视角和文风偏好，减少重复问答
- 中断续写 - 意外中断？自动检测并从断点继续
- 多种写作模式 - 串行 / 子Agent并行 / Agent Teams，按需选择
- 检查与润色 - 逐章审读连贯性与表达，脚本检查字数，不达标时修复
- 章节衔接 - 记录人物处境与事件后果，承接未解悬念

 Phase 0：初始化

自动加载用户偏好（user-preferences.json），检测是否有未完成的项目可续写，展示个性化欢迎。

 Phase 1：三层递进式问答

Layer 1 — 核心定位（必答，3问）：题材创意、主角设定、核心冲突

Layer 2 — 深度定制（可跳过）：世界观、叙事视角、核心主题、读者定位、章节数量

 每个问题都支持随机生成，也可以直接说"跳过"或"都用默认"。

v2.3.2：摘要承接与写作质量优化 v2.3.2 2026-10-29
写作质量与连贯性改进

- 章节摘要保留关键事件及后果、人物已知与误解、真实打算、未消解的情绪关系，以及影响后续的行动条件；续写前读取相关摘要，减少人物状态断裂。
- 放宽固定对话比例、冲突频率和每章意外转折等机械配额，按章节用途安排节奏。
- 去 AI 味指导从逐词禁用转为检查空泛、重复解释和无效修饰，保留符合人物声音的表达。
- 扩充内容优先展开人物的尝试、阻碍、选择与代价；感官细节按场景需要选取。
- 对话允许直说、寒暄与潜台词，按人物目的和关系判断，并修正写作示例。

 工具调整

- 字数检查脚本由 Python 迁移至 Node.js，继续支持单章、批量检查及 JSON 输出。运行方式：node scripts/check_chapter_wordcount.mjs  --json。
- 清理内部设计文档。

 验证

- Skill 格式校验、Git diff 检查及 Node.js 脚本语法检查通过。
- 本版本尚未完成小说生成效果的系统对照评估；既有质量反馈仍需通过实际作品验证。
