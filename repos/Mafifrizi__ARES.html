Operator-directed red team orchestration & continuous security validation

Prove exploitability. Compute shortest paths to Crown Jewels. Ship audit-ready evidence.
Built for enterprise red teams, MSSPs and security operations centers that need to validate defensive posture continuously, not once a year.











Quickstart · Screens · Features · Docs · Security · Sponsor



---

 What ARES is

A self-hosted platform that runs real offensive validation modules inside a fail-closed scope enclave, maps attack paths on an interactive DAG, and produces branded reports, so your SOC sees exactly what an attacker could reach today, not what a scanner thinks might be a problem.

Not just a scanner. ARES only reports what it actually proved on a live target, including the multi-stage chain used to prove it.

 Why not a traditional pentest or a vulnerability scanner? See the market comparison matrix.

 Features

- Fail-closed scope enclave: dual-layer ScopeGuard (application pre-check + OS/transport firewall) guarantees zero offensive packets reach out-of-scope hosts. → security model
- Goal-directed attack planning: set domain_admin or cloud_audit, and the decision engine synthesizes multi-stage execution paths (graph heuristics, optional LLM agents under explicit authorization). → engine design
- Multi-vector attack graph (DAG): ingest BloodHound or map sessions in real time. Shortest-path, chokepoints, lateral pivot feasibility. → attack graph
- Zero-trust auth model: memory-only short-lived JWTs, HttpOnly rotating refresh, HMAC CSRF, AES-256-GCM AEAD vault (PBKDF2-HMAC-SHA256 600k). → security model
- 66 active production modules across 60+ MITRE ATT&CK techniques (AD, cloud, credential access, exfil, lateral, recon, Windows, Linux, EDR). → module catalog
- Automated deliverables: one-click branded PDF/HTML/Markdown/JSON reports via headless browser (no GTK deps on Windows/Linux). → dashboard guide
- MCP Gateway: Cursor/Claude Desktop/Windsurf/Cline can drive ARES safely under Pre-Flight ScopeGuard, anti-prompt-injection taint isolation and single-use HMAC confirmation tokens. → MCP spec
- Type-safe Python SDK: write custom modules with BaseModule[P, R] + @ares_module, simulate in ModuleTestHarness, automate with AresClient. → SDK docs · → module dev guide
