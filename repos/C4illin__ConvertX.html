!ConvertX

 ConvertX





!GitHub commits since latest release
!GitHub repo size
!Docker container size





A self-hosted online file converter. Supports over a thousand different formats. Written with TypeScript, Bun and Elysia.

 Features

- Convert files to different formats
- Process multiple files at once
- Password protection
- Multiple accounts

 Deployment

 [!WARNING]
 If you can't login, make sure you are accessing the service over localhost or https otherwise set HTTP_ALLOWED=true

yml
 docker-compose.yml
services:
  convertx:
    image: ghcr.io/c4illin/convertx
    container_name: convertx
    restart: unless-stopped
    ports:
      - "3000:3000"
    environment:
      - PUID=1000  user id for file permissions (should match your host user id)
      - JWT_SECRET=aLongAndSecretStringUsedToSignTheJSONWebT
