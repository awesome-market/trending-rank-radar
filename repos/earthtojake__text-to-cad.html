 🚀 Quickstart

macOS and Linux:

bash
curl -fsSL https://texttocad.dev/install.sh | sh


Windows, in PowerShell:

powershell
irm https://www.texttocad.dev/install.ps1 | iex


It installs uv if it is missing, then sets up text-to-cad in every agent app on
your computer with each app's own commands (the plugin, which brings the skills
and CAD's MCP server, or for an agent without a plugin the skills alone; Claude
Code gets the skills, and Claude Desktop the server, for its Chat and Code tabs),
registers the cad command, and moves CAD's server to the new release. Run
it again to update everything, or click CAD's update button when it shows one; it
lists the apps to restart.

Then ask your agent for a part or an assembly: it writes the model as a Python
script, runs it to build the model and shows it in the CAD viewer.

Installing by hand, app by app, and updates: docs/install.md

 ✨ Features

The text-to-cad plugin gives your agent local workflows to generate 3D models as STEP, GLB, STL or 3MF files, check them for manufacturing, draw them, and connect to 3D printing, sheet metal and CNC services. It works with any agent that supports plugins or skills.

- Parts and assemblies: Models written as Python scripts with build123d and OpenCASCADE, exported as STEP, STL, 3MF or GLB, and as DXF profiles and flat patterns for laser and waterjet cutting, with joints and animations for mechanisms, and shown live in the CAD viewer.
- Circuit boards: KiCad schematics and boards, placed and routed, checked with ERC and DRC, reviewed before you order, and exported as fabrication files.
- Manufacturing checks: Whether a part can be machined, cut and bent, molded or 3D printed, measured against the process's rules, and what to change where it cannot.
- Stress checks: Whether a part or an assembly of bonded parts holds under its loads, solved with CalculiX: each part's peak stress, safety factor and how far it moves, drawn on the model.
- Engineering drawings: Dimensioned PDF sheets projected from the part's geometry: views, hidden lines, centre marks, hole callouts and a title block.
- Renders: Photoreal stills, turntables and films of a model with Blender, lit and framed in a Python script and run on the GPU, with a quick draft before each final.
- Fabrication services: Checks DXF and STEP files against SendCutSend's guide before you upload them, and slices 3D prints with OrcaSlicer and sends them to Bambu Connect or Bambu Studio.
- Robotics and simulation: Robot and world descriptions for simulation and motion planning: URDF for ROS, SRDF for MoveIt and MJCF for MuJoCo.

 🛠️ Contributing

text-to-cad is MIT-licensed and built in the open.

- Bugs and plugin requests: open an issue.
  A bug report with the model script and the output of cad doctor --check is the
  fastest to fix, and an agent app without a plugin gets one on request. A
  security problem is reported privately, as SECURITY.md says.
