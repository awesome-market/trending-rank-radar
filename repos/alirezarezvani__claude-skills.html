Claude Code Skills & Plugins

415 production-ready skills for Claude Code and 12 other coding agents, covering engineering, product, marketing, compliance, finance and the C-suite. We test whether each skill loads when you ask in plain words, and publish the results.









Works with: Claude Code · OpenAI Codex · Gemini CLI · OpenClaw · Hermes Agent[^hermes] · Mistral Vibe[^vibe] · Cursor · Aider · Windsurf · Kilo Code · OpenCode · Augment · Antigravity

 Install in one minute

Claude Code

bash
/plugin marketplace add alirezarezvani/claude-skills
/plugin install engineering-skills@claude-code-skills


Codex, Cursor, Gemini CLI, Copilot and other agents (the open-source skills installer)

bash
npx skills add alirezarezvani/claude-skills


More options for each tool are under Quick Install.

2.14.11 — CRA, IEC 62304 and skill hints
_Released 2026-11-11_

Two new compliance plugins: cra-readiness for the EU Cyber Resilience Act, whose Article 14 reporting already
applies, and medical-device-software for IEC 62304 and IEC 81001-5-1. Eight plugins now ship a quiet
UserPromptSubmit hook that names one of 21 skills that never loaded on their own when a prompt clearly fits it;
it makes no model or network calls, and SKILL_ROUTER=0 turns it off (SKILL_ROUTER_=0 for one plugin).
No renames, so nothing needs a reinstall: claude plugin update picks up the hooks, and the new plugins install
