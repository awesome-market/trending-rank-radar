Telegram Drive

 A local-first file workspace powered by your own Telegram account

Organize, transfer, preview, stream, sync, and share the files you keep in Saved Messages and Telegram channels—on Windows, macOS, Linux, Android, and Google TV.









Download for desktop · Download Android 4.1.0 · Product website · Changelog



!Telegram Drive desktop dashboard

Telegram Drive turns Telegram's familiar file storage into a focused, desktop-style workspace. The app connects directly to Telegram with credentials you provide; it does not run a separate file-storage or relay service. Every application feature is available without payment.

 [!IMPORTANT]
 Telegram Drive is an independent project and is not affiliated with Telegram FZ-LLC. Files remain subject to Telegram's account, service, and per-file limits. Telegram Drive should not be treated as literally unlimited storage or as the only backup of important data.

 Download and install

Desktop 4.1.4 and Android / Google TV 4.1.0 use separate version lines. The desktop release does not update or include Android or Google TV. Downloads are listed below.

| Platform | Download | Notes |
| --- | --- | --- |
| Windows x64 | Installer | Includes the required Microsoft Visual C++ runtime setup |
| macOS — Apple Silicon | DMG | For M-series Macs |
| macOS — Intel | DMG | For Intel-based Macs |
| Linux x64 | AppImage · Debian · RPM · Arch | Choose your distribution; Arch updates remain managed by pacman |
| Android phones and tablets | Signed universal APK | Android 7.0 or newer; supports ARM64, ARMv7, x86, and x86_64 |
| Android TV / Google TV | Signed TV-compatible APK | The same universal package includes the TV launcher and remote navigation |
