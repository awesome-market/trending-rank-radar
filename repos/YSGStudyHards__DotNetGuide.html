 📚DotNetGuide简介
在当下技术生态中，Java、Python、Android、Golang 等技术的学习资料、实战心得、面试攻略随处可得。反观 C/.NET 生态，优质学习资料、实战经验、面试指南都比较零散、碎片化，很难系统性一站式查阅。经常在 QQ 技术群、微信技术群、知乎等平台看到大家提问：有没有靠谱的 C/.NET 学习书籍、视频教程、实战项目、主流项目框架和高频面试题推荐？ 其实并不是没人分享，而是因为网上内容太分散、缺少一个系统化汇总的知识库，新手入门、老手进阶都要到处找资料，白白浪费大量时间。作为一名 .NET 开发者，我也不想一直看着这种现状持续下去。创建 DotNetGuide 知识库的初衷，就是为了整理、收录、沉淀全网优质 C/.NET/.NET Core 学习资源：包含完整学习路线、精品视频教程、优质文章、经典书籍、开源项目、主流框架、开发实战案例、编程技巧、必备工具、技术周刊、行业动态、高频面试题、面试经验、简历模板、行业招聘，以及个人学习与工作中的实战心得。旨在帮助那些想要入门 .NET 或者正在从事 .NET 开发的同学，少走弯路、高效成长。一个人的力量终究有限，由衷欢迎大家在 Issues 投稿，或直接提交 PR，一起共建、完善这份 C/.NET/.NET Core 学习、工作、面试一站式指南知识库🤞。
