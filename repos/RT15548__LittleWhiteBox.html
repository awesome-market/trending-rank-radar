README

LittleWhiteBox

面向 SillyTavern 的多功能扩展，为长篇角色扮演提供剧情记忆、状态管理、绘图、语音和应用面板。

版本更新与说明见 Releases。

 主要功能

- 剧情总结与记忆：整理剧情，辅助长对话中的记忆召回；支持记忆包导入导出。
- 变量与任务：管理角色状态、委托和任务进展。
- 绘图与语音：生成剧情插图，播放角色语音。
- 小白 OS：集中使用地图、私人通讯、语言学习、钱包和游戏等应用。

 开发构建

执行 npm run build 构建整个插件，npm run check 完成整体验收。完整规则见 构建与发布资源。

 绘图

 NovelAI
感谢 @tpy225 提交的 PR 129。

- Vibe 氛围转移：在参数预设里上传参考图，勾选启用、调整强度，即时保存到当前预设。编码会消耗 Anlas，只在手动点击时发起；编码按模型和信息提取值分别保存，调回原来的值不用重新花点数。
- Vibe 组：把当前的勾选和强度存成一组，一次套用多张参考图；修改组不影响其他预设已经套用的选择。组可以导出、导入，文件里带原图和编码，换设备不用重新编码。分享云端预设时，勾选的 Vibe 也会一起带上。
- 预设缩略图：参数预设列表改成网格卡片。在卡片右上角「…」里选「更换缩略图」，可以从图库选图或本地上传；拖动缩略图调整顺序。
- 快捷菜单：楼层和悬浮菜单里的预设下拉框换成缩略图网格，没有缩略图的预设显示成文字按钮。菜单高度固定，预设多了在菜单里滚动；「自动/手动」开关和张数放在同一行。
- 旧图转 JPEG：图片管理里新增按钮，把缓存里还是 PNG 的旧图批量转成 JPEG，节省空间。转换前会先把 PNG 原图存到酒馆服务器，存不上的那张不转。
