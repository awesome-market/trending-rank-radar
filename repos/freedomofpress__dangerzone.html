Dangerzone

Take potentially dangerous PDFs, office documents, or images and convert them to a safe PDF.


| !Settings | !Converting
|--|--|

Dangerzone works like this: You give it a document that you don't know if you can trust (for example, an email attachment). Inside of a sandbox, Dangerzone converts the document to a PDF (if it isn't already one), and then converts the PDF into raw pixel data: a huge list of RGB color values for each page. Then, outside of the sandbox, Dangerzone takes this pixel data and converts it back into a PDF.

_Read more about Dangerzone in the official site._

 Getting started

The documentation lives at docs.dangerzone.rocks.
Its source is under docs/ in this repository:

 Installation for macOS, Windows, Ubuntu, Debian, Fedora, Qubes OS, and Tails, and the supported platforms
 Tutorials to get started
 Development environment to build from source, and how to contribute
 Security policy and changelog

Preview the site locally with poetry install --with docs followed by make docs-serve.

Latest release

0.11.1 v0.11.1 2026-10-22
We're pleased to announce that Dangerzone 0.11.1 has been released.
This release mostly includes stability improvements and security fixes, with a few new features.

The highlights for this release are:

 Users can now choose to disable or skip update checks.  
 GitHub release notes are no longer rendered from Markdown to HTML in the application.  
 Documents are now accepted from stdin, and safe PDFs are written to stdout.  
 (Linux-only) Users now get progress reports for image downloads.  
 Documentation is now published at https\://docs.dangerzone.rocks.
