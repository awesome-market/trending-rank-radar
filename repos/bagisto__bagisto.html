 Introduction

Bagisto is an open-source Laravel eCommerce and multi-vendor marketplace platform for building scalable online commerce solutions. Built with Laravel and Vue.js, Bagisto provides a flexible and customizable foundation for businesses to launch online stores, multi-vendor marketplaces, and enterprise commerce experiences.

Whether you're building a single-vendor store, B2B eCommerce platform, or multi-vendor marketplace, Bagisto helps reduce development time and cost while giving you the freedom to customize and scale your commerce solution.

 🐳 Run with Docker

A single command gives you a fully installed store — migrations, seed data and search indexes are all baked into the image, so there is no first-run setup.

bash
docker run -d --name bagisto -p 80:80 webkul/bagisto:latest


Images are published for each web server and each database, so you can match whatever you already run:

| | MySQL 8.0 | MariaDB 10.11 | PostgreSQL 16 |
|---|---|---|---|
| Nginx | :latest · :latest-nginx · :latest-nginx-mysql | :latest-nginx-mariadb | :latest-nginx-postgres |
| Apache | :latest-apache · :latest-apache-mysql | :latest-apache-mariadb | :latest-apache-postgres |
| OpenLiteSpeed | :latest-litespeed · :latest-litespeed-mysql | :latest-litespeed-mariadb | :latest-litespeed-postgres |

Pin a release by swapping latest for the version, e.g. webkul/bagisto:2.5.0-nginx-postgres. Setting DB_HOST to an external server skips the bundled database entirely. Full details in docker/production/README.md.
