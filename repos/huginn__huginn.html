 What is Huginn?

Huginn is a system for building agents that perform automated tasks for you online.  They can read the web, watch for events, and take actions on your behalf.  Huginn's Agents create and consume events, propagating them along a directed graph.  Think of it as a hackable version of IFTTT or Zapier on your own server.  You always know who has your data.  You do.

!the origin of the name

 Here are some of the things that you can do with Huginn

 Scrape websites and receive an email when they change
 Watch RSS feeds, IMAP mailboxes, webhooks, and MQTT topics, and act on what arrives
 Track the weather and get an email when it's going to rain (or snow) tomorrow ("Don't forget your umbrella!")
 Watch for air travel or shopping deals
 Detect peaks and gaps in a stream of events and send a message within moments when something unusual happens
 Send digest emails with the things you care about at specific times of the day
 Post to Slack, Telegram, Threads, Tumblr, Twitter, Weibo, Pushover, Pushbullet, and Jabber, or send SMS and phone calls with Twilio
 Summarize, classify, and translate text, or generate images and speech, with OpenAI-compatible APIs
 Fetch, transform, and store files on Dropbox, S3, FTP, and the local filesystem
 Write custom logic in JavaScript, Liquid templates, or jq
 Publish your own feeds and JSON endpoints from the events your Agents collect
 Track your location over time
 Send and receive webhooks to connect Huginn with anything else

Ask questions and share your ideas in GitHub Discussions.

 Join us!

Want to help with Huginn?  All contributions are encouraged!  You could make UI improvements, add new Agents, write documentation and tutorials, or try tackling issues tagged with "help wanted".  See CONTRIBUTING.md to get started.

Have an awesome idea but not feeling quite up to contributing yet?  Head over to our official 'suggest an agent' thread and tell us!

 Getting Started

 Try it with Docker

The quickest way to check out Huginn is the official Docker image, which runs everything in one container:

bash
docker run -it -p 3000:3000 ghcr.io/huginn/huginn


Open http://localhost:3000/ and log in as admin with the password printed once in the container log.  See the Docker documentation for persistent storage, an external database, and the multi-container image.

 Local development

If you want to hack on Huginn, fork this repository and then:

 Run git remote add upstream https://github.com/huginn/huginn.git to add the main repository as a remote for your fork.
 Copy .env.example to .env (cp .env.example .env) and edit .env, at least updating the APP_SECRET_TOKEN variable.
 Make sure that you have MySQL

This security release fixes server environment disclosure through JqAgent and bypasses of the enforced outbound proxy.  Upgrade installations that enable JqAgent or rely on OUTBOUND_PROXY to restrict users' outbound requests.

 Security fixes

- JqAgent now starts jq with an empty environment.  User filters can no longer read server environment variables through env or $ENV.  This affects installations with jq support enabled through USE_JQ.  GHSA-3f56-748g-q34j
- Enforce OUTBOUND_PROXY for HTTParty, open-uri and directly built Net::HTTP connections, including JiraAgent and WeiboPublishAgent.
