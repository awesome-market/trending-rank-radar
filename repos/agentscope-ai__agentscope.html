 What's AgentScope 2.0？

AgentScope 2.0 是一款面向生产、易于使用的智能体框架，提供与不断进化的模型能力相匹配的核心抽象。

AgentScope 的目标是充分发挥大模型的推理与工具调用能力，
而非用严格的提示词和固化的编排方式来束缚它们。

 快速开始

 安装

 AgentScope 需要 Python 3.11 或更高版本。

 从 PyPI 安装

bash
uv pip install agentscope


 从源码安装

bash
 从 GitHub 拉取源码
git clone -b main https://github.com/agentscope-ai/agentscope.git

 以可编辑模式安装
cd agentscope

uv pip install -e .


 智能体（Agent）

SDK 层 —— 用一整套丰富的构建模块组合出你的智能体：

| 构建模块 | 包含内容 |
|---|---|
| ReAct | 推理-行动循环，支持结构化输出、实时中断与恢复、以及批量（顺序 / 并发）工具执行 |
| 工具集 | 智能体自主工具管理（囊括 Python 工具、MCP 与 Skill）；内置编码工具（Shell、文件编辑、搜索）与任务/规划工具开箱即用 |
| 模型 | LLM、Embedding、TTS，覆盖主流厂商（OpenAI、Anthropic、Gemini、DashScope、DeepSeek、Moonshot、Volcengine、xAI、Ollama） |
| 上下文 | 自动压缩、工具结果卸载、以及上下文注入（系统提示、RAG、记忆），均由内置中间件实现 |
| 事件系统 | 统一事件总线，将推理、工具调用与多模态内容（文本、图像、音频）流式推送到前端 |
| 权限与 HITL | 对工具和资源的细粒度控制、确认、bypass 模式 |
| 中间件 | 贯穿整个循环的可组合钩子 —— 回复、推理、行动、模型调用、权限检查、上下文压缩、系统提示 |
| 记忆 | Agentic Memory，可切换后端（ReMe、Mem0） |
| 工作空间 / 沙箱 | 隔离工具与代码执行 —— local、Docker、Apple Container、Bubblewrap、E2B、OpenSandbox、Daytona、K8s |
