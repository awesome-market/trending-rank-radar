BrowserSkill

BrowserSkill 把你的 AI Agent 连接到 Chrome 或 Microsoft Edge，直接使用你已有的登录状态。 交给它读取、点击、填表或排查问题。任务在独立、可见的 Agent Window（代理窗口） 中运行，需要时由你接手；也可以显式借用已有标签页，任务结束后归还。

 能做什么

| 你想完成的事 | BrowserSkill 如何帮忙 |
| --- | --- |
| 用已有账号，做网站任务 | 复用浏览器登录态，读取文档、搜索内部网站，完成需要登录的网页流程。 |
| 一句指令，落实到操作 | 读取页面文本和控件，点击、输入、填写表单、拖拽元素、选择范围、管理标签页；截取可见区域或完整页面，在本地模式上传和下载文件。 |
| Agent 操作，你来掌控 | 共享控制让你与 Agent 协作；编辑时暂停 Agent，让它核对你的改动后继续。任务在独立窗口中可见运行，也可显式借用已有标签页。 |
| 网页表格，导出即用 | 将已加载的表格和列表导出为 JSON/CSV，保留列名、页面/frame 来源、合并单元格信息和完整性标记。结构化提取 |
| 操作出错，找到线索 | 关联操作、请求、响应正文、控制台和页面变化，检查性能、慢接口与疑似重复请求；用明确配置的 HTTP 规则或请求重放验证判断。网站调试 |
| 录下过程，随时回看 | 将一个已授权的任务标签页录制为无声 MP4，在扩展中预览、保存或删除。任务视频录制 |
| 页面就绪，再做下一步 | 设置明确的超时，等待目标元素满足指定条件后再继续操作。元素等待 |
| 已经观察，按需复用 | 用 step 执行一个已决定的动作并同步状态；明确保存完整观察结果，再用 view 搜索或分段阅读，无需重新采集页面。步骤与观察结果保存 |
| 浏览器与账号，选对再开工 | 为浏览器实例命名，让任务绑定指定 Profile；也可以让服务器上的 Agent 连接你电脑上的浏览器。浏览器 Profile |
| 任务结束，记录可查 | 重新打开浏览器本地的调试历史、导出 JSON，或单独开启操作审计，查看任务执行记录。操作审计 |

 快速开始

本地自动化需要 AI Agent + bsk CLI + 浏览器扩展。CLI 自带后台守护进程（daemon），skill 则负责告诉 Agent 如何使用这些工具。

| 组件 | 支持环境 |
| --- | --- |
| CLI / daemon | macOS：Apple Silicon、Intel；Linux：x64、ARM64；Windows：x64 |
| 浏览器扩展 | 基于 Chromium 125 或更新版本的 Chrome、Microsoft Edge。其他 Chromium 浏览器可能可用，但不保证兼容。 |
| Agent 接入 | 能调用 Shell 的 Agent 配合 BrowserSkill skill，或 DeepSeek Harness 配合 DSH 插件。 |

 让 Agent 帮你安装

把下面这句话发给 Agent：

text
按照 https://raw.githubusercontent.com/Tencent/BrowserSkill/main/AGENT_INSTALL.md 的说明，在本机安装并配置 browser-skill。


安装指南会引导 Agent 安装 CLI、选择对应的 skill 或 DSH 插件、检查连接，并完成第一次浏览器任务。你仍需在想使用的浏览器中安装扩展：

安装 Chrome 扩展 · 安装 Edge 扩展


手动安装步骤

 1. 安装 CLI

macOS / Linux：

sh
curl -fsSL https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.sh | sh
export PATH="${BSK_INSTALL_DIR:-$HOME/.local/bin}:$PATH"


Windows PowerShell：

powershell
irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex


默认安装到 ~/.local/bin。在实际使用工具的终端或 Agent 环境中检查：

sh
bsk --version


如果已启动的 Agent 找不到 bsk，重启 Agent 以加载新的 PATH，或配置安装后二进制的绝对路径。

 2. 连接扩展

从 Chrome Web Store 或 Edge 加载项商店 安装扩展，开启连接后即可使用。本机配对是可选的：未配对仍可正常使用，扩展会提示连接身份未经验证。如需配对，运行 bsk daemon pair，将链接粘贴到连接设置 → 配对链接并保存。重启和升级后无需重复配对；已配对后验证失败不会自动跳过验证。详见本机配对指南。

 3. 给 Agent 安装 skill

sh
bsk install-skill


按 空格 选择使用的 Agent，按 Enter 安装。非交互安装时显式指定目标，例如：

sh
bsk install-skill --harness cursor --json


用 bsk install-skill --list 查看支持的目标和安装路径。已有安装默认跳过，只有显式使用 --force 才会覆盖。其他 Agent 可将完整的 crates/bsk-cli/skill/ 目录复制到其 skill 目录下，命名为 browser-
