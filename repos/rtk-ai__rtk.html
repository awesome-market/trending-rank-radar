rtk 在命令输出到达 LLM 上下文之前进行过滤和压缩。单一 Rust 二进制文件，零依赖， 完整说明：RTK 的节省是如何计算的

 安装

 Homebrew（推荐）

bash
brew install rtk


 winget（Windows）

Windows 上最简单的安装方式 — 一条命令，无需配置 PATH：

powershell
winget install rtk-ai.rtk


 快速安装（Linux/macOS）

bash
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | sh


 Cargo

bash
cargo install --git https://github.com/rtk-ai/rtk rtk


 Apache-2.0 版本（仅开源，允许商业使用）

同一个 rtk 二进制文件，构建时不包含 BUSL-1.1 压缩引擎：钩子重写系统和所有命令过滤器，仅遵循 Apache-2.0。

bash
curl -fsSL https://raw.githubusercontent.com/rtk-ai/rtk/refs/heads/master/install.sh | RTK_EDITION=oss sh
brew install rtk-ai/tap/rtk-oss
cargo install --git https://github.com/rtk-ai/rtk rtk --no-default-features


 验证

bash
rtk --version    应显示 "rtk 0.27.x"
rtk gain         应显示 token 节省统计


 快速开始

bash
 1. 为对应的 AI 工具安装 hook
rtk init --global                Claude Code（默认）
rtk init --agent trae            Trae（项目级）
rtk init --global --agent trae   Trae（全局）

 2. 重启相应的 AI 工具，然后测试
git status   自动重写为 rtk git status


 工作原理


  没有 rtk：                                      使用 rtk：

  Claude  --git status--  shell  --  git         Claude  --git status--  RTK  --  git
    ^                                   |            ^                      |          |
    |        ~2,000 tokens（原始）       |            |   ~200 tokens        | 过滤     |
    +-----------------------------------+            +------- （已过滤）-----+----------+


四种策略：

1. 智能过滤 - 去除噪音（注释、空白、样板代码）
2. 分组 - 聚合相似项（按目录分文件，按类型分错误）
3. 截断 - 保留相关上下文，删除冗余
4. 去重 - 合并重复日志行并计数
