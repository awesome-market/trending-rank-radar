README

VoIP Stack for Home Assistant and ESPHome

An independent, open-source SIP PBX running inside Home Assistant, installable through HACS.

!VoIP Dashboard with incoming, active and held calls

_VoIP Dashboard development preview,
shown with illustrative incoming, active and held call states._

Answer your SIP video doorbell from a Home Assistant dashboard or Companion
app, call between rooms, and use ordinary SIP desk phones or softphones.
VoIP Stack provides the phones, shared phonebook and call handling inside
Home Assistant. Connect a provider trunk when you also want external calls.

Build a small intercom or a complete local telephone system: ring several
phones, forward unanswered calls, take voicemail, transfer a conversation or
route a caller according to your Home Assistant entities and automations.

Install · Make your first call · Understand phones and cards · PBX walkthrough · Automation recipes

Developed and maintained by n-IA-hane, with community contributions and support. ❤️ Sponsor the project

| Goal | How it works | Start here |
| --- | --- | --- |
| Answer a SIP doorbell | The door station calls a Home Assistant phone or ring group. Answer with audio and supported video from a dashboard, Companion app or SIP phone. | Door-station example · Video compatibility |
| Call between rooms | Give each tablet, kiosk or browser phone its own name and extension, then call another room from the phonebook. | Logical Home Assistant phones |
| Use existing telephones | Register a desk phone, ATA, Zoiper, Linphone or another SIP client directly with Home Assistant. | SIP phones and softphones |
| Ring several phones | Call a ring group; the first answer wins and the other phones stop ringing. | Groups |
| Hold an audio meeting | Call an HA-hosted conference group and talk with the other participants. | Conference groups |
| Handle unanswered calls | Apply phone routing defaults, send the caller to voicemail or forward to another destination. | PBX functions |
| Make external calls | Connect a named provider or PBX trunk and choose which phones can use it. | SIP trunks |
| Build an IVR or contextual route | Play a greeting, collect keypad input and select a destination using native HA triggers, conditions and actions. | Automations as dialplan |
| Speak to Assist by telephone | Assign a Home Assistant Assist pipeline a callable name or extension. | Assist extension |
| Add a physical ESP room station | Choose a maintained phone profile, or combine calls with a local voice assistant and media playback. | ESPHome devices |
