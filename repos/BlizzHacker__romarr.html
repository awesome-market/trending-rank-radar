README

ROMarr

The arr for games.

Find games, verify ROMs, and import them into your library.




Install · First setup · Plugins · Roadmap · Releases

!ROMarr interactive search, with scores and reasons beside each result

Forks and code reuse are welcome; independent projects should use their own branding. Attribution and branding policy.

Unraid: install the official ROMarr listing, using ghcr.io/blizzhacker/romarr. ROMarrNG is a separate fork and is not supported by this project. Official builds and support policy.

 What can I use it for?

| I want to… | Start here | What you need |
|---|---|---|
| Import ROMs I already have | Manual Import | A destination folder and access to the source files. No indexer or download client needed. |
| Find and download a particular game | Add New or Interactive Search | A search source, a matching download client, and a destination folder. |
| Check what a collection is missing | Collections | A No-Intro or Redump DAT and your local library. |
| Reclaim space taken by exact duplicates | Stats → Audit | A local library; review the preview before moving duplicates to quarantine. Restore is available. |
| Add another game source | Hub → Plugins | ROM Hub, included in the Windows app and amd64/arm64 Docker images. Details. |

You can use a plain folder as your library. RomM, Gaseous, Retrom and other library integrations are optional. Your emulator or frontend plays the games; ROMarr handles finding, checking and importing files.

Imports can be checked against DAT checksums. The result is verified, bad dump, or unknown. Without a matching DAT, a file is unknown; that does not mean it is damaged. Rename on import can use a verified single-file ROM's DAT name while keeping its source extension; unknown filenames are retained and existing files are not overwritten. A bulk, in-place rename planner for existing libraries is on the roadmap.

 Install

 Choose a method

| Method | Best fit | Guide |
|---|---|---|
| Docker Compose | Most servers, NAS hosts, or Docker Desktop | Quick start below |
| Proxmox LXC | A Proxmox host | LXC installer |
| Windows app | Windows 10/11 on x64 | Download the Windows ZIP, extract it and double-click ROMarr.exe. No Python, PowerShell or .NET installation required. |
| Linux/macOS source checkout | Development or an existing Python host | Source instructions |
| Home Assistant add-on | A Home Assistant installation | Add-on instructions; this packaging needs more field testing. |

For Docker, have Docker Engine or Docker Desktop with Compose installed. Reserve port 6868 and choose where settings, downloads, and ROMs will live. ROMs and download space are usually much larger than the app itself.

 Docker Compose quick start

These commands are for a Linux or macOS shell, or an SSH terminal on your Docker host. They create a new folder library. If you already use RomM or another library, mount its real ROM directory instead of ./roms.

bash
mkdir -p romarr/config romarr/roms romarr/downloads

ROMarr v1.9.2 — Platform-filtered ROM Hub search v1.9.2 2026-11-13
Platform-filtered ROM Hub searches now work for Sega Genesis / Mega Drive. ROMarr translates its saved platform ID into the identifier expected by archive-org and nointro-archive, so you can keep the platform selected in Interactive Search.

The same fix covers TurboGrafx-16, Odyssey 2, ZX81, and Apple II. Existing platform selections and library folders are preserved.

Verified with a live Sonic search against both affected sources, regression tests through Interactive Search, 3,636 passing Linux tests, both Docker images, and native Windows executable checks. Fixes 175 via 176.
