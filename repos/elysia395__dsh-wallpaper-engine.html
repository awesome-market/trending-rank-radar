README

把本机 Wallpaper Engine 的 Scene、Web 与视频壁纸带进 DSH 对话界面，再配上液态玻璃、字体、吉祥物与可分享的外观预设。插件不向 agent 注册工具、不注入提示文本，不增加模型 token 开销。


  


真实界面演示；历史素材与当前安装版本可能略有不同。

- 壁纸：Scene / Web 实时渲染，Video 直接播放；支持自定义图片 / 视频上传与 WE 项目目录。
- 外观：设置窗、对话区与侧栏液态玻璃；配色、透明度、模糊、边框与字体可调。
- 玻璃子包：液态玻璃是独立子包行 wallpaper-engine-glass，可在插件管理器单独停用；停用后，除内容区壁纸外界面回到宿中原生外观，壁纸、字体与吉祥物等功能不受影响。
- 扩展：吉祥物、会话头像、点击 / 拖尾特效、3D 视差；可选桌宠联动 dsh-pet-dshwe（dsh-pet 全量 fork），设置页卡片可一键安装，未装 / 关闭 / 版本过旧时回落原生吉祥物。
- 壁纸库：筛选、隐藏 / 恢复、自动轮播；外观预设整套导入导出。



| 类型 | 在 DSH 中的路径 | 支持情况 |
|---|---|---|
| Scene（场景） | 内置 WebWallGL 实时渲染，失败时按降级链回退 | 支持，不需要 WE 在后台运行 |
| Web（网页） | 网页挂载、WE API 注入与沙箱隔离 | 支持；效果取决于网页与浏览器能力 |
| Video（视频） | 浏览器播放，配合转码、帧率上限与暂停控制 | 支持 |
| Picture（图片 / 幻灯片项目） | 读取 WE preset 项目的图片目录，按 WE 里设的周期在本机交叉淡化轮播 | 支持；图片不上传、留在本机 |
| 自定义图片 / 视频 | 上传本地 JPG / PNG / MP4 | 支持，文件保存在本机 |

Application（应用）类壁纸需要启动第三方程序，不支持，也不会进入壁纸库或轮播候选。



前置：Node.js = 22.12.0、DSH 0.2 内核（含 0.2.0-rc.1/rc.2）与 pnpm。安装前完全退出 DSH。

npm（推荐）

sh
dsh plugin --profile web add dsh-plugin-wallpaper-engine


桌面端把 web 改为 desktop。

本仓按多包发布集发布：主包与同版本子包一起解析（具体包数、tarball 数与 publishOrder 见发布流程，各版本变化见变更记录）。

源码

sh
node scripts/install-source.mjs --profile desktop --dsh-home "" --app-closed


源码安装会构建客户端并注册主包与子包；安装后不要移动或删除源码目录。完整说明见 安装与升级 与 贡献指南；没有命令行经验请先看 入门指南。



1. 打开 设置 → Wallpaper Engine → 壁纸库，或在聊天顶部从吉祥物拉绳进入壁纸仓库。
2. 在页内壁纸库选择缩略图，按需调整播放与外观；修改即时生效并保存到宿主端。
3. 暂停 / 播放只控制当前播放；清除当前壁纸不会删除原文件。


  



  




- Windows / macOS / Linux 使用同一份源码；macOS 没有 WE 客户端，可上传图片 / 视频或指向 WE 项目目录。
- Scene 渲染依赖浏览器 WebGL 与显卡驱动，复杂工坊项目可能存在兼容差异；失败会逐级降级。
- 遮挡暂停、窗口失焦暂停与音频回环采集按平台适配。
- 与其他皮肤 / 插件同时启用时，先看 共存说明。

🎉 v1.4.2：紧急修复——拖动吉祥物时右侧栏不再疯狂闪烁（1.4.1 回归）

本版是 1.4.1 的紧急修复版：拖动吉祥物时右侧栏按帧反复弹出又收回（真机复现：40 帧拖动触发 30 次侧栏开/关）。根因是两处叠加——主包拖动路径逐帧向桌宠联动发手势，而 pet-link 的 performer 门面不看当刻模式恒走 linked provider，联动未装/未开（绝大多数用户的常态）时直接回落到「开关右侧栏」。修法两层互为纵深：门面按 provider 路由 + 手势段绝不回落 fallback；修复后端到端复现拖动全程 toggles=0，linked 与 native 两态一致，三条新守卫各自做过反向验证。完整条目见 CHANGELOG。

 📦 九件套（九包同号锁步 1.4.2）

主包 dsh-plugin-wallpaper-engine + 八个子包（-fonts / -fx / -glass / -parallax / -media-bridge / -about-notice / -mascot-avatar / -pet-link）。其中 -glass（液态玻璃）为 1.4.1 起新增的子包。
