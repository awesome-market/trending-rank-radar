Latest release

gperftools-2.19.3 gperftools-2.19.3 2026-11-10
This is another bug-fix release on top of 2.19.2. It updates the vendored aw-backtrace.

With the previous version of aw-backtrace, we got broken backtraces on aarch64 when gperftools was built with -fstack-protector-strong, which is the default compiler setting on many distros, e.g. Ubuntu (see https://github.com/gperftools/gperftools/issues/1653). This release fixes that and related issues. aw-backtrace's own CI now also tests builds with stack protector, hardening (-mbranch-protection or -fcf-protection), without frame pointers, and, on x86-64, x86-64-v3 builds (stack realignment).
