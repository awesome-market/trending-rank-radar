 安装

macOS · Linux

sh
curl -fsSL https://omp.sh/install | sh


安装脚本会从 build.stencil.so 下载预编译二进制，并在安装前校验其 SHA-256；如需改用 bun 安装软件包，请传入 --source（PowerShell：-Source）。可通过 curl -fsSL https://omp.sh/install | sh -s -- --binary --ref v 固定某个版本（PowerShell：-Binary -Ref v）。

 Alpine / musl： 预编译的 musl 二进制动态链接 libstdc++/libgcc，而原生 Alpine 并不自带。请先安装：apk add libstdc++ libgcc。

Homebrew

sh
brew install can1357/tap/omp


Bun（推荐）

sh
bun install -g @oh-my-pi/pi-coding-agent


Nix

sh
 Run without installing
nix run github:can1357/oh-my-pi

 Or install into the active profile (Nix .omp、overlays.default、nixosModules.default 或 homeManagerModules.default。Home Manager 配置可以安装 OMP 并以声明式方式管理其设置：

nix
{
  inputs.omp.url = "github:can1357/oh-my-pi";

   In your Home Manager module:
  imports = [ inputs.omp.homeManagerModules.default ];
  programs.omp = {
    enable = true;
    settings.startup.quiet = true;
  };
}

 Shell 补全

omp 会根据实时的命令/参数元数据，为 bash、zsh 和 fish 生成自己的补全脚本，因此永远不会与实际 CLI 脱节。子命令、参数和枚举值是静态补全的；模型名（--model、--smol、--slow、--plan）会根据内置模型目录解析，--resume 则根据磁盘上的会话解析。

sh
 zsh — add to ~/.zshrc (or write the output into a file on your $fpath)
eval "$(omp completions zsh)"

 bash — add to ~/.bashrc
eval "$(omp completions bash)"

 fish
omp completions fish  ~/.config/fish/completions/omp.fish

 你 _喜爱_ 的 Pi，如今全副武装。

omp 最初基于 Mario Zechner 出色的 Pi 构建，补齐了你所缺少的一切。

 01 · 可调用工具的代码执行

大多数智能体框架给智能体一个 Python 沙箱就算完事。我们运行持久化的 Python 和 Bun worker，而且两个内核都能通过本地回环桥接回调智能体自己的工具——read、search、task。智能体可以在 Python 里用 tool.read 加载 CSV，再用 JavaScript 绘图，全程不离开同一个单元格。

!omp TUI 运行 Python 代码并渲染图表。

 02 · 每次写入都接入 LSP

要求重命名，得到的就是真正的重命名。调用会走 workspace/willRenameFiles，因此在文件移动之前，重导出、barrel 文件和带别名的导入都会先被更新。IDE 知道的一切，智能体都知道。

!启用了 TypeScript 和 Biome 语言服务器的 omp TUI。

_阅读 LSP 配置文档_

 03 · 驱动真正的调试器

C 程序段错误：智能体挂上 lldb，单步到出错的指针，读取栈帧。Go 服务卡死：挂上 dlv，逐个查看 goroutine。Pytho
