 :rocket: 学习路线

每条路线把笔记按天排好，每天 1～2 小时：读一段笔记，回答几道面试中的真实问题，做一个动手练习；后三条路线每天还有一道算法题。

- 零基础：没有学过计算机课程时从这里开始，用一次外卖下单讲清程序、操作系统、网络、数据库和数据结构，不需要会编程；
- Java 后端：会 Java 语法以后，系统准备后端面试，依次学 Java、MySQL、Redis、网络、操作系统、Spring、分布式和系统设计；
- 大模型应用开发：准备 RAG、Agent 方向的岗位，从 Transformer 的原理学到 Agent 和工程实践；
- 面试冲刺：两三周后就要面试时，每天复习 3 个最常考的知识点。

不按路线学习时，可以直接读下面的笔记。
