 🔎 GPT Researcher

GPT Researcher 是首个开放的深度研究代理，可针对任意任务开展网络与本地研究。

代理可以生成详细、正式且客观的研究报告，并提供自定义选项，专注于相关资源、结构框架和经验报告。GPT Researcher 早已不止于 RAG：规划代理与执行代理将每个任务拆解为研究问题，决策模型只保留真正有助于回答问题的上下文，多代理工作流协调各专业代理完成从规划到发布的全过程，递归深度研究则从广度和深度两方面探索主题。研究并行执行，因此快速、稳定、可靠，并能减少错误信息。

我们的使命是利用人工智能的力量，为个人和组织提供准确、客观和事实的信息。

 为什么选择GPT Researcher?

- 人工研究要形成客观结论可能需要数周时间，耗费大量资源和精力。
- 基于过时信息训练的 LLM 会产生幻觉，难以胜任当下的研究任务。
- 当前的 LLM 存在 token 限制，不足以生成长篇研究报告。
- 现有服务的网络资源有限，容易导致错误信息和肤浅的结果。
- 只选用部分网络资源可能给研究任务带来偏见。

 架构

核心思想是使用“计划者”和“执行”代理：计划者生成研究问题，执行代理收集相关信息，最后由发布者将所有发现汇总为一份完整的研究报告。





步骤：
 根据研究查询创建特定任务的代理。
 生成一组研究问题，共同形成对该任务的客观意见。
 使用爬虫代理为每个问题收集信息。
 对每个资源进行汇总并跟踪其来源。
 过滤并聚合所有摘要，生成最终研究报告。

 特性

- 📝 基于网络与本地文档生成详细的研究报告。
- 🖼️ 智能抓取并筛选报告配图。
- 🍌 使用 Google Gemini（Nano Banana）生成 AI 内联配图。
- 📜 生成超过 2,000 字的详细报告。
- 🌐 汇总 20 多个网络资源，形成客观结论。
- 🎯 通过 Jev 进行智能上下文过滤，默认无需 API 密钥或 embeddings。
- 🖥️ 提供轻量（HTML/CSS/JS）与生产级（NextJS + Tailwind）两种前端。
- 🔍 支持 JavaScript 渲染的网页抓取。
- 📂 在整个研究过程中维护记忆与上下文。
- 📄 将报告导出为 PDF、Word 等格式。

 ⚙️ 快速开始

 安装

1. 安装 Python 3.12 或更高版本。指南。
2. 克隆项目并进入目录：

    bash
    git clone https://github.com/assafelovic/gpt-researcher.git
    cd gpt-researcher
    

3. 通过导出或写入 .env 文件设置 API 密钥。

    bash
    export OPENAI_API_KEY={Your OpenAI API Key here}
    export TAVILY_API_KEY={Your Tavily API Key here}
    

    （可选）如需增强追踪与可观测性，还可以设置：
    
    bash
     export LANGCHAIN_TRACING_V2=true
     export LANGCHAIN_API_KEY={Your LangChain API Key here}
    

    如使用自定义的 OpenAI 兼容 API（如本地模型、其他提供商），还可以设置：
    
    bash
    export OPENAI_BASE_URL={Your custom API base URL here}
    

4. 安装依赖并启动服务器：

    bash
    pip install -r requirements.txt
    python -m uvicorn main:app --reload
    

访问 http://localhost:8000 即可开始。

其他安装方式（如 Poetry 或虚拟环境）请参阅快速开始页面。

 以 PIP 包运行
bash
pip install gpt-researcher


 示例用法：
python
...
from gpt_researcher import GPTResearcher

query = "why is Nvidia stock going up?"
researcher = GPTResearcher(query=query)
 Conduct research on the given query
research_result = await researcher.conduct_research()
 Write the report
report = await researcher.write_report()
...


更多示例与配置请参阅 PIP 文档页面。
