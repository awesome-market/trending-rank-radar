Aerial

给国产电视的一块干净桌面。

参照 Apple TV 做的 Android TV 桌面：没有广告，没有推荐流，只有你的 App、壁纸和航拍屏保。
适合小米、TCL、创维、索尼等国产电视，也能装在盒子和投影仪上。开机自动进入，待机也不会被清理。

 功能


  
  


- 首页：常用的一排 App 放在屏幕下方的玻璃底板上，往下是全部 App。小米「应用中心」「米家」这类藏起来的系统 App 也在。
- 整理：长按 OK 键（或按菜单键）可以移动、放进文件夹、隐藏、卸载，或者设成「开机时打开」（开机、待机醒来直接进这个 App 或信号源）。固定到主屏幕的 HDMI 可以选接的是 Apple TV、PlayStation、Switch、Xbox、电脑等，换成对应的图标，也能在手机上起名字。
- 用手机整理：扫电视上的二维码，手机上就是和电视一样的图标网格：按住拖动排序，点一下改名、换图标、放进文件夹或隐藏，也能把 HDMI 等信号源加到主屏幕。
- 图标库：常用 App 直接用做好的 16:9 磁贴图，一个 App 可以有好几张，在手机上点开 App 挑，每张都写着来源。图来自 le5inioo 画的一套（706）、App 自己的 tvOS 版图标、Aerial 自己画的系统 App 图标和当贝桌面。
- 控制中心：在第一排按上键到右上角打开，有信号源、网络、设置、音量、亮度和个性化。
- 屏保：Apple TV 的 114 段航拍影片，电视支持时播 4K 或 4K 杜比视界，也可以换成照片、时钟或从手机添加的本地视频（说明）。
- 壁纸：必应每日精选、14 张内置壁纸、用手机扫码传的照片和视频，或者航拍：停在主屏幕 10 秒后在磁贴后面播放，按任意键停在当前画面。
- 个性化：每排 4、5 或 6 个 App，单排或双排、时钟大小和位置、App 名称、焦点样式、按键声音，都能改。


  
  



  
  


 安装

不用 root，不动系统应用，随时能还原。电脑和电视连同一个网络。

 1. 打开电视的 ADB 调试

| 电视 | 怎么打开 |
|---|---|
| 小米 / Redmi | 设置 → 关于 → 连续按「产品型号/产品类型」进入开发者模式，再到 设置 → 账号与安全，打开「ADB 调试」和「安装未知来源的应用」 |
| TCL / 雷鸟 | 设置 → 关于 → 本机信息，快速按遥控器「上下左右」，在底部的「更多」里打开 ADB |
| 海尔 / 模卡 | 按电视机身上的信号源键，再用遥控器按「左左上右」，在工厂菜单里打开「ADB 调试开关」，别动其他选项 |
| 海信 / Vidda | 设置 → 声音，关闭杜比全景声；在 专业音响设置 → 声音平衡 里快速交替按「确认」「菜单」，左上角出现 M 后按「菜单」进工厂菜单，把「选项」里的 To Fac 从 U 改成 M 后重启，别动其他选项；再到 设置 → 全部设置，连按「菜单」打开原生设置，连按版本号后在开发者选项里打开「USB 调试」和「无线调试」。工厂菜单按错有风险，反复改 To Fac 可能让 USB 失灵、要重置电视，只改一次（详细） |
| OPPO（含 S1） | 设置 → 系统 → 关于本机 → 设备型号，按「上上右右」再按确认；再到 设置 → 系统 → 开发者选项，打开「USB 调试」。IP 在 设置 → 网络 → 已连接的网络 最下面 |
| 其他 Android TV | 设置 → 设备偏好设置 → 关于 → 连按「内部版本号」7 次，再在开发者选项里打开「USB 调试」 |

电视的 IP 在「设置 → 网络 → 已连接的网络」里。第一次连接时，有 USB 调试开关的电视会问是否允许调试，选「始终允许」；只有无线调试的电视不弹这个窗，见下一段。

只有无线调试、没有 USB 调试 / 网络调试（ADB 调试）开关的 Android 11+ 电视，第一次要先配对（例如索尼 BRAVIA 的 Android 14，747）：这类电视不提供旧的明文端口，不能直接 adb connect :5555。在电视上打开 设置 → 系统 → 开发者选项 → 无线调试 → 使用配对码配对设备，把配对码屏幕上的 IP:端口和 6 位配对码输入电脑：

bash
adb pair 192.168.1.20:37115    电视配对码屏幕上的端口（示例，以电视显示为准）
 提示 Enter pairing code 时输入电视上的 6 位配对码
adb connect 192.168.1.20:39201    无线调试主页面上的另一组 IP:端口（示例）


连上后照常安装。想让以后直接用 :5555，连上时再运行一次 adb tcpip 5555；配过对的电脑不用再配对。install.sh 和安装说明里的 Agent 会引导这一步。部分 TCL 固件（Q10M、Q10L、鹤 6 Ultra 等）没有配对码入口，只能先按下面的分品牌说明用数据线连电脑授权。

更细的分品牌说明（包括打不开 ADB 的机型）见 docs/devices/adb-by-brand.md。

text
请帮我把开源电视桌面 Aerial 装到我的电视上，并设为开机进入的桌面。
电视 IP：
保持 ADB 常开：要

（打不开时用 https://raw.githubusercontent.com/pengchujin/aerial-tv/main/site/agent.md ）

请先完整读完安装说明再动手，然后在我的电脑上亲自运行命令，不要只把步骤告诉我。需要我在电视上操作时提醒我。
最后按说明里的「验收」，把这几条命令的原始输出原样贴给我：
- adb shell "cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME"
- adb shell settings get secure enabled_accessibility_services
- 按主页键后的 adb shell "dumpsys window | grep mCurrentFocus"


手机上的豆包、网页版聊天只会把步骤告诉你，不会执行；要用能跑命令的电脑版 / 工作版（豆包电脑版或豆包工作版、WorkBuddy、千问电脑版、Trae、Claude Code、Codex 等）。Agent 说装好了，看它贴出的 mCurrentFocus 输出里有没有

Aerial 1.96 v1.96 2026-11-13
中文

升级：控制中心「有新版本」→「下载并安装」，或再运行一次安装命令。

- 音量键：守护替固件接管音量键的电视上（TCL ak30a5、小米 ANSM0 等），守护调音量时也弹出系统音量条；按住音量键能连续调，不再只走一格（1499 1498）。
- 海信 VIDAA 安卓 6：主页键弹出的聚好看浮层会收掉、回到 Aerial，不用再等 5 秒，从设置里按主页键也能回来（1505）。
- 老款海信 VIDAA：从磁贴打开原桌面不再马上被拉回（1502）。
- 设置按钮：电视厂商的设置页要系统权限、第三方打不开时，跳过它试下一个，不再直接提示「此电视不支持」（1388，Aerial Lite 同步）。
- 从磁贴打开原桌面：Aerial 被系统清理、守护重新启动后，仍然记得是你主动打开的，不会把原桌面拉回（海尔，1491）。

以上改动没有在对应机型上实测，升级后麻烦在 issue 里告诉我们结果。小米 MFTR0、TCL MT5879 上回归过主页键、信号源和屏保。
