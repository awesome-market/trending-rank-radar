🌱 ARIS 是方法论，不是平台。重要的是科研工作流——带着它去任何地方。

💡 在 Claude Code / Codex CLI / Cursor / Trae / Antigravity / GitHub Copilot CLI / OpenClaw / DeepSeek Harness 里以 skill-based workflow 用 ARIS——任你选！执行者干活，另一个独立模型（默认 Codex MCP）审稿。替代模型组合（包括 ModelScope 上托管的模型）不需要 Claude 或 OpenAI API。

📦 上面是直接安装 skills 的用法。想一条命令装好?ARIS 也提供独立 CLI 和插件:  ·  ·  · 

🤝 SuperARIS：你的个人科研 Agent，背后有一支持续协作的团队。

把 ARIS 工作流交给一支常驻团队：主 Agent 统筹，工程与写作并行，每位成员都能按需读取 ARIS 技能与项目上下文。直接与 Codex 推进实验、与 Gemini 讨论和写作，也可以使用全 Codex 团队。主 Agent 主动跟进交付，项目文件承载跨会话记忆；现有的临时 MCP worker 和独立 reviewer 继续参与协作。
