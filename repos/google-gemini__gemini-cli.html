Gemini CLI








 [!IMPORTANT]
 Read before installing — Gemini CLI status & tool guide

 - Enterprise Code Assist only: Designed for Gemini Code Assist Standard / Enterprise licenses and Code Assist for GitHub on Google Cloud (your access remains unchanged).
 - No free tier or Google AI plans: Free individual access and Google AI Pro / Ultra (Google One) moved to Antigravity CLI on June 18, 2026 (transition post).
 - Not optimized for Gemini 4+: Not tuned for the Gemini 4 series (for example, Gemini 4 Argon) or future releases in this or later generations.
 - Not for model benchmarks: Don't use Gemini CLI to benchmark Gemini models—its harness isn't tuned for Gemini 4+ and produces unrepresentative scores.

 Which Google CLI do you need?

 | Tool | Best for | Links |
 | :--- | :--- | :--- |
 | Antigravity CLI (agy) | Interactive multi-agent coding terminal. Use for Gemini 4 Argon+, free / Google AI Pro & Ultra accounts, or Google Cloud. | Download · Migrate · Argon post |
 | Gemini API CLI (gemini-api) | Stateless API CLI (not a coding harness). Gives agents (agy, Claude Code, Codex), scripts, and CI direct commands for Gemini models, media gen, file analysis, and managed agents. | GitHub · Releases · API docs |
 | Gemini CLI (gemini, this repo) | Organizations with Gemini Code Assist Standard / Enterprise or Code Assist for GitHub on Google Cloud (plus legacy paid API / Vertex keys). | Docs |

Gemini CLI (gemini) is an open-source terminal agent maintained for enterprise
Gemini Code Assist workflows on Google Cloud. Learn more in the
Gemini CLI documentation.

 📦 Installation

See
Gemini CLI installation, execution, and releases
for recommended system specifications and a detailed installation guide.

 Quick Install

 Run instantly with npx

bash
 Using npx (no installation required)
npx @google/gemini-cli


 Install globally with npm

bash
npm install -g @google/gemini-cli


 Install globally with Homebrew (macOS/Linux)

bash
brew install gemini-cli


 Install globally with MacPorts (macOS)

bash
sudo port install gemini-cli


 Install with Anaconda (for restricted environments)

bash
 Create and activate a new environment
conda create -y -n gemini_env -c conda-forge nodejs
conda activate gemini_env

 Install Gemini CLI globally via npm (inside the environment)
npm install -g @google/gemini-cli
