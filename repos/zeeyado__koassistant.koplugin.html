KOAssistant







Powerful, customizable AI assistant for KOReader.

Documentation: the Wiki has a page for every feature; the full list is at the end of this page.


  
  
  
  


 What it does

- Highlight text → translate, explain, define words, analyze passages, connect ideas, and save the answer into KOReader's notes; short answers land in a small popup at your selection. Contexts and Chat
- X-Ray → a browsable guide to the book up to where you are (people, places, ideas, terms), kept current by checkpoints as you read, with known names underlined in the text. Using X-Ray
- Book Groups → a series or a project with its own hub and settings; what the other books' X-Rays know is carried in for free. Book Groups and Series
- Book Hub → one page per book gathering its artifacts, chats, notebook, group and settings. Book Settings and Book Hub
- Reading analysis → recap, document summary and analysis, an About overview, notes analysis, discussion questions, chapter quizzes, an end-of-book suggestion. Reading Analysis Actions
- Research Mode → papers with a DOI get an academic X-Ray, research-aware prompts and, with web search on, web-enriched analysis, with no setup. Research Mode
- Spoiler protection → on by default: the AI stays behind your reading position, per book or for one chat. Spoiler Protection
- Session controls → a chip row in the input dialog (Domain, Web, Tools, Quick, Scope, Attach, Spoiler); most chips are a tap for this chat and a hold for their default. Contexts and Chat
- Dictionary and translation → actions in KOReader's dictionary popup, a compact AI dictionary, bypass modes that skip the menus, and translate views. Dictionary and Translation
- Notebooks → a markdown notebook per book, an optional one-tap Add to notebook button in the highlight menu, Obsidian vault integration. Conversations, Notebooks and Export
- Library → what to read next, reading patterns, comparisons across books, collection analysis. Contexts and Chat
- General chat → the AI without book context. Contexts and Chat
- Web search, book tools, reasoning → current information from the web, the AI searching the open book for its answers, thinking set per model. Reasoning, Web Search and Book Tools
- Multilingual → chat in any language the AI understands; the plugin's UI has 26 languages. Languages
- Generate images → a highlight or an X-Ray entry drawn by OpenAI, xAI, Gemini or OpenRouter, kept in a gallery on the device. Image Generation
- Customizable → custom actions, behaviors, domains, per-action models, template variables, and control over every menu the plugin appears in. Actions and Menus, Prompts, Behaviors and Domains
- Private by default → your highlights, notes, notebook, the book's text, library and reading habits are asked for before anything goes. Privacy and Data
- Keeps itself current → one-tap updates, backups and restore. Backups and Updates
