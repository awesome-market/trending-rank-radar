 7天用Go从零实现系列

7天能写什么呢？类似 gin 的 web 框架？类似 groupcache 的分布式缓存？或者一个简单的 Python 解释器？希望这个仓库能给你答案。

推荐先阅读 Go 语言简明教程，一篇文章了解Go的基本语法、并发编程，依赖管理等内容。

推荐 Go 语言笔试面试题，加深对 Go 语言的理解。
