 🚀 快速部署

一行命令完成交互式安装（已有部署执行同一命令即可更新）：

bash
curl -fsSL https://raw.githubusercontent.com/hicocos/tg-vault/main/install.sh | bash


安装向导会自动生成配置、迁移数据库并启动容器。更多说明见在线部署教程。

 📦 存储支持

可在 设置 → 存储 中同时添加多个存储账户，并为默认上传、Bot 转存或单个频道订阅分别指定归档目标：

| 存储类型 | 接入方式 | 适用场景与特性 | 配置教程 |
| :--- | :--- | :--- | :--- |
| 本地磁盘 | 宿主机目录挂载 | 零外部依赖，适合本地大容量数据盘高速读写与直接预览 | 本地存储指南 |
| OneDrive | Microsoft OAuth 2.0 | 支持国际版个人/商业账户、大文件分块续传与多账户接入 | OneDrive 指南 |
| Google Drive | Google OAuth 2.0 | 支持个人盘与共享云端硬盘，Resumable 会话续传与回收站管理 | Google Drive 指南 |
| S3 / Cloudflare R2 | S3 兼容 API | 兼容 AWS S3、Cloudflare R2、MinIO 等对象存储分片直传 | S3 / R2 指南 |
| 阿里云 OSS | 阿里云对象存储 API | 支持 RAM 最小权限密钥与同地域内网高速写入 | 阿里云 OSS 指南 |
| WebDAV / NAS | Basic / Digest 认证 | 对接群晖、威联通 NAS、Nextcloud 等标准 DAV 服务 | WebDAV 指南 |
| OpenList | OpenList 原生 API | 直连已挂载多网盘的 OpenList 实例，无需额外协议转译 | OpenList 指南 |

 🤖 Bot 常用命令

| 命令 | 说明 |
| :--- | :--- |
| /start | 绑定并认证当前 Telegram 账号 |
| /tg_download | 启动频道/群组历史文件下载向导（支持按日期范围或标签筛选） |
| /tg_sub / /tg_subs | 创建新频道订阅，或查看、暂停、恢复已有订阅 |

| /target | 切换 Bot 默认接收文件的目标存储账户与目录 |

 🔌 扩展能力

- MCP 连接 AI Agent：通过 Streamable HTTP 或本地 stdio 桥接向 AI 客户端开放文件搜索、UTF-8 文本读取、分块上传、订阅管理与历史归档能力，采用独立 Bearer 令牌与存储范围隔离。详见 MCP 接入指南。
- qBittorrent 下载转存：连接本机 qBittorrent WebUI，支持提交磁力链接或 .torrent 种子、勾选目标文件并在下载完成后自动转存至云端，可自由选择清理源文件或保留做种。详见 qBittorrent 教程。

v3.0.0

2026-11-08 · GitHub Release

 新增

- MCP AI 接入：支持远程 Streamable HTTP 与本地 stdio，让 AI Agent 搜索文件和目录、读取文本、生成下载与预览链接，以及改名、移动、收藏和删除文件。
- AI 任务与归档：支持查询进度、暂停、继续、取消和重试任务，创建、编辑、启停和同步订阅，并按日期或标签提交 Telegram 历史归档。
- AI 文件上传：支持直接上传、分块上传、断点续传和内容校验，可查询上传状态、核对中断后的结果，减少重复传输。
- 「AI 接入」管理页：可分别设置客户端权限、存储账户和有效期，生成或撤销令牌、验证连接并查看调用记录；写操作支持请求去重与操作预览。
- 一键安装入口：新增根目录 install.sh，支持自动下载项目、指定安装目录和更新已有部署。
- 中文文档站：提供部署、Telegram、存储、MCP 和日常运维教程，支持全文搜索与移动端浏览，可从应用「关于」页直接访问。

 改进与修复

- 新增毛玻璃外观，更新深浅色界面与项目标识，统一操作按钮样式并改进「关于」页面。
- 存储账户详情支持直接更新认证信息并保留已有文件关联，修复 OneDrive 凭据刷新覆盖新配置的问题。
- 改进 Telegram 暂停、恢复和归档调度，细化下载、上传、等待上传及重试进度，修正任务
