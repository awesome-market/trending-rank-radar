 安装

先安装并退出一次官方 Codex / ChatGPT，然后从 GitHub Releases 下载对应平台的安装包：

| 平台 | 下载 | 安装说明 |
|---|---|---|
| macOS · Apple Silicon / Intel | CodexDreamSkin-vX.Y.Z.dmg | docs/install-macos.md |
| Windows · x64 | CodexDreamSkin-Setup-vX.Y.Z.exe | docs/install-windows.md |

不需要 clone 源码、安装 Node.js 或运行 .sh / .ps1。安装后从 macOS 菜单栏或 Windows 系统托盘使用。更新是手动的：下载新安装包覆盖安装即可，主题和图片会保留。公开安装包目前未签名，新下载的文件在个别系统上仍可能出现一次安全提示，文档里有图形界面的放行方法。

一键换肤 —— 在 DreamSkin.cc 上点一下，本机客户端直接装上，不用先下载再手动导入

在 DreamSkin.cc 上看到喜欢的主题，点「一键换肤」即可。需要 v1.5.0 或更新的客户端（建议 v1.5.5 及以上）。

流程与安全边界：

- 网页通过 dreamskin://apply?version=ver_... 唤起本机 App。链接只能携带一个主题版本 ID，不能携带任意 URL、文件路径或命令，也不存在静默应用参数。
- App 只向固定的官方 API 取包，并拒绝重定向。
- 换肤前弹出原生确认框，并核对该版本的审核状态、一键兼容标记、版本号、包大小、实际下载字节数和 SHA-256。
- 通过后复用与手动导入完全相同的 ZIP、manifest、图片与 Safe CSS 校验。
- 只有真实渲染进程确认新主题已生效才算成功。启动或渲染失败会自动尝试恢复换肤前的主题，恢复结果同样要经过可见性验证；无法确认时会明确报告状态未确认，而不是假装已恢复。

只有完整满足当前主题包契约（背景图 + theme.json + 非空 theme.css + 声明 safe-css 能力）的主题才会显示一键换肤按钮；不满足的走下面的手动导入。

中文 · English

本次更新修复 Windows 在启用 Node.js 环境代理时，因一条非致命警告而无法安装、启动或操作主题的问题。对应 435。

 修复与改进

- Windows 代理环境兼容：启用 NODE_USE_ENV_PROXY=1 时，Node.js 的 UNDICI-EHPA 实验性警告不再被 Windows PowerShell 5.1 当成操作失败。图片检查、主题导入及应用继续根据实际校验结果决定是否成功，非法图片、CSS 和主题包仍会被拒绝。
- Windows 启动判断：将辅助程序的结构化结果与警告分开读取，避免无害警告干扰隐藏窗口识别和已显示皮肤的保留判断；实际失败的诊断信息仍会保留。
- macOS：本次没有运行时行为变更，版本号同步为 1.5.21。

 升级与使用

Windows 用户可使用新版安装包覆盖安装。此修复不需要关闭代理或屏蔽全部 Node.js 警告，安装器不会改写用户的代理环境变量。
