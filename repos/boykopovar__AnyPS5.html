 About

Tool for automatic executables porting to Linux and Windows.

The relinker-only build runs on macOS, including Apple silicon.

Web converter - files stay on your device.

!anyps5_collage1

Includes a relinker that converts executable to the target system's native format and implementations of system prx libraries suitable for dynamic linking. No emulation or separate runtime process.

Discord, Usage, Build instructions, Architecture, Technical debt of the project, code style conventions, contributing

 Status

   



Progress history

 System libraries: percentage of the functions known to the project so far (declared in core/libs/prx), not of every PS5 system function. The total grows as more functions are declared.

Unsupported or unexpected states throw a C++ exception, usually std::runtime_error. An exception that nothing catches prints its what() to stderr and ends the process.

The shader recompiler successfully produces SPIR-V (validated via Spirv-Tools when built with ANYPS5_ENABLE_SPIRV_TOOLS).

 Compatibility

Per-game status and test reports live in the Game bring-up discussions, one thread per title.

 Input mapping

SDL-mapped game controllers are supported, including analog sticks and triggers. Keyboard and mouse controls can be configured with an anyps5-input.ini file. See input mapping for the supported devices and configuration format.
