CreatorHub

本地运行的多平台内容管理工作台，支持 抖音 / 小红书 / 快手 / 视频号 / TikTok。

在线预览 · 平台能力 · 使用指南 · 下载安装 · 问题反馈 · 赞赏与交流


  
    
      
      
    
  


统一管理账号、采集与监控内容、下载素材和处理发布及互动任务。账号登录态、数据库与媒体文件保存在本地，各平台能力以使用指南为准。

 在线预览使用脱敏示例数据，仅展示界面与交互；真实登录、采集、下载和发布需要在本地运行。

 平台能力

| 平台 | 主要功能 |
|---|---|
| 抖音 | 作品 / 评论 / 弹幕监控、批量采集、下载、发布与私信管理 |
| 小红书 | 笔记 / 评论监控、关键词与收藏采集、下载、发布与私信管理 |
| 快手 | 作品 / 评论监控、批量采集、下载与发布 |
| 视频号 | 本账号作品、数据与评论管理，批量采集与发布 |
| TikTok | 关键词视频采集、作品 / 评论监控、下载、视频发布与用户互动 |

 视频号仅处理本账号内容；TikTok 当前支持单视频发布，暂不支持图文发布与直播。详细能力、操作步骤和使用限制见使用指南。

 快速开始

 Windows 安装版（推荐）

1. 在 Releases 的 Assets 中下载 CreatorHub-Setup-版本-windows-x64.exe。
2. 双击安装，通过桌面快捷方式启动。
3. 点击「启动本地服务」，等待浏览器组件准备完成，打开工作台并登录账号。

适用于 Windows 10/11 x64，无需手动安装 Python；安装与首次启动请保持联网。版本更新见更新与备份。

 源码运行（开发者 / macOS / Linux）

准备 Python 3.10+ 和桌面环境，其他依赖与平台要求见安装指南。

bash
git clone https://github.com/3441293738/creatorhub.git
cd creatorhub


Windows：

powershell
.\start.cmd


macOS / Linux：

bash
chmod +x start.sh
./start.sh


首次运行自动准备虚拟环境、Python 依赖、浏览器组件和 config.yaml，随后打开 http://127.0.0.1:8000。

 技术栈

基于 Python、FastAPI、SQLite 与兼容 Playwright 的浏览器自动化接口。浏览器按平台使用系统 Chrome/CDP 或 Patchright。
