  Mole
  Mac 深度清理、应用卸载、系统优化、磁盘分析与状态监控，免费开源命令行，另有原生 Mac App

 💡 这个仓库是免费开源的命令行工具（mo），喜欢图形界面的话可以单独下载 Mole for Mac，支持删除前逐项确认、实测 800 多款软件的卸载残留、系统维护、逐层分析磁盘空间、实时状态监控，以及在支持的 Mac 上控制风扇，Windows 上对应的原生 App 是 Mole for Windows，brew install mole 只会安装命令行工具。

 功能

- 多合一命令行：把 CleanMyMac、AppCleaner、DaisyDisk 与 iStat Menus 的日常用法放进一个终端命令
- 深度清理：清除系统缓存、应用日志与卸载残留，释放磁盘空间
- 应用卸载：移除应用程序，同步清理配置文件与自启动项
- 磁盘分析：终端交互式浏览目录层级，定位占用空间的大文件
- 系统优化：刷新 DNS、QuickLook 与图标缓存，优化系统数据库
- 实时监控：在终端看板中实时查看 CPU、内存、磁盘读写、网络流量与进程

 快速开始

Mole 支持 macOS 12 及更高版本，兼容 Intel 与 Apple Silicon 芯片，Homebrew 不再支持你的 macOS 版本时改用脚本安装。

通过 Homebrew 安装

bash
brew install mole


通过脚本安装

bash
curl -fsSL https://raw.githubusercontent.com/tw93/mole/main/install.sh | bash


用 AI Agent 安装

直接告诉你的 Agent：

 Install Mole for me by reading https://raw.githubusercontent.com/tw93/Mole/main/llms.txt

也可以自己装 skill，装上后 Claude Code、Codex、Cursor 等 Agent 删东西前会先用 --dry-run 把清单给你看，卸载 App 和要管理员权限的步骤留给你自己跑，更新用 npx skills update -g -y。

bash
npx skills add tw93/Mole -a claude-code codex cursor -g -y


喜欢用宿主自带的插件管理，Claude Code 里先 /plugin marketplace add tw93/Mole 再 /plugin install mole@mole，Codex 里先 codex plugin marketplace add tw93/Mole 再 codex plugin add mole@mole，DeepSeek Harness 里用 dsh plugin --profile  add dsh-mole。

常用命令

bash
mo                            打开交互式菜单
mo clean                      深度清理与已卸载应用残留
mo uninstall                  卸载应用及其残留
mo optimize                   刷新系统缓存与服务
mo analyze                    磁盘空间浏览（也可写 mo analyse）
mo status                     实时系统健康看板
mo purge                      清理项目构建产物
mo installer                  查找并删除安装包
mo slim                       移除通用应用里的 Intel 代码

mo touchid                    配置终端 Touch ID 指纹提权
mo completion                 配置命令行 Tab 键自动补全
mo update                     检查并更新 Mole
mo update --nightly           更新到最新未发布的开发版（仅限脚本安装）
mo remove                     从系统中完全卸载 Mole
mo --help                     查看帮助信息
mo --version                  查看已安装版本


安全预览

bash
mo clean --dry-run
mo uninstall --dry-run
mo optimize --dry-run
mo purge --dry-run

mo history

mo optimize --whitelist       管理受保护的优化规则
mo clean --whitelist          管理受保护的缓存白名单
mo purge --paths              配置代码项目扫描目录
mo analyze /Volumes           仅分析外接移动硬盘或磁盘卷
mo analyze /private/tmp       仅查看临时目录（不自动清理）



其他安装选项

想装特定版本就传入 Releases 页面 里的任意 Tag，带不带开头的 V 都行，想跟开发分支就传 main：

bash
curl -fsSL https://raw.githubusercontent.com/tw93/mole/main/install.sh | bash -s -- 1.51.0
curl -fsSL https://raw.githubusercontent.com/tw93/mole/main/install.sh | bash -s -- main


main 会安装默认分支上还没发布的代码，可能不稳定，latest 只是 main 的旧别名，并不会安装最新稳定版。

安装脚本默认装到 /usr/local/bin，可能需要输入管理员密码。希望以后的 mo update 不用输密码，可以装到用户目录：

bash
mkdir -p "$HOME/.local/bin"
curl -fsSL https://raw.githubusercontent.com/tw93/mole/main/install.sh |
