DSH Desktop


  基于 DeepSeek Harness 构建的 Windows、macOS 和 Linux 开源桌面客户端。


一键下载，开箱即用。


  万物皆「插件」，桌面本身也是「插件」。


独立的社区开源项目，与深度求索不存在隶属、合作、授权或背书关系。本仓库目前无深度求索员工或 DeepSeek Harness 上游官方团队成员参与；GitHub Contributors 中显示的上游贡献者来自 fork 继承和同步的提交历史。中文 · English


  



  
  
  
  
  
  


DSH Desktop 将 DeepSeek Harness 的本地 Web UI、Host 服务和插件系统集成到原生桌面应用中。项目固定并原样运行特定上游版本；DSH Desktop 提供窗口、托盘、终端、更新和工作配置，并通过 DeepSeek Harness 提供的插件机制与上游能力组合。



 下载与安装

当前正式安装包支持 Windows x64、macOS Universal 和 Linux（x64 与 arm64）。无需额外环境，下载安装，一键使用。

| 平台 | 下载 | 安装方式 |
| --- | --- | --- |
| Windows x64 | 下载安装程序 | 运行 NSIS 安装程序并按提示完成安装 |
| macOS Universal | 下载 DMG | 打开 DMG，将 DSH Desktop 拖入 Applications |
| Linux x64 / arm64 | GitHub Release | 按发行版选择 deb、AppImage 或 tar.gz，见下方 Linux 安装 |



 Linux 安装

Linux 安装包只在 GitHub Release 发布，x64 与 arm64 各有三种格式：

| 格式 | 适用 | 安装与启动 |
| --- | --- | --- |
| deb | Debian、Ubuntu 及其衍生发行版 | sudo apt install ./DSH-NEXT--amd64.deb（arm64 为 -arm64.deb），之后从应用菜单启动 |
| AppImage | 其他发行版，免安装 | chmod +x DSH-NEXT--x86_64.AppImage（arm64 为 -arm64.AppImage）后直接运行 |
| tar.gz | 自行管理文件 | 解压 DSH-NEXT--linux-x64.tar.gz（arm64 为 -linux-arm64.tar.gz），运行其中的 dsh-desktop-next；不会创建应用菜单入口 |

Ubuntu 24.04 及以上推荐使用 deb，它会安装 Chromium 沙箱需要的 AppArmor 配置。发布页的 SHA256SUMS.txt 可用于核验下载的文件。

Linux 版不能在应用内安装更新：发现新版本时应用会提示，并可直接打开该版本的发布页；请下载与当前安装方式相同的格式手动更新。deb 用同样的 sudo apt install 命令覆盖安装，AppImage 用新文件替换旧文件。

详细步骤、插件命令和故障排查见用户指南与常见问题。

我们希望和所有插件作者一起，构建一个开放、可组合、可持续的 DSH 插件生态，让每个插件都能与其他插件共同进步：DSH 插件生态倡议书。

 主要功能


  
    
      Desktop
      把上游 DeepSeek Harness 的本地 Web UI 带到原生桌面。应用自动启动和管理本地 Harness 服务，集成系统托盘与桌面窗口，无需安装 Node.js 或执行命令。
    
    
      手机远程控制 
      通过 iOS 和 Android 远程连接 Desktop，在手机上发起任务、查看 Agent 进度，并在需要时继续跟进。已在2.0.9及以上版本中内置

Latest release

DSH NEXT v2.0.23-next v2.0.23-next 2026-11-13
中文

本次 Next 更新将上游升级至 DeepSeek Harness v0.2.2-rc.3，换用全新瓷青“鲸尾”应用与托盘图标，带来实验性「DeepSeek 会话导入」、多层级 AgentTeam 协作与 DeepSeek Search API 默认搜索，新增 Host 启动超时配置、慢启动插件提示与渲染性能采样，并将 Windows 应用内更新升级为原子目录替换，同时修复 macOS 滚动区窗口拖动、Linux AppImage 沙箱与 Windows 权限传播等问题。

DSH NEXT 是社区维护的开源项目，并非 DeepSeek 官方产品。

上游版本： DeepSeek Harness v0.2.2-rc.3。

 新增与改进

- 全新瓷青“鲸尾”图标: 应用主图标与系统托盘图标升级为瓷青“鲸尾”设计，适配 macOS 默认、深色与色调外观；优化 Windows 暗色模式下的窗口初始背景，减少启动白闪。
- 上游 0.2.2-rc.2 / rc.3 新特性: 新增实验性「DeepSeek 会话导入」插件，支持将 DeepSeek App 或网页版历史会话导入工作区继续对话；支持 Git Worktree 按分支／提交审阅改动与 GitHub 评审、多层级具名子代理及按会话开启的 AgentTeam 协作；网页搜索默认改用 DeepSeek
