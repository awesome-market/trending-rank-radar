README

Ground Station

     


Ground Station is an open-source, browser-based application for tracking satellites and celestial targets,
controlling station hardware, and receiving, decoding, and recording SDR signals. Built for amateur radio
operators, satellite enthusiasts, and researchers, it brings orbit visualization, multi-target tracking consoles,
SDR waterfall analysis, packet and telemetry decoding, scheduled observations, and hardware management into a
single web interface.

 Recent Releases

 v0.8.26 (2026-11-12): Added an opt-in installation census with disclosed country inference, a dedicated settings card, and localized controls, and grouped system pages with routed maintenance tabs for clearer navigation. Chinese translations are now complete, thanks to a community contribution, and schedule regeneration no longer discards observations that have already started.
 v0.8.25 (2026-11-11): This release adds live aircraft tracking with ADS-B decoding, flight instruments, playback, and altitude-aware map markers; radiosonde decoding with multi-frame RS41 parsing and per-serial capture grouping; and Meshtastic decoding with regional tuning ranges and node mapping. APRS stations gained info panels, symbol rendering, and packet history, and the Packet Map moved to MapLibre with a live mode, transmitter context actions, and column management. The waterfall gained SDR detachment with background streaming, independent receiving sessions, Soapy server management with manual probing, and Bias-T voltage safeguards, while continuous observations can now be created from live sessions and managed persistently. Manual rotator control arrived with floating draggable controls and tracker handoff, file browsing gained type-based purging and telemetry status badges, and the app adopted new Meridian branding alongside rebuilt satellite icons.
 v0.8.24 (2026-10-30): This release adds scheduler observation conflict detection that validates shared hardware time across the observation form, satellite selector, and pass selector, plus new packet decoding, telemetry parsing, and housekeeping views with RS18S support in the USP parser. Numeric decoder parameters gain range-validated input fields, toolbar actions adapt to available space with a new responsive button, and artifact dates now consistently prefer capture time across the backend and file browser. Saved satellites and transmitters load reliably by NORAD ID despite autocomplete limits, with expanded test coverage for satellite search, scheduling validation, and decoder workflows.
 v0.8.23 (2026-10-29): SSTV decoding is now far more robust, with new tone detection and audio resampling, and decoded images open in a reusable image viewer that works across decoded files. Satellite deletion now preserves the catalogs, groups, and schedules it shares with others, and the monitored satellite dialog falls back to option labels when translations are missing.
