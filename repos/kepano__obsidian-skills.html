README

Agent Skills for use with Obsidian.

These skills follow the Agent Skills specification so they can be used by any skills-compatible agent, including Claude Code, Codex, and Open Code.

 Installation

 Claude Code marketplace

From terminal:

sh
claude plugin marketplace add obsidianmd/obsidian-skills
claude plugin install obsidian@obsidian-skills


From within a Claude Code session:

sh
/plugin marketplace add obsidianmd/obsidian-skills
/plugin install obsidian@obsidian-skills


To get new skills later, run claude plugin update obsidian@obsidian-skills.

 Codex marketplace

sh
codex plugin marketplace add obsidianmd/obsidian-skills


Then install Obsidian from the plugin directory in Codex or the ChatGPT desktop app.

 Cursor

Install Obsidian from the Cursor Marketplace.

 npx skills

sh
npx skills add https://github.com/obsidianmd/obsidian-skills


To use ssh instead, if you have a GitHub SSH key set up:

sh
npx skills add git@github.com:obsidianmd/obsidian-skills.git


 Manually

 Claude Code

Copy the plugins/obsidian/skills/ directory to .claude/skills/ in the root of your Obsidian vault (or whichever folder you're using with Claude Code). See more in the official Claude Skills documentation.

 Codex

Copy the plugins/obsidian/skills/ directory into your Codex skills path (typically ~/.agents/skills). See the Agent Skills specification for the standard skill format.

 OpenCode

Clone the entire repo into the OpenCode skills directory (~/.opencode/skills/):

sh
git clone https://github.com/obsidianmd/obsidian-skills.git ~/.opencode/skills/obsidian-skills


Do not copy only the inner skills/ folder — clone the full repo so the directory structure is ~/.opencode/skills/obsidian-skills/plugins/obsidian/skills//SKILL.md.

OpenCode auto-discovers all SKILL.md files under ~/.opencode/skills/. No changes to opencode.json or any config file are needed. Skills become available after restarting OpenCode.

 Release maintenance

Update the plugin version in every manifest with:

sh
./scripts/bump.sh patch


The script also accepts major, minor, or an explicit version like 1.1.0.
