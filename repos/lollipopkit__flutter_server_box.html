 特点

连接

- 支持 SSH 直连、经跳板机连接或使用 ProxyCommand；也可通过 Monitor 使用 HTTP 连接，适用于不希望暴露 SSH 端口的主机。
- 在支持的平台上，可打开本机 shell，或安装 Linux 用户空间（本机终端）。

查看状态

- CPU、内存、交换分区、磁盘、磁盘 I/O 和网络的实时与历史图表，以及传感器、GPU（NVIDIA、AMD）、电池和磁盘 S.M.A.R.T.。
- 一览所有服务器，可按标签筛选，也可在地球视图中查看。
- 推送提醒、桌面小组件和 watchOS App；App 关闭后，Monitor 仍会为这些功能提供支持。

管理服务器

- 完整的终端；工作区支持分屏。
- 通过 SFTP 或 SCP 浏览、上传、下载并直接编辑文件。
- RDP 和 VNC，可以连服务器本身，也可以连它能访问到的其他桌面。
- Docker 与 Podman、进程、systemd 服务、用户与用户组、防火墙规则（ufw、firewalld）、定时任务、端口转发和代码片段。
- 管理 libvirt 和 Proxmox VE 上的虚拟机与容器，通过 Redfish 管理服务器的 BMC。
- 基准测试（YABS）和 iperf。
- AI Agent 可协助管理服务器，并使用你选择的模型提供商、MCP server 和 skill。

个性化

- 内置商店里的主题和图标包，也可以自己制作。
- 生物识别应用锁；可将备份保存到 iCloud 或 WebDAV，并使用你设置的密码加密。
- 支持 iOS、Android、macOS、Linux 和 Windows，16 种语言。

 帮助

- ServerBox Monitor 是安装在你服务器上的服务端组件。不打开 ServerBox app 时仍需工作的功能都依赖它 —— 推送通知、桌面小部件 和 手表 app；它同时也是添加服务器的第二种方式：app 可以经 HTTP 而不是 SSH 访问它，适用于不便暴露 SSH 端口的主机，并且图表在 app 首次连接前就已有历史数据。Monitor 还提供网页面板。
- Agent skills： 本仓库包含三份供 AI agent 使用的 skill。使用下面的命令添加：

  sh
  npx skills add lollipopkit/flutter_server_box
  

  - serverbox-help：使用 App，以及部署和配置 Monitor，例如添加服务器、某台服务器缺少某个功能的原因、权限、告警、小部件和备份。App 内置的 Agent 自带这份 skill。
  - serverbox-onboarding：参与开发，包括搭建 Flutter + Rust + Node 开发环境、构建与测试，以及项目的工作原理。
  - serverbox-theme：制作主题包（.fsbt），校验后发布到主题商店。

  它们的源文件都在本仓库中，安装前可以先读一读它们会告诉你的 Monitor 什么。
