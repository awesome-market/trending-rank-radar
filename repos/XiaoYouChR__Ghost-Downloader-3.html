 功能特性

 快在刀刃。 好网快是本分，烂网快才是本事。智能分块无需合并文件，自动适配带宽。真实浏览器 TLS 指纹，不触发风控。
 合而不同。 集大成，而不失其专。HTTP、磁力/BT、FTP、M3U8、MPEG-DASH、eD2k 全协议通吃。YouTube 与 Bilibili 框选片段、任意画质与字幕、播放列表与合集分 P。GitHub 与 HuggingFace 镜像加速。
 一触即发。 下载按钮跟随视频画面，任意画质随心选。扩展窗口列出页面上所有媒体，在扩展中点一下，或者仅是照常下载，桌面端无缝接管。链接不用复制，而且带着验证状态。
 始终如一。 细节见真章。同一个软件，四个系统，体验处处原生。Android 端同样支持直播录制与后台下载。
 尽在掌控。 游刃有余。兼容 aria2 RPC API，第三方工具直接推送。下载途中改链接、改请求头、改代理，进度不丢失。


 关于本项目

始于兴趣，最初是为了帮一位 B 站 UP 主整合资源。如今已覆盖四大平台、支持几乎所有主流下载协议，功能包插件体系也在逐步开放中。

| 平台 | 版本要求 | 架构支持 |
|:--|:--|:--|
|  Windows | 10+ | x86_64 / arm64 |
|  macOS | 13.0+ | x86_64 / arm64 |
|  Linux | glibc 2.35+ | x86_64 / arm64 |
|  Android | 9.0+ | arm64-v8a |

 [!WARNING]
 由于 Qt 6.6+ 已经不再支持 不支持 AVX 指令集的 CPU

 Arch Linux AUR 支持：现已可通过社区维护的软件包 ghost-downloader-bin 和 ghost-downloader-git 进行安装（维护者：@zxp19821005）

 命令行

在 设置 - 命令行工具 中安装 ghd 后即可使用。

| 命令 | 作用 |
|:--|:--|
| ghd probe  | 预览链接，不添加任务 |
| ghd add ... | 添加并开始任务 |
| ghd tasks | 列出任务 |
| ghd task  | 查看任务详情 |
| ghd pause ... | 暂停任务 |
| ghd start ... | 继续任务 |
| ghd remove ... | 移除任务，并删除未完成的文件 |
| ghd wait ... | 等待任务结束 |

sh
 查看种子包含哪些文件
ghd probe "https://example.com/a.torrent"
 只下载其中第 0、3 个文件，保存到 ./downloads
ghd add "https://example.com/a.torrent" --select 0,3 -o ./downloads
 等待下载完成
ghd wait tsk_0123
