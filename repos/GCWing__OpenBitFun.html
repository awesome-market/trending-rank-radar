 四种模式，按你的方式工作

Agent Harness 决定任务如何推进，负责规划步骤、组织上下文、调用工具、协调多个 Agent 并整合结果。根据当前任务，选择适合你的协作方式：

!四种工作模式：极简、标准、极致与创造

| 模式 | 什么时候选 |
| --- | --- |
| 极简 · Minimal | 即时协作。 目标明确、希望快速动手时，AI 直接执行，你随时反馈，在协作中持续调整。 |
| 标准 · Standard | 日常任务。 工作需要多个步骤时，有序规划、逐步执行，并检查结果。 |
| 极致 · Ultimate | 复杂任务。 问题需要深入分析时，拆解任务，由多个 Agent 分工协作、整合结果。 |
| 创造 · Creative | 创造与定制。 想做自己的应用或扩展工作台时，创建 Mini App，定制 OpenBitFun 的界面与功能。 |

 切换多台电脑，手机远程控制

切换设备，整个工作台随之切换。 在桌面端选择另一台已连接的电脑，界面就会切换到那台设备的会话、工作区、文件与任务状态。家中电脑、办公室电脑和服务器，都可以在同一个应用里切换查看与操作。

手机就是远程控制端。 通过手机或浏览器发送指令、查看进度、补充要求和处理授权。任务始终在所选设备上运行，切换界面或断开控制端连接后仍会继续。

官方 Relay 开箱即用，无需部署服务器。 在各设备上使用同一个 OpenBitFun 账号登录，可选择 GitHub 或受支持的邮箱验证码登录；也可使用同一网络连接。登录、联网与自托管条件见连接常见问题。

手机端支持单屏、双屏、三屏布局自由切换。 单屏时专注对话，展开后并排查看会话与文件；界面随屏幕形态调整，让折叠屏的空间真正用起来。

!在多台电脑间切换完整工作台，并通过手机远程控制所选设备


连接与部署说明

工作区也可以通过 SSH 连接到远程主机、跳板机或容器，让文件访问、终端与工作区命令在目标环境中执行；Agent Runtime 仍由 OpenBitFun 宿主运行。桌面和 CLI 共享核心执行能力，移动端与消息机器人提供更多控制入口。

同账号设备互控默认使用官方 Relay；桌面端也可启动本地 Relay，供同一网络内的手机连接。两种方式登录时都需要访问 OpenBitFun 在线身份服务，局域网模式不提供离线登录。私有 Relay 需要配套客户端构建，详见部署指南。

设备间传输的内容采用端到端加密，密钥在设备上生成，会话与文件按需从持有它们的在线设备读取；Relay 仍处理账号、设备和路由元数据。这一加密边界不涵盖模型服务商、聊天机器人平台或已发布的 Pages。详见隐私边界、远程连接与远程工作区。



 把想法，变成自己的应用

为仓库做一个 Git 洞察面板，为演示文稿做一个 PPT 工作台，或把常用操作集中到一张表单。Mini App 让工作中的具体需求，变成可直接使用的小应用。

描述需求，让 Agent 创建应用。每个 Mini App 都有自己的界面和 Agent 会话：你可以操作界面处理任务，也可以通过对话调整功能，让工具在使用中不断完善。

做好的应用可以安装、反复使用。你也可以去 Mini App 市场发现适合自己的工具。

 用 OpenBitFun，创造 OpenBitFun

从角色、工具到界面和源码，都可以按需定制。 从贴合工作习惯的专属 Agent 开始，逐步扩展你的工作台：

- 定制专属 Agent。 围绕漫剧创作、视觉设计、代码评审等领域，选择模型、设定角色，组合需要的工具与工作方法。
- 接入工具与流程。 通过 MCP 连接专业工具，把常用工作方法保存为 Skills，用 Hooks 扩展任务执行流程。
- 改变界面与源码。 选择内置主题调整外观，也可以修改 UI、工具与 Runtime 源码，构建自己的 OpenBitFun。

你可以直接让 OpenBitFun 的 Code Agent 修改和扩展 OpenBitFun 本身。

扩展方式见 Agent 管理、Hooks 契约与兼容范围和产品架构。

 持续执行，也认真对待效率

Rust Agent Runtime 承载会话状态、上下文管理与工具执行。持久会话、中断恢复、长期记忆与长程任务支持工作接续；上下文压缩和缓存复用帮助控制持续执行的资源开销。

在这组 DeepSWE v1.1 评测中，OpenBitFun 的表现：

- GLM-5.3-Flash：通过率 64.6%，耗时 P50 42.9 分钟。
- DeepSeek-V4-Flash：通过率 56.6%，耗时 P50 19.6 分钟。

OpenBitFun 1.0.10 桌面端更新

- Office 文档生成：新增 Word、Excel、PowerPoint 文档的增量创建与编辑，支持 Excel 图表、Word 公式、多语言内容和字体继承，并完善文件导出与错误恢复。
- 消息队列：待发送消息以输入框托盘呈现，支持预览、编辑和排序；移动端提供原生排序操作，CLI 提供键盘管理，队列顺序由执行宿主统一维护。
- 多设备工作台：支持本地管理设备排序与侧边栏可见性，改进设备预览、切换动画和会话预热；修复 Peer Device 会话附件、控制端文件选择和主题设置的归属问题。
- Generative UI 与 Agent：不完整的交互界面可自动修复，减少修复过程中的额外消息；完善 MiniApp 会话恢复、BTW 权限继承和 Claw 用户问题处理，并新增 BTW 关闭确认偏好。
- 搜索与链接：新增 Keenable Search 搜索服务，可为会话链接选择默认浏览器，并在多个窗口间同步浏览器偏好。
- 会话与快捷键：改进回滚后的历史恢复与空状态、工具组宽度和长错误文本展示，修复标签关闭、画布导航及快捷键录制的焦点与冲突处理。
- 性能与稳定性：降低长轮次流式投影、滚动和工作台常驻渲染开销，改进终端生命周期；修复禁用代理和 Windows 代理绕过规则，并在系统托盘新增重启入口。
- 远程控制：Relay 链接改用
