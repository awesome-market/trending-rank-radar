_November 4, 2026_

 Changes in 1.4 (since 1.3.2)

- CMake:
  - The minimum CMake version is now 3.15, up from 3.12.
  - Library file names changed on MSVC: z is now libz, as in libz.dll, libz.lib, and the static libzs.lib. minizip's libraries changed the same way.
  - On Cygwin, the libraries now use the lib prefix.
  - Contrib targets and tests built as part of zlib are now prefixed with zlib_. Several test targets were renamed to one scheme, for example zlib_examplestatic and minigzipstatic.
