README

DBDelve

A fast, native, cross-platform, multi-engine database client. Written in Rust
with GPUI, no Electron and no JVM: instant startup, friendly on your memory,
and smooth scrolling through large tables where other clients crash or
introduce limits.

 Why

I wanted something which is performant, modern and consumes little ram. The existing DB clients are either filled with bloat (Electron and JVM) or paid. This is an alternative to them. No feature is ever going behind a paywall and with time we will have complete parity on features with those too.

 Install

macOS (Apple Silicon, macOS 12 or later):

sh
brew install --cask ShayanAbbas1/dbdelve/dbdelve


The app isn't notarized, so the cask clears the quarantine flag macOS would
otherwise refuse it over. Without Homebrew:

sh
curl -fsSL https://raw.githubusercontent.com/ShayanAbbas1/dbdelve/main/install.sh | sh


Linux (x86_64 or aarch64): the same one-liner installs it under ~/.local
with no root, or yay -S dbdelve-bin from the AUR, or the tarball or AppImage
from [the latest release][releases].

Windows (x86_64): run the installer from [the latest release][releases],
or unzip the zip and run dbdelve.exe. The installer asks for AppData (just
for you) or Program Files (all users).

Updating, the .dmg, Linux requirements, building from source and where your
data lives are all in docs/install.md.

[releases]: https://github.com/ShayanAbbas1/dbdelve/releases/latest

 Supported databases

Postgres, MySQL, MariaDB, SQLite, Turso, DuckDB, Snowflake, SQL Server, MongoDB,
Redis (and Valkey, KeyDB, Dragonfly) and ClickHouse.

Any other database with an ODBC driver is reachable through the bundled ODBC
bridge, with that driver installed: IBM Db2, Oracle, SAP HANA, SAP ASE
(Sybase), Informix, Teradata, Vertica, Exasol, Firebird, Amazon Redshift,
Google BigQuery, Databricks, Apache Hive, Trino and Presto, Dremio,
InterSystems IRIS, Microsoft Access and more. Grid editing is off, and
statements you type run under the connection's mode. See
Connecting through ODBC.
