VideoSeek





中文 | English

本地视频语义检索：用文字或截图定位镜头，支持硬字幕 OCR，预览后导出 MP4 / 剪映 / NLE。  
默认全程在本机索引（ONNX · Lance · FFmpeg），不上传素材。若你在设置里主动开启「云嵌入」，抽出的帧和查询会发到你配置的云服务。

 永久免费。 勿信收费倒卖或付费代装；请从 GitHub / 官网 获取。

官网下载 · Releases · 使用教程 · QQ 1033551438

 功能

- 文字与图片搜索 — 自然语言或参考图找相似镜头时间段  
- 图库 — 同步图片文件夹后，在搜索页「找图」  
- 硬字幕 OCR — 按画面字幕关键词定位台词  
- 库与范围 — 多库、指定视频、搜索预设；搜索页可填绝对时间段，套在每一条视频上  
- 预览与导出 — 时间轴预览；MP4；剪映草稿 / Premiere XML / 达芬奇 FCPXML  
- 本地优先 — 默认同步和搜索都在本机。只有主动开启「云嵌入」时，抽帧和查询才会发到你配置的云服务。局域网里，用户机可以用文字或图片搜索服务机已经建好的库；同步在本机或服务机上做。另有 localhost Agent API  

 可选：视频理解、标签搜索、多种 CLIP 系模型、实验性解说剪辑等。主路径：同步 → 搜索 → 导出。

 适用场景

| 你的情况 | 你想… |
|----------|--------|
| 大量本地 / NAS 视频 | 按画面语义找片段，而不是翻文件名 |
| 记得台词或硬字幕 | OCR 后按关键词跳到时间点 |
| 剪辑工作流 | 粗定位后进剪映 / PR / 达芬奇 |

 快速开始（安装包）

1. 从 lv17.top 或 Releases 下载  
2. 首次启动按提示 导入运行资源（模型、FFmpeg；需要字幕时再导入 OCR）  
3. 侧边栏 视频库 → 添加文件夹 → 勾选视频 → 同步选中视频  
4. 搜索 → 输入查询 → 预览 → 导出  

 快速开始（源码）

推荐 Windows 10/11。其它系统见 docs/quickstart.md。

bash
pip install -r requirements.txt
python main.py


bash
conda env create -f environment.yml
conda activate VideoSeek


| 缺什么 | 怎么办 |
|--------|--------|
| 模型 / FFmpeg | 应用内导入、123 云盘，或 models release |
| VLC（仅 Windows 源码） | vlc_lib release → 解压到项目根目录 |

备选：模型 zip 与 ffmpeg.exe 已在磁盘、且不想点导入弹窗时，先关闭 VideoSeek，下载 import_runtime_resources.py 后执行（无需克隆仓库，写入 %LOCALAPPDATA%\VideoSeek）：

bat
python import_runtime_resources.py openai-clip.zip ffmpeg.exe
