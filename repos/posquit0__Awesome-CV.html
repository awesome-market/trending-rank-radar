 What is Awesome CV?

Awesome CV is LaTeX template for a CV(Curriculum Vitae), Résumé or Cover Letter inspired by Fancy CV. It is easy to customize your own template, especially since it is really written by a clean, semantic markup.

 How to Use

 Requirements

Awesome CV uses LuaLaTeX with HarfBuzz, driven by latexmk. XeLaTeX and pdfLaTeX are not supported by this version of the class.

Install a current full TeX Live distribution (or MacTeX on macOS), including lualatex, latexmk, and fontawesome6. TeX Live 2026 is the recommended starting point. latexmk also requires Perl, which is included with TeX Live on Windows. Make is optional.

Install the Source Sans 3 and Roboto font families, including Regular, Italic, Bold, Bold Italic, Light, and Light Italic. Use the static desktop OTF/TTF fonts from Source Sans 3 and Roboto; installing only a variable font may not provide the named faces required by the class. Fonts must be visible to LuaLaTeX under these family names. After installing fonts, run luaotfload-tool --update if they are not found.

Alternatively, place the static font files in the repository root. The included luaotfload.conf enables discovery of fonts in the working directory, including files uploaded to Overleaf.

The Dockerfile provides TeX Live and the required fonts together. It is also used by CI, so Docker is the reference environment for reproducing builds locally.

 Usage

Run commands from the repository root, where latexmkrc and awesome-cv.cls are located. Paths in the examples are relative to this directory.

bash
latexmk


This builds the cover letter, CV, and résumé into build/coverletter.pdf, build/cv.pdf, and build/resume.pdf. make runs the same command. Generated PDFs, logs, and SyncTeX files stay in build/; the committed PDFs in examples/ are previews and are not overwritten.

To build one document, or rebuild it automatically while editing:

bash
latexmk examples/resume.tex
latexmk -pvc examples/resume.tex


The existing make resume.pdf, make cv.pdf, and make coverletter.pdf shortcuts also write to build/. For your own document, run latexmk your-cv.tex from the repository root; keep its input and image paths relative to that root.
